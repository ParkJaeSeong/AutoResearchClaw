# M1 UI 연결 및 실제 역할 테스트

사용자 승인: M1 화면 연결 → 실제 역할 실행 → 작은 사례의 수정/재검토 루프를 테스트한다. 기존 E01–E06 설계의 M1 부분을 실행하며 M2/M3 완료로 표시하지 않는다. 시작 코드 c9303c4, 기존 isolated worktree 유지.

## 작업 단위

- [x] U1 조회·실행 접점: E01 M1 build_view(root, head_id), 안전한 raw allowlist, research inspect/view, 등록된 operation용 CLI apply와 역할별 packet. GET는 읽기 전용. 단일 검증 스냅샷·실제 ancestry·단계 공개를 지킨다. 비공개 최초 의견/해시/사설 이벤트/가짜 raw 경로는 노출하지 않는다.
- [x] U2 화면: E02/E03 M1 지도, 실제 개정/이동, 대화 단계, 쟁점 타임라인, 원문·근거·검증·승인·인계 상세. 한국어, 기존 vanilla JS, 안전한 textContent, 반응형/키보드/light-dark, polling 선택·스크롤/과거 HEAD 유지. 기존 m1_ui 유지.
- [x] U3 실행·수용: 공개 init/apply/packet으로 테스트 프로젝트를 만든다. 제공 자료와 합성 여부를 명시하고 실제 역할별 최초 의견→반박→최종 의견을 등록한다. 지적→가설 개정→재검토를 실제 공개 경로로 수행하며 조정자가 역할 판단을 대필하지 않는다. 각 실제 제출의 호스트/모델은 확인 범위만 표시한다. 사용자가 계속 테스트할 수 있는 실행 지침과 로컬 URL을 남긴다.
- [ ] U4 최종 확인: 안전/정책 관련 pytest와 UI node:test, 실제 브라우저 viewport/theme/선택유지/쟁점·대화·raw 대조. 기존 원본·가져온 프로젝트 불변. 완료/미확인 범위를 구분해 기록한다.

## 승인·호스트 경계

실행은 Codex 호스트에서 public CLI를 통해 수행하고 UI는 읽기 전용 관찰/다음 작업 전달을 담당한다. 문헌 승인·실험 권한을 자동 생성하지 않는다. 합성 테스트 준비 단계에 포함되는 테스트용 선언은 명확히 표시하고 실제 사용자 승인으로 포장하지 않는다. M2 실험은 실행하지 않는다.

## 검증과 작업 분담

U1→U2→U3 의존 구현은 직렬, 별도 검토자가 각 작업을 검토한다. 읽기 전용 사전 점검은 병행 가능하다. 원본 작업판 E01–E06의 M2/M3 요구는 미완료로 남기고 이 M1 부분만 상태를 기록한다. 기존 관련438개 검사는 c9303c4 코드 기준 확인됐으며 관련 변경 이후 최종 회귀만 실행한다.

## 실행 결과

U1 eabc522, U2 db8e228 및 실제 U3 수용 경로를 검토 완료했다. U4 자동 검사는 Python15개, Node11개 통과. 실제90개 역할 실행·72개 협의 제출로9개 단계와 가설 개정1회를 진행했으며, 중요한 가설 쟁점7개를 별도 검증 후 해소하고 선택적2개를 보존했다. 인계 자료는 발행됐으며 수신자 수락을 기다린다.

U4는 브라우저 시각 수용만 남아 있다. Chrome ERR_BLOCKED_BY_CLIENT, 인앱 브라우저 미제공으로360/736px·테마·키보드·스크롤을 실제 화면에서 확인하지 못했다. 이 항목을 완료로 표시하지 않는다. [테스트 안내](2026-09-09-m1-ui-test-guide.md)를 참고한다.
