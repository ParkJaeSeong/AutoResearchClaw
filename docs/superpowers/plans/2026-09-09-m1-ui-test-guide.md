# M1 UI 테스트 안내

테스트 화면: <http://127.0.0.1:8767/>

프로젝트는 이 작업 트리의 `.superpowers/sdd/m1-ui-test/native-live-project`에
있다. 기존 M1 원본·가져온 프로젝트는 그대로 유지한다. 새 화면은 읽기 전용이며,
실행은 Codex 호스트가 공개 `research init/apply/packet` 명령으로 수행한다.

## 확인할 순서

1. **가설 → 내용·개정**에서 1차와 2차를 비교한다. 과도한 입증 단정이
   미검증 가설로 바뀌고, 집단별 반증 조건과 경쟁 설명이 보완됐다.
2. **공개 대화**에서 각 버전의 도메인·방법론·비판 검토자의 최초 의견,
   교차 반박, 최종 의견을 읽는다. 첫 의견은 전원 제출 전에는 공개되지 않는다.
3. **쟁점 이력**에서 중요한 쟁점 7개가 열림 → 검증 중 → 해결로 바뀐 근거를
   확인한다. 가설 개정만으로 닫힌 것이 아니라 고정된 해소 조건, 검증 결과,
   별도 검토자의 해소 기록이 연결돼 있다. 선택적 쟁점 2개는 열린 채 보존된다.
4. **근거·검증**에서 제공 원문과 추출 구간, 독립 검사, 가설의 근거 참조를
   확인한다. **승인·인계**에서는 합성 테스트용 승인 선언과 인계 상태를 구분한다.
5. 상단에서 과거 HEAD를 선택해 당시 공개 범위를 확인한다.
   “최신 기록 따라가기”로 돌아오면 새 기록을 반영한다.

이 사례의 자료와 권한 선언은 **합성 개발 테스트용**이다. 실제 문헌 승인이나
실험 결과가 아니다. 역할별 의견은 별도 Codex 실행에서 실제 생성했으며,
모델 식별은 설정 기본값으로 미확인, 역할 격리는 `instructions_only`다.
M2/M3 실행은 구현하지 않았고 M2 수신자 승인을 자동으로 만들지 않는다.

## 서버 다시 실행

```sh
cd /Users/jspark/orca/AutoResearchClaw/.worktrees/m1-research-graph
.venv/bin/researchclaw-codex research view .superpowers/sdd/m1-ui-test/native-live-project --port 8767
```

서버가 이미 실행 중이면 같은 포트를 다시 열 필요가 없다. 화면의 CLI 안내에서
`ROOT`는 위 프로젝트 경로로 바꾼다. `packet`은 각 검토자 전용이며 공개 HTTP
화면에는 제공하지 않는다. `apply`는 현재 HEAD와 새 command ID를 요구한다.
이번 사례의 입력·명령·역할별 실행 기록은 `.superpowers/sdd/m1-ui-test/`에
보존되어 있으며, 대용량 런타임 원문은 Git 기본 검색 대상에서 제외된다.

## 확인 범위

서버와 모든 UI 자산의 HTTP 응답, 실제 공개 데이터의 화면 연결, 과거 첫 의견
비공개, CLI 등록 및 M1 수정·재검토 경로를 검증한다. 실제 Chrome 탭은
`ERR_BLOCKED_BY_CLIENT`로 차단됐고 인앱 브라우저는 사용할 수 없어,
360/736px 배치·실제 키보드 동작·테마 대비·스크롤 복원은 아직 수용 확인 전이다.
DOM 검사 결과를 실제 브라우저 시각 검증으로 간주하지 않는다.
