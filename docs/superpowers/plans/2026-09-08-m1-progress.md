# M1 실행 현황

M1 전체 완료 전이다. A 묶음의 UI·호스트 연결·그래프 계약에 이어 Task11 쟁점·응답·최종 입장 구현·검토까지 완료했다. 기존 전체 회귀 검사는 장시간 대기로 중단되어 부분 기준선으로 남았다.

| 작업 | 상태 | 확인할 결과 |
|---|---|---|
| 01 기준선·정책 | 정책·부분 기준선 검토 완료 | 주요 166개 통과. 전체는 중단, 환경 실패 2개는 설정 보완 후 재검사 통과 |
| 02 결정 과정 UI | 완료 · 독립 검토 통과 | 아래 로컬 시안에서 가설 수정·대안 보류·근거 탐색 |
| 03 실제 호스트 연결 | 완료 · 독립 검토 통과 | 세 역할의 최초 제출 및 동일 문맥 후속 응답 |
| 04 그래프·역할 계약 | 완료 · 독립 검토 통과 | 열 개 작업의 페르소나·권한·복귀 경로 |
| 05 신규 프로젝트·불변 저장 | 완료 · 독립 검토 승인 | 초기화·조회, 자료·이력 보존, 중복·충돌·저장 오류 대응 |
| 06 작업 패킷·산출물 등록·재개 | 완료 · 독립 검토 승인 | 입력·제출 조건 고정, 등록·보정 이력, 검토 대기와 읽기 전용 재개 |
| 07 문헌 승인과 추출 | 완료 · 독립 검토 승인 | 승인 문헌 집합·선별 사유·추출 근거 연결, 변경·반려 시 대기 |
| 08 근거 종합과 계보 | 완료 · 독립 검토 승인 | 주장·충돌·공백에서 해당 버전의 추출·승인·출처 추적 |
| 09 가설 모델·독립 심사 배정 | 완료 · 독립 검토 승인 | 가설 버전·근거·수정 이유·작성자 분리 |
| 10 독립 제출·전체 공개 | 완료 · 독립 검토 승인 | 세 역할의 같은 입력과 최초 의견 등록 |
| 11 쟁점·응답·최종 입장 | 완료 · 독립 검토 승인 | 실제 최초 의견에 대한 응답과 최종 판단 |
| 12~16 | 진행 중 | 결정·복귀·예산·실제 기록 UI 연결 |
| 17~20 | 후속 통합 | 앞 단계 협의 연결, 인계·통합·설치 검증 |

[최신 로컬 UI 시안](http://127.0.0.1:51633/researchclaw/codex/m1_ui/) — 로컬 서버가 실행 중일 때 열린다. 화면 대화는 명시적으로 표시된 예시다.

[실제 세 에이전트 검증 기록](2026-09-08-m1-host-verification.md) — 합성 자료를 사용한 실제 호스트 통신 결과. UI 시안 대화와 별개이며 M1 완료나 실제 연구 결과가 아니다.

개발 위치: `.worktrees/m1-research-graph`, 브랜치 `feature/m1-research-graph`. 원래 main의 기존 프로젝트는 수정하지 않는다.

앞선 A 묶음의 확인 항목: H1 수정 결정에서 처음 주장·쟁점·응답·수정안을 추적할 수 있는가? H2 보류 이유가 구분되는가? 실제 세 역할의 발언이 기대한 검토 방식인가?

추가 검사: M1 그래프·역할 계약 29개, 기존 역할 검사 123개 통과. UI 검사 8개 통과. 검사 묶음 간 중복 가능성이 있으므로 하나의 총합으로 더하지 않는다.

전체 기준선의 중단 시점 결과는 **2 failed, 3639 passed, 43 skipped, 1 deselected**, exit2다. 75%에서 SSL 대기가 길어져 중단했으며 전체 통과가 아니다. 실패 두 개는 venv 의존성과 CLI PATH 설정을 보완한 동일 원본 소스 검사에서 2 passed로 확인했다. 자세한 명령과 한계는 [기준선 기록](2026-09-08-m1-a-verification.md)에 보존한다.

Task05는 [B 검증 기록](2026-09-08-m1-b-verification.md)에서 명령과 결과를 확인할 수 있다. 신규 검사 66개, 기존 프로젝트·상태·CLI 검사 155개를 통과했다. 별도 프로세스 재조회, 이전 기록 보존, 신규·기존 초기화 충돌 거부도 확인했다.

Task06은 신규 32개를 포함한 관련 검사 **163개 통과**, 별도 CLI 프로세스 수용 확인과 독립 검토 승인을 받았다. 등록 후에는 `review_pending`에서 대기한다. 실제 연구 협의와 UI 연결은 후속 작업이다. 명령과 한계는 [B 검증 기록](2026-09-08-m1-b-verification.md)에 정리했다.

Task07은 신규 39개를 포함한 관련 검사 **343개 통과**, 별도 CLI 프로세스 수용 확인과 독립 검토 승인을 받았다. 승인·반려 이력을 보존하고 변경된 자료에는 새 승인을 요구한다. 실제 원문 확인과 앞 단계 협의는 이번 합성 검사에 포함하지 않았다. [B 검증 기록](2026-09-08-m1-b-verification.md)에서 확인할 수 있다.

사용자 요청에 따라 **Task08부터 Task16 UI 연결까지 연속 진행 중**이다. 각 작업을 독립 검토한 뒤 다음 작업으로 이어간다. 실제 호스트의 발언을 새 엔진에 등록하되 자료는 합성 검증 자료로 표시한다. Task17 이후의 전체 M1 실행·인계 검증은 아직 포함하지 않는다.
