# 작업 문서 읽기 안내

1. 작업 ID를 알면 `tasks/<ID>.md`를 바로 연다. 다음 미착수 작업은 [A05](tasks/A05.md)다.
2. 해당 작업서의 **필수 읽기** 링크만 읽는다. [공통 실행 계약](common.md)은 변경이 없으면 작업 묶음에서 한 번 읽는다.
3. 선행 구현은 필요한 함수·계약을 코드에서 확인한다. 완료된 작업의 전체 보고서를 기본 입력에 넣지 않는다.
4. 추가 문서는 해결할 질문을 정한 뒤 필요한 절만 읽는다. 링크를 재귀적으로 모두 열지 않는다.

전체 진행 상태가 필요할 때만 [작업판](../2026-09-09-research-governance.md)을 연다. 설계 주제를 찾을 때는 [설계 목차](../../specs/2026-09-09-research-governance-design.md)를 사용한다.

문서 분할은 구현 범위·승인·검토 규칙을 변경하지 않는다. 원본 발언·자료·검증 기록은 보존한다.
