# M1 C — Real Hypothesis Council Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 가설의 독립 검토·쟁점·응답·최종 판단을 실제 배정과 근거 버전에 연결한다.

**Architecture:** 가설 작성과 심사를 분리하고 고정 입력에 결합된 협의 세션을 사용한다. 등록기는 형식·순서·권한을 검사하고 연구 내용의 판정은 각 역할이 제출한다.

**Spec:** [총괄 계획](2026-09-08-m1-transition.md). B 및 실제 호스트 확인 03 선행.

## Global Constraints

총괄 제약 전체 적용. 기존 13~15단계 정책과 레코드를 변경하지 않는다. 합의가 없는 결과도 성공적으로 기록할 수 있어야 한다. 실제 대화 원문을 조정자가 만들어 넣지 않는다.

- [x] 근거 있는 단일 가설·정성적 예측 허용, 불명 참조·반증 조건 누락·동일 작성자 검토 거부 검사를 작성한다.

```python
from researchclaw.core.m1.hypotheses import can_review, hypothesis_key
def test_revision_identity_and_author_separation():
    assert hypothesis_key({'id':'H1','revision':2}) == ('H1', 2)
    assert not can_review(author_assignment_id='A1', reviewer_assignment_id='A1')

## Task 10: 독립 제출과 전체 공개

**Interfaces:** `prepare_council(root: Path, *, attempt_id: str, assignments: list[dict], command_id: str) -> dict`; `register_initial(root: Path, *, session_id: str, assignment_id: str, payload: dict, command_id: str) -> dict`; `reviewer_packet(session: dict, assignment_id: str) -> dict`. - [x] review session은 동일한 가설·근거 버전을 세 역할에 배정한다. 역할 중복·필수 역할 누락·작성자 자체 심사를 거부한다.

from researchclaw.core.m1.council import reviewer_packet
def test_initial_packet_does_not_disclose_another_initial():
    session = {'id':'S1','input_binding':'a'*64,
      'assignments':[{'id':'A1','role_id':'domain'},
                     {'id':'A2','role_id':'methodology'},
                     {'id':'A3','role_id':'critical_reproducibility'}],
      'initials':{'A1':{'rationale':['private initial']}},
      'responses':[], 'final_positions':[], 'status':'collecting_initials'}
    packet = reviewer_packet(session, 'A2')
    assert packet['disclosed_initials'] == []
    assert packet['phase'] == 'initial'
```

def test_response_to_unknown_issue_is_rejected():

                'stance':'challenge','rationale':'scope differs','evidence_refs':['C1']}
