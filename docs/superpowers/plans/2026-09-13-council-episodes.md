# Atlas 검토 실행과 회차 연결

합의한 작업 회차 설계의 다음 작은 구현이다. 기존 run_council 실행 경로에서 회차를 자동 시작하고, 이미 받은 Atlas 입력의 참조, 공개 완료된 라운드 의견, 최종 산출물과 종료를 기록한다.

- 기존 잠금과 _saved 명령 재전송을 재사용한다. 회차 ID는 요청 키 해시에서 결정한다.
- 독립 의견은 세 native 제출이 모두 성공한 뒤 공개 회차에 복사한다. 일부 제출·실행 실패 시 미공개 의견을 노출하지 않는다.
- 원래 rationale를 윤문하지 않고 역할/라운드를 작성자 라벨로 표시한다.
- Atlas 조회가 이미 끝났다면 새 도구 호출로 꾸미지 않고 받은 입력의 해시·참조를 기록한다.
- 검토 종료는 개발 검토 대기로 남긴다. 사람 대신 continue를 생성하지 않는다. 기존 연구 실행기의 다음 명령을 전부 차단하는 작업은 별도 통합이다.
- 예전 result.json이 있는 완료 작업은 그대로 반환하며 회차를 소급 생성하지 않는다.
- 중단된 검토는 같은 회차에서 재개한다. running은 실행 보고이며 생존 감지 상태가 아니다.

작업: 회귀 테스트 작성/실패 확인 → atlas_council.py 연결 → 기존 재개·공개 경계 검사 → 사용 안내. 실제 연구·유료 호스트 실행은 이번 코드 검증에서 하지 않는다.

## 결과

자동 연결 구현 완료: atlas_episode.py와 atlas_council.py. 신규·기존 회차 검사23개와 outcome/reviewer/service CLI11개 통과. 독립 리뷰 차단 없음. commit 후 receipt 유실 재개·기존 완료 결과 무변경을 회귀 검사에 추가했다. 합성 executor로 자동 생성한 1회차·11기록(입력1, 의견9, 산출물1)을 UI 스냅샷으로 확인했다. 실제 Atlas·호스트 요청이나 연구 상태 변경은 하지 않았다. 증거: output/evaluations/council-episodes/.
