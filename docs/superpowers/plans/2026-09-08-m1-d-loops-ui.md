- [ ] 도달 가능한 영향을 고정점까지 계산한다. 입력 list는 ArtifactRef ID 문자열로 정규화한 projected attempts를 사용한다.

```python
def affected_attempts(attempts, changed_artifact_ids):
    changed = set(changed_artifact_ids)
    affected = set()
    while True:
        added = False
        for attempt in attempts:
            if attempt['id'] not in affected and changed.intersection(attempt['input_refs']):
                affected.add(attempt['id'])
                changed.update(attempt['output_refs'])
                added = True
        if not added:
            return tuple(sorted(affected))
```
