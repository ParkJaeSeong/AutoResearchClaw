# 자료 직접 수집 흐름 — Zotero 제외

상태: 사용자 합의 방향. 수집 도구와 세부 인터페이스는 설계·검증 전.

사용자가 Zotero를 Pilot 도구 구성에서 제외하기로 결정했다. Zotero·Connector 설치 여부나 항목 키를 Pilot/Atlas 필수 전제로 삼지 않는다. 이전 Zotero 공유 제안을 대체한다. 서지 관리 책임은 유지한다.

## 흐름과 책임

1. Pilot이 연구 질문과 실험 설계에 필요한 근거를 정의한다.
2. 기존 Atlas 자료를 확인한 뒤 부족한 자료를 외부에서 검색·선정한다.
3. 수집 도구로 서지정보와 접근 가능한 PDF·보충자료를 확보한다. 구체 도구는 미선정이며 자동화 완료가 아니다.
4. 원문과 서지를 로컬 전달 자료로 정리한다. 파일명은 사람이 읽기 쉽게 만들되 자료 식별·중복·버전 판별을 파일명에 의존하지 않는다.
5. Pilot이 원문·서지·분석 목적을 Atlas에 전달한다. Atlas가 Documents 변환을 조정하는 방향을 검토한다.
6. Atlas가 변환 결과와 원문·출처를 연결해 지식을 축적한다.
7. Pilot이 내용을 조회·질의하고 에이전트 검토로 가설·실험 계획에 활용한다. 부족하면 이유를 연결한 새 탐색 작업을 만든다.

## 유지할 요구

- 제목·저자·연도·DOI 등 서지, 원문 URL·확보 시각·버전·파일 해시 보존. DOI가 없는 자료도 내부 자료 ID로 식별한다. 정확한 필드 계약은 별도 협의한다.
- 서지만 확보 / PDF 확보 / 변환 완료 / 분석 완료를 구분한다.
- 중복 수집·변환 방지, 부분 실패와 재개, 원문 위치·변환 한계 보존.
- Pilot 작업과 Atlas 작업 및 Documents 하위 호출의 관계·요청·결과 추적.
- 프로젝트와 단계, 실제 수행 순서를 분리한 작업 기록 및 Markdown 요약 구조 유지.

## 이번 검증의 실제 범위

Polybot 논문 한 건의 서지와 PDF를 직접 확보하여 Zotero 로컬 API에 등록한 것은 성공했다. Connector를 이용한 자동 수집 성공은 확인하지 못했다. 이를 범용 자율 수집 기능이 구현된 것으로 취급하지 않는다.

Zotero 제외는 설계 변경이다. 이미 저장한 논문·실험 기록을 삭제하거나 앱·확장 프로그램을 제거했다는 뜻이 아니다. 기존 API/MCP 계약 및 서비스 구현을 이 문서만으로 변경하지 않는다.

사용자 추가 확인: 도구 구성에서만 제외하고 Zotero 앱·브라우저 Connector 설치 및 보관 자료는 유지한다.
