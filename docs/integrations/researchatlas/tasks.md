# 작은 작업 단위와 완료 기준

[전체 줄거리](README.md) · [구현 검토](review.md) · [제안 계약](contracts.md) · [프로젝트](projects.md)

상태: C0 계약 완료. A1은 Atlas 구현·배포 완료. Pilot P0–P3의 HTTP/UI 연결과 별도 시험 연구 T1을 구현·검증했으며 [검증 기록](pilot-t1-implementation.md)을 따른다. 나머지 항목은 계획이다. 이 문서 작성은 구현 착수·완료나 Atlas 측 전달 완료를 의미하지 않는다. 기존 소스·버전·queue·job·QA 체계를 확장하고, 별도 중복 실행기나 새 승인 체계를 만들지 않는다.

## 우선 진행: 이미 보유한 자료로 왕복 연결

| ID | 담당 | 작업 | 선행 | 완료 증거 |
| --- | --- | --- | --- | --- |
| C0 | Pilot·Atlas | 프로젝트/null·instance ID·jobs analyze·원형·멱등성 계약 최종 대조 | 없음 | 필드 예제와 실패 예제가 양쪽에서 동일하게 해석됨 |
| A1 | Atlas | QA raw/record/lifecycle, consulted_pages, 페이지 원형 선택 반환 | C0 | HTTP/MCP 원형 해시 일치, archive 후 원문 불변, 페이지409, QA10 MiB 한도 |
| P1 | Pilot | 연결 파일·info instance 확인을 이용한 조회 클라이언트 | C0 | stats/search/page HTTP·MCP 의미 일치; 토큰 로그 미노출 |
| P0 | Pilot | 연구 재개/생성, Atlas 프로젝트 선택·ID 대응·연결 이유 저장 | P1 | 이름과 ID 구분, 연결 변경 후 기존 job/QA의 소속 유지 |
| P2 | Pilot | 요청 키·job ID·질문/쟁점 연결 영속화 | P1 | 응답 유실·재시작 후 같은 작업 확인; 중복 실행 없음 |
| P3 | Pilot | QA 원기록 수신→기존 외부 근거 등록 연결 | A1,P0,P2 | 원본 해시 보존, 중복 등록 방지, 기존 수동 import와 같은 판단 조건 |
| T1 | 공동 | 보유 지식 질답→검토→추가 질문 시험 | P3 | 원래 질문부터 후속 답변·판단까지 추적; 준비/M1 상태 임의 변경 없음 |

T1은 기존 Atlas 프로젝트를 명시적으로 선택해 시작한다. P0는 A0 생성 API를 기다리지 않는다. 새 Atlas 프로젝트가 필요한 자동 시작에는 A0가 필요하다.

A1은 우선 작은 실사용 연결을 여는 작업이다. 이것만으로 지정 자료 분석이나 자료 전달 공백이 해결되지는 않는다.

| A0 | Atlas | 프로젝트 생성·기존 input/source 연결 서비스 | C0 | 요청 충돌·동명 처리, 대상 종류·명시 버전, 원본 중복 없음 |
| A2 | Atlas | 업로드→queue input 접수, 선택적 source 참조 | C0 | source=null 허용, 접수 멱등성과 파일 중복 구분, 프로젝트/metadata 충돌·미완성 전송 처리 |
| A2b | Atlas·변환 도구 담당 | 완료된 변환 산출물 수령·원본 해시 대응 | A2 또는 기존 source | task/도구 버전·출력 해시·부분 실패·읽은 범위 보존 |

| A3 | Atlas | 기존 jobs kind=analyze로 지정 버전·질문·목적 접수 | C0 | 등록 source 버전·질문·목적 고정, 결과 근거 범위 검사; 접근 격리와 구분 |
| A4 | Atlas | 불변 result_ref와 근거·범위·미해결 결과 조회 | A3 | 주장→구절→원본 버전 추적, 부분 결과·위키 반영 상태 구분 |
| P5 | Pilot | 분석 결과 보존·검토 입력 묶음 생성 | A4,P2 | 동일 입력으로 독립 초기 의견 작성; 새 근거는 다음 회차로 편입 |
| A5 | Atlas | previous_result_ref·미해결 항목을 연결한 보완 분석 | A3,A4 | 이전 결과 보존, 변경 이유·해결/잔여 항목 비교 |
| P6 | Pilot | 부족한 근거 재탐색→후속 분석 반복 | P4,P5,A5 | 같은 쟁점에 연결; 새 근거 없는 반복을 이유 없이 실행하지 않음 |
| T2 | 공동 | PC/CNT 사례의 전체 왕복 시험 | P6 | 자료 발견→전달→분석→반론→보완→설계 사용 판단을 실제 기록으로 추적 |

신규 input은 명시적 ingest 후 source 매핑을 얻어 A3에 전달한다. A3/A4는 기존 텍스트·검토된 추출본으로 먼저 시험한다. PDF 변환이 필요한 T2 사례에는 A2b가 선행한다. 자동 documents 호출 시점·담당은 별도 계약으로 확정한다.

## 후속 운영·확장

- P7: 근거 변경 비교→영향받는 가설·설계 재검토. 첫 버전은 조회·해시 비교로 수행하고 변경 알림 서비스는 필요가 확인되면 추가한다.
- A6: MCP 작업 목록·운영 복구 도구의 필요성 검토. 실행 중인 에이전트를 무시하고 자동 재실행하지 않는다.
- C1: Pilot 연구 결과의 Atlas 반환·정리 후보 계약. Pilot 기원·가설/실측 구분과 프로젝트 간 공유 규칙 포함.
- U1: Pilot 공통 UI에 요청·분석 결과·쟁점·추가자료·변경 이유 연결. 원문 전체보다 현재 판단과 다음 행동을 먼저 표시한다.

## 통합 시험 시나리오

| 시험 | 반드시 확인할 결과 |
| --- | --- |
| 일반 null·검색 범위 | Atlas project=null 허용; project_only=false는 공용 wiki 보완, 타 프로젝트는 별도 조회 |
| 자료실 교체 | 같은 URL의 다른 instance ID를 감지해 자동 의뢰하지 않음 |
| QA 크기 경계 | 디코딩 원형10,485,760바이트 기준, 초과 시 job 결과는 보존하고 import 불가 표시 |
| 연구 생성·재개 | 기존 Pilot 연구와 Atlas 지식 프로젝트를 불필요하게 복제하지 않음 |
| 프로젝트 공유·변경 | 공용 원본을 사용해도 판단은 분리; 기존 작업의 소속 유지; 잘못된 ID를 전체 조회로 대체하지 않음 |
| 범위 밖 발견 | 참고 후보로 구분하고 Pilot 판단 후 편입 |
| 이미 보유한 자료 | 새 수집 없이 조회·QA·근거 등록, 원본 동일성 |
| 새 논문 전달 | 접수와 분석 완료 분리, 출처·해시·프로젝트 이유 보존 |
| 같은 자료 재전송 | 새 source/실행이 불필요하게 늘어나지 않음 |
| 논문 개정본 | 이전 버전 보존, 분석에서 지정한 버전 사용 |
| QA lifecycle 갱신 | 원기록 파일 해시 불변, payload fingerprint와 구분 |
| 페이지 원형 | YAML 포함 바이트로 해시 검증, 본문만으로 판정하지 않음 |
| 신규 input·변환 실패 | source 매핑 전후 구분, 부분 추출을 원문 전체 확인으로 처리하지 않음 |
| 측정 방향 미기재 | 미확인과 영향 반환; 방향을 추정해 완료하지 않음 |
| 자료 간 상충 | 조건 비교·양쪽 근거 보존; 강제 합의 없음 |
| 추가 자료로 판단 변경 | 이전 분석·쟁점에 연결, 새 결론의 변경 이유 표시 |
| 조회 중 페이지 변경 |409등 명확한 변경 감지, 혼합 버전으로 같은 회차 진행하지 않음 |
| 응답 유실·서비스 재시작 | 저장한 키/ID로 상태 확인, 완료·중단 작업 무단 재실행 없음 |
| partial/failed | 전송 성공과 작업 결과 구분, 부분 결과 보존 |
| 독립 초기 의견 작성 중 | Atlas 공용 QA·UI를 통한 미공개 의견 우회 공개 없음 |
| API/MCP 동등성 | 동일 작업·페이지·원본에 대해 의미·해시 일치 |
| M1 착수 준비 미확인 | 분석 완료만으로 준비·인계·실험을 생성하지 않음 |

시험 자료·가상 실행은 실제 연구 근거로 승격하지 않는다. T1/T2에서 사용할 실제 자료와 시험 목적을 기록하고, 과학적 분석 품질은 전송/구조 검증과 별도로 소재·방법·실행 관점에서 평가한다.

## 첫 완료 목표

**Pilot이 질문을 보내고 Atlas의 답변·원기록·참고 버전을 받아 기존 근거 검토에 연결하는 T1**을 먼저 끝낸다. 이후 자료 접수와 지정 분석을 추가해 T2로 확장한다. 자료 탐색·가설 검토·실험 준비 전체를 Atlas의 새 기능으로 옮기지 않는다.
