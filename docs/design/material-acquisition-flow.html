찾은 자료가 연구의 근거가 되기까지

Pilot은 무엇을 찾을지, 무엇을 분석할지, 어디에 쓸지 판단합니다. 수집 담당은 후보와 원문을 확보하고, Atlas는 내용을 분석해 근거와 한계를 돌려줍니다.

두 번 판단하는 이유

③ 분석 대상 선정 — 조사 비용을 어디에 쓸까?

제목·초록·서지 정보로 관련성과 우선순위를 봅니다. 이 단계의 선정은 “연구 근거로 써도 된다”는 승인이 아닙니다. 이미 원문을 확보했어도 같은 기준을 적용합니다.

⑥ 사용 판단 — 이 자료가 무엇을 뒷받침할까?

Atlas가 돌려준 내용과 원문 위치를 바탕으로 도메인 전문가가 검토합니다. 직접 비교에는 못 써도 메커니즘 설명에는 쓸 수 있습니다. 사용 목적·적용 조건·반론·남은 확인을 함께 남깁니다.

예: PC/CNT 전도도 논문을 찾았다면

수집 담당은 PC/CNT·전도도·공정 조건에 맞는 후보를 가져옵니다. Pilot은 비교 조건을 확인할 가치가 있다고 판단하고, Atlas에 함량·가공·측정 방향을 분석하도록 요청합니다. Atlas가 조건 차이를 보고하면 Pilot은 “직접 수치 비교는 보류하되, 배향 메커니즘의 근거 후보로 유지”처럼 용도를 나눠 판단합니다. 이는 흐름 설명용 예시이며 실제 연구 판정이 아닙니다.

이미 보관한 자료는 재사용합니다

시작할 때 Atlas의 기존 자료와 버전을 먼저 조회합니다. 필요한 원문이 있으면 ②·④를 건너뛰고 ③에서 분석 대상을 정합니다. 기존 분석이 질문과 자료 버전까지 충족하면 ⑥에서 재사용 여부를 검토합니다.

수집 담당은 기능상의 역할입니다. 별도 프로젝트로 만들지는 아직 확정하지 않았습니다. Documents의 변환·추출은 Atlas 분석 아래의 세부 과정으로 생략했습니다. UI에서 사람의 검토가 필요한 경우도 별도 정책으로 연결합니다.

설계 검토용 · 자동 연동 구현 완료를 뜻하지 않습니다. 기존 Pilot 공통 디자인의 색상을 사용했습니다. 글꼴은 로컬 Pretendard, 미설치 시 시스템 한글 글꼴입니다. 기존 연구 기록은 변경하지 않았습니다.
