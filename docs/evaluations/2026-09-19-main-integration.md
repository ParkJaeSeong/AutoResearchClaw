# Main 통합 검증 — 2026-09-19

사용자 요청: 현재 개발을 main에 반영하고 GitHub에 올린 뒤 개발 브랜치를 종료한다.

## 범위

feature/m1-research-graph의 누적 Pilot 구현·UI·Atlas/Documents 연결·설계 문서와 프로젝트 정리를 통합한다. M1 전체 자동 실행 완료를 선언하는 배포가 아니다. 현재 구현 경계와 미완료 사항은 README.md와 docs/development.md를 따른다. 실제 연구 상태·외부 서비스·원문 자료는 변경하지 않는다.

## 검증 결과

- Python 기본 수집 대상 6,341개: 고유 항목 기준 **6,285 통과, 56 건너뜀**, 실패 없음. 기존 large_evidence 표시 1개는 기본 설정에 따라 제외됐다.
- 전체 실행을 병렬 처리한 뒤 작업 편중으로 중단하고 남은 항목만 이어 실행했다. 첫 실행 6,178 통과·56 건너뜀, 후속 108 통과(기실행 1개 포함). 최종 collect-only 노드 집합과 두 결과 원장의 합집합이 일치함을 확인했다. 단일 무중단 실행 결과는 아니다.
- Node UI 테스트 **100 통과**.
- Python wheel 빌드 성공, 실행 코드와 UI 정적 파일 포함 확인.
- 통합 변경 및 공개 파일 검토: 인증 파일·토큰·연구 작업 공간은 Git에 추가하지 않았다. 보관 파일 해시와 기존 프로젝트 기록을 대조했다.

원시 로그와 테스트별 결과는 로컬 output/evaluations/main-integration-20260919/에 보존한다.

## 검증 중 수정 및 한계

- 이전 README의 CLI 호환 설명을 docs/legacy-cli.md로 보존하고 문서 검사를 해당 경로에 연결했다. 안전 조건 검사는 유지했다.
- 릴리스 스크립트 테스트를 임시 디렉터리로 격리해 개발용 .venv가 테스트에 개입하지 않도록 했다.
- 복사된 실행기 테스트에 설치 의존성 경로를 전달했다. 실행기 교체 거부 검사는 유지했다.
- 기존 refinement 실행기 환경 검사는 홈 디렉터리의 mtime/ctime 변경에도 영향을 받는다. 검증에는 홈 밖의 별도 가상환경을 사용했다. 운영 검사를 완화하거나 이 제약을 해결했다고 주장하지 않는다.
- 기존 SSH 테스트에서 AsyncMock 경고 1건이 발생했다.

## 보존 및 브랜치 종료

main으로 fast-forward 가능한 것을 확인했다. 기존 원격 codex-native-foundation, codex-native-stage11의 커밋도 통합 브랜치에 포함된다. main 원격 반영 확인 후 이 개발 브랜치들과 로컬 feature/m1-research-graph 이름을 삭제한다.

작업 트리에는 로컬 연구 자료·가상환경·실행 중 서비스가 사용하는 경로가 있다. 따라서 디렉터리는 통합 커밋의 detached HEAD로 보존하고 강제 삭제하지 않는다. main의 기존 로컬 설계 파일 7개는 통합 전에 .git/pilot-integration-20260919/main-local-docs/에 해시와 함께 백업했다.
