## 적용 화면과 구조

현재 사용하는 `research view` 전체를 공통 골격으로 정리했다. 각 연구의 제목·기록·Atlas 연결 기능을 유지하면서 긴 단일 화면을 다섯 영역으로 나눴다.

| 영역 | 표시 내용 |
| --- | --- |
| 연구 개요 | 명시적으로 이어진 결정의 최종 기록, 결론·한계·다음 작업, 대화와 준비 항목으로 가는 링크 |
| 단계와 대화 | 선택 작업의 조건·내용·대화·문제·근거·인계, 자료 분석과 범위 변경 검토 |
| 판단과 준비 | Atlas 답변·사용 판단·조정자 결정·연결된 실제 협의·준비 항목·추가 질문 |
| 자료와 근거 | 확보 파일과 읽은 범위, 문헌 검색 기록·목록·검색 필터 |
| Atlas 연결 | 서비스 연결·질문·접수 상태·답변 수신, 파일 가져오기와 판단 입력 |

결정은 UUID나 화면 배열 순서로 최신을 추측하지 않고 `prior_ref`로 이어진 결정 중 후속 결정이 없는 항목을 보여준다. 서로 독립적인 결정은 모두 남긴다. 요약은 원기록의 문장을 그대로 표시하며, 다음 작업은 조정자가 이유에 명시한 `다음 작업은` 이후의 발췌다. 새 과학적 해설이나 실행 상태를 UI가 생성하지 않는다.

탭 전환은 기존 DOM의 표시를 바꾼다. Atlas 질문 초안·파일 선택·검색·공개 대화·선택 작업을 전환 때문에 다시 생성하지 않는다. 판단 링크와 뒤로 가기는 연결 대상 영역을 먼저 표시한다. 과거 기록의 저장 제한과 독립 의견 공개 규칙은 기존 계약을 따른다.

## 공통 구성과 치수

- 왼쪽: KRICT 원본 로고 → 나침반·Pilot → 현재 연구 → 연구 작업 공간 → 화면 모드·글꼴 라이선스.
- 오른쪽: 현재 위치·기록 설정 → 연구 제목·실시간 상태·마일스톤 → 내부 탐색 → 선택 영역.
- 현재 public view에는 실행 중인 작업·실제 실행 여부·관측 시각이 없다. 세 항목은 각각 확인 안 됨·확인 안 됨·기록 없음으로 표시한다. 실시간 실행 관측 연결은 별도 기능이며, 대화 제출 완료를 현재 프로세스 실행 상태로 변환하지 않는다.
- 사이드바 280px, 1024–1199px에서는 240px. 1024px 미만은 접이식 탐색으로 본문 폭을 확보한다. 원본 표준이 허용하는 중간 폭 예외다.
- 좁은 화면 탐색은 닫기·Escape·키보드 초점 복귀·초점 순환·배경 조작 제한을 제공한다.
- 본문은 가용 폭 전체, 넓은 화면 여백 40px, 중간 24px, 좁은 화면 16px. 사용자 요청에 따라 대화·연구 판단·Atlas 답변·탐색 설명에도 고정 최대 폭을 두지 않는다.
- 작업 지도와 상세는 1400px 이상에서만 240px + 가변 폭 두 열. 그 아래에서는 한 열로 읽는다.
- 제목 28px(접이식 탐색 구간 24px), 영역 제목 20px, 본문 16px/1.6, 조작 14px, 캡션 12px.
- 여백 4·8·12·16·24·32·48px. 패널 반경 12px, 조작 8px, 배지는 pill. 조작 높이는 기본 40px, 좁은 화면 44px.

## 색상·자산

`researchclaw/codex/research_ui/styles.css`에서 공통 역할 토큰과 반응형 규칙을 관리한다. 컴포넌트마다 동일 선택자를 파일 끝에서 반복 덮어쓰지 않는다.

| 역할 | 밝게 | 어둡게 |
| --- | --- | --- |
| 바깥 / 작업 영역 | #F5F7F8 / #FFFFFF | #111816 / #19221F |
| 제목 / 본문 / 보조 | #1A1A1A / #4A4A4A / #626B70 | #F0F5F2 / #D3DED8 / #A7B8AF |
| 선택·행동 / 링크 | #007F70 / #007F70 | #58D5BD / #74DECA |
| 관련 정보 / 조작 경계 | #F2FBF9 / #7B858B | #183D33 / #789589 |
| 초점 | #0075C2 | #73C9FF |

시스템 설정이 기본이며 수동 밝게·어둡게 선택을 보존한다. 저장 차단·알 수 없는 저장값은 시스템 모드로 복귀한다. CSS 미디어 조건이 시스템 변경을 즉시 반영한다. 화면 모드 변경으로 입력이나 연구 실행을 다시 시작하지 않는다. 인쇄는 밝은 표면을 사용한다.

자산은 `research_ui/assets/`에서 자체 제공한다.

- `krict-logo.png`: Presentation 국문 가로 PNG 원본. 원본 비율·색을 유지하며 밝은 화면과 어두운 화면 모두 배경 없이 표시한다. 사용자 피드백에 따라 흰 받침을 제거했다.
- `pilot.svg`: Pilot에서 작성한 32×32 나침반. #007F70 배경·반경 8, 흰 방향 심볼. 파비콘과 제품 아이콘을 공유하며 테마에 따라 색을 바꾸지 않는다. 현재 브라우저용 SVG를 제공하고 별도 ICO는 만들지 않았다.
- Pretendard v1.3.9 Regular·SemiBold·Bold: 원본 WOFF2를 각각 400·600·700으로 선언. `font-display: swap`. 모두 강제 preload하지 않는다.
- `LICENSE.txt`와 `sources.json`: Presentation이 전달한 폰트 라이선스·공식 출처·해시. 사이드바에서 라이선스를 확인한다. 폰트 로딩 실패 시 시스템 서체로 대체한다.

## 구현과 검수

- `index.html`: 공통 껍질, 기관·제품 자산, 정적 파비콘.
- `shell.js`: 영역 탐색, 연결된 기록 이동, 작은 화면 탐색·초점.
- `overview.js`: 선택한 기록 시점의 결정과 준비 요약.
- `app.js`: 기존 연구 렌더링·갱신과 영역 연결.
- `atlas.js`: 기존 입력·등록 기능과 읽기 기록의 표시 위치 분리.
- `research_viewer.py`: 새 JS·이미지·폰트·라이선스의 명시적 정적 경로.

검수 항목과 최종 결과는 [검수 기록](review.md)의 2026-09-13 항목을 따른다. 연구 상태·과학적 판단·단계 완료를 디자인 작업에서 변경하지 않는다. 서버가 하나의 ROOT를 읽는 현재 제품 구조에 맞춰 동작하지 않는 프로젝트 생성·전환 메뉴를 만들지 않았다. 이전 `m1_ui` 구현은 현행 화면이 아니므로 적용하지 않았다.
