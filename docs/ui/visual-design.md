적용 화면은 현재 사용하는 `research view`의 연구 기록·문헌 탐색·에이전트 대화 UI다. 이전 `m1_ui` 화면은 별도 구현이며 이번 적용 대상에 포함하지 않았다. 연구 단계와 권한, 자료·의견·승인의 의미는 기존 계약을 따른다.

## 공통 값과 구현 연결

원본은 `researchclaw/codex/research_ui/styles.css`다. 새 컴포넌트도 이 토큰을 사용하고 파일 끝에 같은 선택자를 다시 덮어쓰지 않는다.

| 역할 | CSS | 밝은 화면 |
| --- | --- | --- |
| 브랜드 표식 | `--brand` | #00AC97 |
| 링크·선택 | `--accent` | #007F70 |
| 바깥 배경 / 작업 영역 | `--bg` / `--card` | #F5F7F8 / #FFFFFF |
| 제목 / 본문 / 보조 | `--heading` / `--ink` / `--muted` | #1A1A1A / #4A4A4A / #626B70 |
| 관련 정보 배경 | `--soft` | #F2FBF9 |
| 장식선 / 조작 경계 | `--line` / `--control` | #E0E0E0 / #7B858B |
| 키보드 초점 | `--focus` | #0075C2, 2px 외곽선·2px 간격 |
| 성공 / 주의 / 오류 / 정보 | `--success` / `--warn` / `--error` / `--info` | #18794E / #8A5A00 / #B42318 / #00649B |

다크 모드는 같은 역할을 중성의 어두운 배경과 밝은 글자로 매핑한다. 밝은 화면의 브랜드색을 흰 작은 글자 배경으로 자동 사용하지 않는다. 선택 표시와 성공 표시는 구분한다. 상태 배지는 원래 문구를 유지하며 성공·주의에 각각 기호를 보조한다.

## 구성 요소 규격

- 일반 콘텐츠 최대 1280px. 바깥 여백은 32px, 768px 미만에서는 16px.
- 제목 28px, 영역 제목 20px, 본문 16px/1.6, 조작·밀도 높은 정보 14px, 캡션 12px.
- Pretendard 우선, Noto Sans KR·Apple SD Gothic Neo·시스템 서체 순으로 대체한다. 웹폰트 파일과 라이선스 배포는 포함하지 않는다. 설치된 서체가 없으면 대체 서체로 표시된다.
- 여백 4·8·12·16·24·32·48px. 패널 모서리 12px, 입력·버튼 8px, 배지는 pill.
- 패널은 경계와 여백으로 구획하고 장식 그림자를 사용하지 않는다. 긴 대화 본문은 최대 800px.
- 버튼·입력 기본 높이 40px, 작은 화면 44px. 탭은 선택 표시선과 문구를 함께 사용한다.
- 1200px부터 작업 탐색 288px + 상세 패널. 그 아래에서는 한 열로 읽는다. 작업 지도는 중간 화면 3열, 작은 화면 2열이다.
- 페이지가 본문 스크롤을 담당한다. 제목이 붙은 긴 쟁점·검색 결과 목록만 내부 스크롤을 유지한다.
- 제품 헤더에는 Pilot 이름을 사용한다. 기관 로고와 제품 로고의 일괄 대체는 하지 않는다.

## 적용 확인

기존 UI·탐색 자동 검사 21개와 서버 조회 검사 4개 통과. 실제 서버의 CSS를 갱신한 후 크롬에서 밝은·어두운 화면과 대화를 확인했다. 두 테마 각각 320·390·768·1280px에서 긴 원문 대화를 펼친 상태로 페이지와 본문 요소의 가로 넘침이 없음을 확인했다.

200% 브라우저 확대 검수는 이번 확인에 포함하지 않았다.

이 기록은 디자인 적용 범위의 확인이다. 전체 접근성 인증이나 아직 구현하지 않은 M2/M3 화면의 검수 완료를 뜻하지 않는다.
