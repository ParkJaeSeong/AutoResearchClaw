# 연구 운영 가이드

연구 에이전트와 작업을 조정하는 Codex가 같은 기준으로 판단하고 진행하기 위한 문서다.

- [M1–M4 운영 흐름](milestones.md): 목적별 분기, Pilot과 전문 프로젝트의 책임, 단계별 산출물.
- [M1 목적별 프롬프트](../prompts/m1/README.md): 공통 규칙·페르소나·세 경로별 자료와 산출물·검수 사례.
- [연구 에이전트 가이드](research-agents.md): 자료 확인, 독립 판단, 반박, 쟁점 처리, 쉬운 설명.
- [조정자 가이드](coordinator.md): 작업 범위, 단계 진척, 조사 중단 기준, 구현·실행·보고의 구분.
- [재검토 진행 기준](return-policy.md): 횟수 대신 부족한 근거·영향·다음 행동을 판단하고 기록하는 방법.
- [프로젝트 화면과 보관 기준](project-storage.md): 프로젝트·마일스톤·단계·수행 회차의 구분과 새 연구 및 기존 자료의 저장 위치.

화면 설계와 표현은 [UI 가이드라인](../../ui/README.md)을 따른다.

최신 합의와 M1 완료 조건은 [AGENTS.md](../../../AGENTS.md)를 기준으로 한다. 연구 경로의 M1은 실험 설계와 실행 준비까지 포함하며, 보고서·계획서는 M1에서 M4로 이어진다.

## Pilot–Atlas 연결

자료 탐색·확보는 Pilot, 전달받은 자료의 분석·축적은 Atlas가 담당한다. [M1 시나리오별 API·MCP 검토](../../integrations/researchatlas/README.md)에서 현재 지원, 제안 계약과 작은 작업 단위를 확인한다.

## 공통 단계 경계

| 단계 | 해야 할 판단 | 완료 판단에 필요한 결과 |
| --- | --- | --- |
| M1: 자료 수집 및 토론 | 어떤 근거로 어떤 방향과 계획을 선택하는가 | 목적별 근거·판단·실행 또는 작성 의뢰 |
| M2: 실험과 분석 | 새 결과가 어떤 설명을 지지·반박하는가 | 실행·분석 결과, 해석과 다음 행동 |
| M3: 논문 작성 | 연구 주장을 논문으로 어떻게 설명하는가 | 검토된 원고·근거·보충자료 |
| M4: 보고서·계획서 작성 | 보고 목적 또는 추진 목표를 어떻게 문서화하는가 | 근거·가정·위험을 구분한 제출용 문서 |

M1에서도 수집 자료의 신뢰성과 사용 적합성을 확인한다. 원문의 단위·두께·온도 의미, 중복과 가공 방식 확인은 M1에 속한다. 기존 자료로 답할 수 없는 과학적 질문을 새 실험으로 확인하는 것은 M2에 속한다. M2·M3에서도 새 자료 문제가 발견되면 해당 근거의 검토로 돌아간다.

예: “원문의 1.2 mm가 시편 두께인가?”는 M1 자료 확인이다. “두께를 같게 해도 공정에 따른 전도도 차이가 유지되는가?”는 M2 실험 질문이다. 앞 질문을 확인하지 못했다면 그 값을 실험의 확정 전제로 사용하지 않는다.

## 적용 범위

이 문서는 운영 지침이다. 문서 작성만으로 실행 엔진의 통과 조건이나 에이전트 프롬프트가 자동 변경되지는 않는다. 기존 검증·승인 요건과 충돌하면 차이를 명시하고 구현 변경을 별도 검토한다. 상태를 우회하거나 열린 문제를 해소했다고 기록하지 않는다.
