# 연구 에이전트 가이드

필수 운영 기준: [에이전트 표준 절차](../prompts/m1/protocol.md). 모든 연구 과업은 목적·페르소나·이전 자료·검수 조건을 담은 [작업 패킷](../prompts/m1/task-packet.md)으로 배정한다. 누락된 핵심 근거나 검토를 채운 것으로 가정하지 않는다. 초안 보존과 최종 채택은 구분한다.


## 목적에 따라 역할과 질문 구성

M1-1 연구 설계, M1-2 조사·평가, M1-3 계획 수립은 같은 공통 규칙을 사용하되 요구하는 자료·이론·해석·결과가 다르다. [목적별 프롬프트](../prompts/m1/README.md)의 목적 카드와 경로별 요구를 먼저 적용한다. 아래 소재·실험 중심 역할 표는 연구 경로의 예시이며 모든 업무에 강제하지 않는다.

## 맡은 역할과 공통 책임

| 역할 | 중심 질문 |
| --- | --- |
| 자료 탐색 담당 | 관련 자료를 찾았는가? 출처와 실제로 읽은 범위는 무엇인가? |
| 소재·분야 전문가 | 자료가 주장과 연결되는가? 다른 물리적 설명도 가능한가? |
| 평가 방법 검토자 | 비교가 공정한가? 같은 원자료의 재사용이나 측정 조건 차이가 결론을 바꾸는가? |
| 실험·실행 검토자 | 실제로 측정할 수 있는가? 실패·비용·사람 개입을 어떻게 기록할 것인가? |
| 판단 정리 담당 | 무엇에 동의했고 무엇은 남았는가? 다음 확인은 어떤 판단을 바꾸는가? |

책임의 구분이며 역할 수만큼 별도 에이전트가 구현됐다는 뜻은 아니다. 판단 정리 담당은 다수결로 과학적 사실을 결정하지 않는다.

## 자료를 찾고 확인하는 방법

1. 확인할 연구 질문과 이 자료가 필요한 이유를 먼저 쓴다.
2. 출처·버전·위치를 기록하고 제목만 확인, 초록 확인, 본문 일부 확인, 필요한 본문 확인을 구분한다.
3. 원문이 말하는 내용, 다른 사람이 제공한 해석, 자신의 추론을 구분한다. 접근하지 못한 내용을 읽었다고 하지 않는다.
4. 자료를 찾은 사실과 사용할 수 있다는 판단을 따로 기록한다. 사용 판단 전에도 수집 기록은 남긴다.
5. 문제를 발견하면 영향을 받는 값·주장·작업을 특정한다. 자동으로 자료 전체나 연구 전체를 무효로 만들지 않는다.

각 자료·주장은 다음 중 하나로 정리한다.

- **사용:** 현재 주장에 필요한 근거가 확인됨. 허용되는 주장 범위를 적는다.
- **조건부 사용:** 한계를 적으면 특정 용도로 사용 가능함. 허용/금지 용도를 함께 적는다.
- **보류:** 핵심 출처나 의미가 불명확하여 해당 용도로 사용할 수 없음. 다시 판단할 조건을 적는다.
- **제외:** 관련성·품질 등 명시한 기준에 맞지 않음. 이유를 남기고 원본은 보존한다.

이 분류는 운영상의 판단이며 시스템의 정식 승인·검증 상태를 대신하지 않는다.

## 추가 확인을 제안하는 기준

추가 조사마다 다음 네 가지에 답한다.

- 무엇을 모르는가?
- 답이 달라지면 어떤 사용 판단이나 연구 방향이 달라지는가?
- 어떤 출처·관측으로 확인할 수 있는가?
- 확인되거나 끝내 확인되지 않을 때 각각 어떻게 처리할 것인가?

현재 판단을 바꾸지 않는 주변 조사는 후속 목록으로 남긴다. 출처가 막히거나 동일한 증거만 반복되면 같은 조회를 계속하지 않는다. 새 접근 경로가 있으면 시도하고, 없으면 범위를 좁힌 조건부 사용 또는 보류를 제안한다. 임의의 시간·문헌 수로 실행을 강제 종료하지 않는다. 합의된 자원 한계에 도달하면 결과와 재개 지점을 보존한다.

## 독립 판단과 토론

- 첫 의견은 같은 입력을 바탕으로 독립적으로 작성한다. 먼저 상대 의견을 읽었다면 독립 판단으로 표시하지 않는다.
- 반박에서는 상대의 구체적인 주장 하나와 그 근거를 짚는다. 사람이 읽을 수 있는 역할명과 주장으로 설명한다.
- 입장을 바꿀 때 새 근거 또는 논리적 오류를 명시한다. 의견이 일치했다는 사실은 새 실증 근거가 아니다.
- 강제 합의를 하지 않는다. 정보 부족과 근거가 같아도 남는 판단 차이를 구분한다.
- 확신도 숫자를 합의 기준으로 삼지 않는다. 여러 모델 사용도 독립성과 정확성의 보증으로 삼지 않는다.
- 기존 쟁점과 같으면 그 쟁점에 근거를 추가한다. 같은 문제를 표현만 바꾸어 재등록하지 않는다.

## 사람이 이해할 수 있는 발언

첫 문장에 판단을 쓴다. 가설 번호만 쓰지 말고 뜻을 붙인다. 다음 네 부분을 각각 짧은 문단으로 작성한다.

**내 판단:** 무엇은 진행하고 무엇은 보류하는가?

**그 이유:** 확인한 근거와 아직 모르는 사실은 무엇인가?

**다른 의견에 대한 답:** 누구의 어떤 의견에 동의·반대하거나 내 판단을 수정하는가? 첫 회차라면 아직 다른 의견을 읽기 전이라고 쓴다.

**다음 할 일:** 어떤 자료의 무엇을 확인하며, 어떤 결과면 다음으로 갈 수 있는가?

“expt 독립성 미확정” 대신 “같은 연구팀의 자료가 학습용과 평가용에 함께 들어갈 수 있습니다”처럼 쓴다. 전문 용어가 꼭 필요하면 처음에 뜻을 풀어 쓴다. 내부 ID·해시·전체 출처 목록은 별도 근거 연결에 둔다. 짧게 쓰더라도 결론을 바꾸는 한계는 생략하지 않는다.

## 단계별 판단

M1에서 기존 자료의 의미·적합성을 판단한다. 확인하지 못한 자료는 사용 범위를 제한하거나 보류하고, 그 결과 가설 자체도 보류해야 하는지 판단한다. M2로 넘기는 것은 새 실험으로 검증할 질문이며 불명확한 값을 확정 사실로 넘기지 않는다.

M2에서는 실패·미도달·재시도와 사람의 기여도 포함하여 결과를 해석한다. M3에서는 실제 확보한 근거 범위 안에서 결론을 쓰고 미해결 사항을 보존한다.
