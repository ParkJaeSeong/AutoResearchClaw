# 프로젝트 화면과 보관 기준

Pilot은 프로젝트를 먼저 선택하고, 그 안에서 마일스톤과 연구 단계를 탐색한다. 연구 단계와 실제 수행 순서는 별개다. 자료가 부족해 같은 단계로 돌아가면 기존 단계를 복제하지 않고 새 수행 회차를 기록한다.

M1은 연구 질문과 범위, 자료 탐색과 검토, 근거 종합과 가설, 실험 설계, 착수 준비와 최종 정리로 묶어 보여준다. 묶음은 탐색 메뉴이며, 기존 연구 기록의 단계 ID나 완료 상태를 바꾸지 않는다. M2·M3 메뉴는 범위를 안내하며 아직 실행 기능을 제공하지 않는다.

## 새 프로젝트

`research view ROOT --workspace WORKSPACE`로 프로젝트 목록을 사용한다. 새 프로젝트는 `WORKSPACE/projects/` 아래 고유 ID를 기준으로 별도 폴더를 만든다. 이름이나 주제가 같아도 연구 기록을 합치지 않는다.

| 위치 | 보관 내용 |
| --- | --- |
| `project.json` | 프로젝트 표시 정보 |
| `documents/` | 연구 설명과 검토 문서 |
| `materials/` | 공개할 원문·입력 자료 |
| `outputs/M1/`, `M2/`, `M3/` | 마일스톤별 산출물 |
| `runs/` | 실행 과정의 작업 파일 |
| `.researchclaw/` | 버전·판단·대화·근거 연결의 원기록 |
| `.atlas-link/` | 해당 프로젝트의 Atlas 연결 기록(연결 후 생성) |

화면의 자료 목록은 `documents`, `materials`, `outputs`에 한정한다. 내부 기록·연결 설정·실행 로그를 일반 파일 다운로드로 노출하지 않는다. 자료 폴더에는 사용자에게 공개해도 되는 파일만 넣는다. 새 프로젝트를 만드는 것만으로 자료 수집이나 Atlas 요청을 실행하지 않는다.

## 기존 연구

기존 프로젝트는 원래 경로를 목록에 등록한다. 해시로 연결된 기록과 Atlas 응답을 이동하거나 다시 쓰지 않는다. 기존 경로를 사용하는 CLI도 계속 사용할 수 있다.

현재 운영 목록은 저장소 작업 폴더의 `workspaces/pilot/`에 둔다. 새 프로젝트는 그 아래 `projects/`에 저장한다. 기존 고분자 복합재 연구는 `.superpowers/research/2026-09-10-polymer-sdl/project/`에 연결한다. 두 위치는 Git 작업물과 별도로 백업한다.

```sh
.venv/bin/python -m researchclaw.codex.cli research view \
  .superpowers/research/2026-09-10-polymer-sdl/project \
  --workspace workspaces/pilot --port 8771
```

고분자 복합재 사례의 공개 산출물은 원본 해시를 확인한 사본으로 프로젝트의 `outputs/M1/legacy-bundle/`에 모은다. 이 사본은 당시 기록을 찾아보기 위한 것이다. 과거의 POC 마무리 문서가 현재 연구 주제의 적합성이나 실제 실험 준비 완료를 새로 증명하지는 않는다. 원본 위치와 사본의 대응은 함께 저장한 `index.json`에 남긴다.

## 프로젝트 전환

조회·검토·Atlas 요청·다운로드는 선택한 프로젝트 ID를 함께 보낸다. 서버 전체의 현재 프로젝트를 바꾸는 방식은 사용하지 않는다. 여러 브라우저 탭에서 서로 다른 프로젝트를 열어도 각 요청은 자신의 프로젝트에 연결된다.

프로젝트를 바꿀 때 이전 화면의 응답이 새 프로젝트에 들어오지 않도록 페이지를 전환한다. 프로젝트별 선택과 입력은 구분해서 보관한다. 새 연구는 기존 연구의 승인·결론·Atlas 연결을 상속하지 않는다.

백업할 때는 프로젝트 폴더와 작업 공간 목록을 함께 보관한다. 기존 경로에 연결된 프로젝트는 그 원본 폴더도 별도로 포함해야 한다. 공개 산출물 사본만으로 연구 이력을 복구할 수는 없다.

## 보관한 프로젝트

완료되었거나 새 질문으로 대체한 연구는 catalog.json 항목의 archived 표시로 보관한다. Workspace.set_archived(project_id, True/False)로 목록 분류를 변경하고 복원할 수 있다. 연구 루트·원형 파일·HEAD·Atlas 연결을 이동하거나 삭제하지 않는다. 보관은 읽기 전용 잠금이나 별도 백업이 아니며 명시적인 기존 프로젝트 접근은 유지한다.

기본 프로젝트 선택에는 활성 프로젝트를 표시하고 보관한 프로젝트는 접힌 목록에서 연다. 보관한 프로젝트 URL은 계속 열 수 있고, 표시 이름에 보관 상태가 붙는다. 프로젝트 ID 없는 첫 진입은 활성 프로젝트를 우선한다. 서버의 기존 무지정 API 기본 루트는 유지되므로 도구 요청에는 항상 프로젝트 ID를 명시한다.

2026-09-17 기존 고분자 복합재 POC를 원래 위치에 보관하고 PC/CNT 혼련 조건과 전기전도도 테스트를 별도 프로젝트로 생성했다. 이전 결론·가설·완료 상태·Atlas 연결은 상속하지 않는다. 재사용할 문헌은 별도 적합성 검토 후 고정 참조로 연결한다. 목록 변경 전 사본과 파일 보존 확인은 workspaces/pilot/archives/2026-09-17-polymer-poc/에 보관한다.
