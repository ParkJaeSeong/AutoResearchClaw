# 문헌 탐색 재시작

사용자 승인: 문헌 탐색 제한을 수정하고 같은 주제로 다시 시작한다.
기존 scope/questions와 5편의 기록은 보존한다. 5편은 최종 corpus가 아니다.

최신 수정: 역할당 600초 강제 종료를 제거했다. `restart-01`에서 완료된 보고서
4개(후보 123건)를 재사용하고, `restart-02`에서 미완료인 2회차 소재·방법론만
재개한다. 각 역할의 기존 웹 호출 9건은 재개 단서로 전달한다. 이전 세션은
ephemeral이었으므로 원문 내용·모델 문맥의 완전한 복구는 보장하지 않는다.
앞으로는 ephemeral을 사용하지 않고 세션과 작업 디렉터리도 보존한다.

이전 실행 중간 확인(2026-09-10 11:03 KST): 독립 탐색 1회차 보고 3개가 끝나고 2회차가
자동 시작됐다. 소재 46건·방법론 33건·SDL/반증 45건, DOI/URL 일치 기준으로
합친 후보 115건이다. 논문·데이터·저장소가 섞인 후보 레코드 수이며, 출판물
수의 완전한 중복 제거 또는 전문 정독 수가 아니다. 실제 검색식은 역할별
21개·16개·20개다. 검색어 연결 1건은 도구 기록과 일치하지 않아 미확인으로
남겼다. 상세 시점별 수치는 `.superpowers/research/2026-09-10-polymer-sdl/discovery-audit.json`에 기록했다.

## 이전 실행이 중간에 끝난 이유

`start_scope.py`, `review_questions.py`, `review_search.py`, `review_screen.py`는
각각 한 노드와 그 협의만 실행하고 종료한다. M1 전체 실행기가 아니다.
UI의 01–09는 내부 노드 번호이고, `ready`는 그 노드의 검토 조건 충족이다.
`complete`는 협의의 필수 제출 완료다. 어느 쪽도 전체 연구 완료가 아니다.
화면은 읽기 전용이므로 다음 에이전트를 자동으로 실행하지 않는다.

조정자가 매 노드마다 대화를 끝낸 것은 이 개별 실행 방식을 사용했기 때문이다.
실제 corpus 승인 같은 정책 조건과, 조정자의 임의 단계별 중단을 구분해야 한다.

## 변경한 실행 방식

`researchclaw.codex.literature_loop`는 다음을 한 번의 실행으로 이어간다.

1. 소재·방법론·SDL/반증 역할의 독립 웹 탐색.
2. 같은 이전 회차를 세 역할에 공개하고 출처·반례·누락을 교차 확인.
3. 근거가 부족하면 다음 회차에서 직접 재검색.
4. 후보 검토 상태 또는 예산 도달과 미해결 쟁점을 기록.

실시간 웹 검색을 설정하고 실제 CLI 웹 호출을 검사한다. 웹 호출 기록은 실행의
증거이며 논문별 해석을 독립 검증했다는 증거는 아니다. 읽은 범위는 역할의
선언으로 보존한다. 원문을 못 읽은 후보도 접근 실패와 함께 남긴다.
DOI 기준 중복을 합쳐도 역할별 읽은 범위·해석 차이는 삭제하지 않는다.
초기 입력에서 동료 의견은 제외한다. 격리는 여전히 instructions_only다.

첫 실행의 600초 제한은 작업을 중단시켰으며 제거했다. 현재는 30초마다 활동
상태를 관찰할 뿐 시간 경과로 프로세스를 종료하지 않는다. `activity.json`에
PID·로그 크기·최근 출력 시점을 기록한다. 자동 정체 판정이나 재시작은 하지 않는다.
호스트의 비정상 종료는 실패로 기록하고 성공한 다른 역할의 결과를 즉시 보존한다.
기존 최대 3회차는 회차가 끝난 뒤 다음 탐색 여부를 점검하는 지점으로 유지하며,
진행 중인 역할을 끊지 않는다. 회차 예산 종료도 충분성이나 M1 완료는 아니다.
같은 출력 디렉터리를 덮어쓰지 않는다.

## 실행과 확인

```sh
.venv/bin/python -m researchclaw.codex.literature_loop \
  --host /Users/jspark/.local/bin/codex \
  --output .superpowers/research/2026-09-10-polymer-sdl/discovery-runs/restart-02 \
  --resume-from .superpowers/research/2026-09-10-polymer-sdl/discovery-runs/restart-01 \
  --topic '고분자 복합소재 물성 예측을 위한 가설 검증형 자율 연구 에이전트와 셀프 드라이빙 랩 설계'
```

출력: `status.json`, `reports.json`, `sources.json`, 역할·회차별 실제
`events.jsonl`, `report.json`. 검색엔진 전체 결과 건수는 추정하지 않는다.
검색어·수집 후보·중복 제거 수를 구분한다. 큰 실행 원문은 Git에서 제외한다.
재사용 보고서는 새 `reports.json`에 집계되고 원본 파일은 이전 실행에 보존한다.
원본이 있는 이전 폴더와 새 폴더를 함께 보관해야 한다. 재개는 완료된 결과와
본인 검색 단서를 재사용한 새 호스트 호출이며, 과거 모델 내부 문맥을 복원했다는
주장은 아니다. 새 출력 경로가 이미 있으면 다시 실행하지 말고 다른 경로를 지정한다.

기존 frozen-evidence council은 등록 자료의 협의용으로 유지한다. 탐색은 이 새
실행 경로가 담당하며, 결과를 후속 native 검색/선정 개정에 연결한다. 새 탐색
로그가 저장됐다는 이유로 과거 5편의 승인이나 원문 검증을 생성하지 않는다.
전체 M1의 수집·추출·가설·검증·인계 자동 실행은 이 탐색 실행기와 별개다.
기존 native 검색/선정 기록에는 첫5편을 보존한다. 현재 같은 UI 상단의 문헌 탐색
패널에서 restart-02의 후보197건·관찰245건·완료보고9개와 선정·가설 초안을
확인할 수 있다. 3회차를 모두 마쳤으며 상태는 budget_reached_with_gaps다.
현재 탐색 에이전트는 실행 중이 아니다. 시간 제한으로 중단된 상태도 아니다.
탐색 패널은 별도 API로 자동 갱신되며, 과거 기록 고정 시 최신 탐색은 숨긴다.
후속 native 개정과 실제 corpus 승인은 별도이며 아직 생성하지 않았다.
