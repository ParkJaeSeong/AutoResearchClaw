# 원문을 읽고 질문·답변으로 자료 사용 범위 정하기

이번 질문은 **현재 확보한 PC/CNT 데이터로 공정·측정 조건의 영향을 비교할 수 있는가?** 이다. ResearchAtlas 연결은 미루고, 기존 원문과 공개 데이터를 실제 연구원 입력으로 전달했다.

## 전달한 자료와 대화 방식

| 전달 자료 | 범위 |
| --- | --- |
| S1 | 가공 CSV에서 PC/CNT에 해당하는 137행의 선택 열 |
| S2 | Abbasi 2010에 대응하는 상세 CSV 25행의 선택 열 |
| S3 | 논문 PDF 3·4·12쪽의 제조·측정 방법과 그림 12 주변 본문 |
| S4 | 데이터 제공자 저장소 README 전체 |
| S5 | 공개 그룹 생성 노트북 전체 셀의 코드 |

CSV 행 번호는 헤더를 제외한 데이터 레코드 순서다. 인용 줄 번호는 S1–S5 전달 텍스트 기준이다. 원본 5개와 전체 PDF 추출 텍스트도 각 연구원의 읽기 공간에 제공했다. 원본 해시를 확인했고, 열 선택·텍스트 추출과 조정자의 해석을 구분했다. 추가 등록된 5개 파일은 이 자료의 발췌본이며 새 논문 5편이 아니다.

소재·측정 전문가, 비교·평가 전문가, 반증 검토자가 같은 자료로 독립 의견을 쓴 뒤 서로의 질문에 답한다. 상대 의견은 해당 회차 전원이 제출한 뒤 공개한다. 각 주장은 관측/해석을 구분하고, 답변까지 출처·줄·직접 인용을 남긴다. 원문에 없는 인용이나 배정 질문 누락은 등록 전에 거부한다. 이 검사는 인용문이 실제로 존재하는지 확인하며, 주장의 과학적 타당성을 자동 보증하지 않는다.

## 교차 검토에서 달라진 내용

- 인장시험 시편의 중앙 구간 치수를 곧바로 전기 측정 구간으로 부르면 안 된다는 점을 명확히 했다.
- 일부 시료의 100 V 설명을 고함량 시료에 사용한 교체 장비의 조건으로 확대하지 않았다.
- 제조한 함량 목록과 그림에 실제 표시된 측정점을 구분했다. 전달 본문을 읽은 연구원들은 그림의 모든 점을 직접 재판독했다고 주장하지 않았다.
- 마스터배치를 희석할 때 CNT 함량과 함께 PC 공급원 비율도 달라진다는 경쟁 설명을 추가했다. 같은 함량 안에서의 제조·형상 비교와 함량 증가 자체의 효과를 구분한다.

## 조정자의 자료 사용 방침

| 용도 | 현재 방침 | 다음에 필요한 것 |
| --- | --- | --- |
| Abbasi 안에서 동일 함량의 제조·형상 조합 비교 | CSV 기준 잠정적인 차이·순서를 설명하는 자료로 유지 | 정량값을 확정할 때 그림의 점·계열·판독 오차 확인 |
| 두께·공정·측정법 각각의 독립 효과 | 보류 | 함께 변하는 형상·열이력·전극 배치 등을 분리하는 대조 설계 |
| 1.2 mm를 최종 시편 두께로 사용 | 보류; 원래 값을 덮어쓰지 않음 | 최종 금형 치수 또는 시편 실측 기록 |
| PC/CNT 전체 137행을 통합해 효과·예측 성능 평가 | 보류 | 단위·온도 출처·동일 시료의 복수 값·문헌 의존성 확인 |

조정자도 25행의 상세 전도도와 가공 log10 값의 수치 대응을 재확인했다(최대 절대 차이 약 1.8×10⁻¹⁵). 두 파일이 일치한다는 사실은 원문 추출 정확도나 단위 환산이 옳다는 증거가 아니다. 원본은 수정하지 않았다.

조정자는 PDF 12쪽의 그림 12를 직접 확인했고, [기존 그림 대조 기록](abbasi-figure-review.md)의 다섯 계열과 추가 함량점 표시를 재확인했다. 이는 연구원의 독해 범위와 구분한다. 기존의 육안 대조를 반복하는 대신, 다음 원문 확인은 **정량 비교에 사용할 점의 좌표·축·계열과 판독 오차를 기록하는 작업**으로 좁힌다. 확인되지 않는 값은 잠정값으로 남기며, 이것 때문에 연구 질문·대조 설계까지 멈추지 않는다.

원문 출처: [Abbasi 논문 공개본](https://nrc-publications.canada.ca/eng/view/accepted/?id=a3d207d2-7f7c-4576-b46b-57a9a213c1c7), [데이터 제공자 저장소의 고정 버전](https://github.com/shimakawa-hvg/expt-group-partitioning/tree/93d74c135d63183a22a6eb88eb31be24892d7959).

## 실행 기록

세 단계(독립 의견 → 질문·답변 → 재판단)에서 각 역할 3회, 총 9개 정식 발언을 등록했다. 첫 질문 6개와 후속 질문 3개 모두 답변을 받았다. 답변 4개는 미해결로 표시됐으며 과학적 의문을 해결한 것으로 세지 않는다. 세 최종 의견은 모두 `limited_use`다. [실행·검사 기록](source-analysis-receipt.json)에 호스트, 정식 제출, 출처와 질문별 처리 상태를 연결했다.

기존 제출까지 합쳐 정식 협의 발언은 81개다. 기존 쟁점 22개는 그대로 남아 있으며, 이번 협의는 자료의 용도에 대한 의견이다. 자료 사용 승인·단계 완료·모델 학습·실험 수행을 대신하지 않는다. M1은 아직 완료되지 않았다.

정식 협의: `e76508e1-bb1f-47c2-aa08-fe3023a91700` (`source_analysis`). 원응답·도구 기록·수정 전후 응답은 `.superpowers/research/2026-09-10-polymer-sdl/source-analysis-01/`에 보존한다. 재실행은 저장된 유효 응답을 재사용한다. 첫 반증 응답의 PDF 두 단을 이어 붙인 인용은 새 호스트가 수정했으며, 최초 응답도 남아 있다.

UI의 **원문을 함께 읽고 검토 → 원문 근거와 질문·답변 보기**에서 정식 발언과 근거를 볼 수 있다. 호스트는 실제 Codex 실행이지만 정확한 기본 모델과 강제 격리 여부는 확인하지 않았고, 다른 모델들을 사용한 것으로 표시하지 않는다.

## 구현·화면 확인

- Python 관련 검사 35개, UI 검사 21개 통과. 코드 검토에서 발견한 답변 인용 누락과 질문 형식 오류의 재개 문제를 수정하고 회귀 검사했다.
- 실제 API에서 3/3·3/3·3/3 제출, 원응답과 정식 발언의 일치, 전달 원문 5개 링크의 바이트 일치를 확인했다.
- 크롬에서 새 검토 영역, 세 단계 대화, 미해결 답변과 인용 위치, 파일명으로 표시되는 근거 링크를 확인했다. 실제 화면의 긴 본문과 어두운 테마를 확인했으며, 이번 변경에서 세 화면 폭·두 테마 전체 조합을 재검수하지는 않았다.
- 완료 후 재실행에서도 기존 호스트 기록 10개와 정식 HEAD가 바뀌지 않음을 확인했다. 유효 응답을 다시 생성하지 않았다.
- 개발과 실제 자료 검토를 구분한다. 기존 9개 노드의 단계 진행·사용 승인 조건과 M2/M3 구현 범위는 이번 변경으로 확장되지 않았다.
