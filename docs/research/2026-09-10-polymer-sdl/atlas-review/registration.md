# Atlas 답변과 연구 판단 연결

2026-09-12. [Atlas 답변](atlas-qa.md)을 Pilot 외부 근거로 등록하고, 사용 범위 판단 → 조정자 결정 → 추가 질문 초안을 연결했다. [등록 영수증](registration-receipt.json)에 각 기록 ID와 전후 HEAD를 보존한다.

- 답변 1건: Abbasi의 제조·배향·전도도 해석 범위. 참조 위키 2페이지와 추가 후보 3건이며 독립 문헌 수로 합산하지 않는다.
- 사용 판단 1건: 동일 배합의 제조 조건 비교 설계에 사용. 배향만의 인과 효과·정량 처방·UTM 물성 전이는 보류.
- 결정 1건: [기존 조정자 결론](decision.md)에 따라 M0/M1 두 조건에서 전류 경로 D0와 접촉 P0를 공통으로 설계한다.
- 추가 질문 1건: Abbasi의 전극 배치·전류 경로·유동 방향 관계를 확인하는 초안. Atlas로 전송하지 않았다.

이전 실제 협업 원응답 9개는 그대로 보존했다. 이번 결정은 런타임에 **조정자 단독 기록**으로 등록했으며 이전 발언을 native council로 재작성하지 않았다. 원문의 직접 재독이나 새 실험도 하지 않았다.

[연구 화면](http://127.0.0.1:8768/)의 **Atlas 답변 가져오기**에서 원문, 사용 판단, 결정 이유, 추가 질문을 연결해 볼 수 있다. [사용법](../../guides/atlas-file-evidence.md)

기존 상태의 모든 필드는 등록 전후 동일함을 확인했다. 기존 쟁점·승인·M1 노드·108개 native 제출은 변경하지 않았다. 외부 근거 경로와 M1의 종합·가설·완료 조건 통합은 다음 개발 단위다. 6단계 및 M1 전체가 완료된 것은 아니다.
