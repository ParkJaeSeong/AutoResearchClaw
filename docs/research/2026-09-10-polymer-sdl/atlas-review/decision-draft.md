# 조정자 결정안 — 최종 역할 검토 입력

이 문서는 1·2차 실제 의견을 종합한 최종 검토 입력이다. 원응답을 대신하지 않는다.

1. 최소 비교는 동일 배합·대응 형상/위치, 공통 시편 좌표 전류 경로 D0와 접촉 P0에서 제조 두 조건 M0/M1(E01/E02)이다. 조합 수는 독립 반복 수가 아니다. 실제 조건값·장비·시편 수는 미정이다. 전도도 증가/감소를 선결하지 않는다.
2. 단일 설정을 의도적으로 바꾸고 냉각 등 실제 이력이 따라 변하면 그 설정 변경의 전체 효과를 질문할 수 있다. 여러 설정을 함께 조작하면 공정 묶음의 효과다. 배정·날짜·배치가 얽힌 경우 원인 효과로 확정하지 않는다. 배향은 미측정 설명으로 남긴다.
3. 국소 유동이 미상이더라도 대응하는 시편 좌표·위치·치수·전극과 경로를 알면 해당 경로 비교는 가능하다. 유동 평행/수직이나 배향 효과라고 부르지 않는다. 경로·치수·환산 적합성 자체가 없으면 정량 판정은 보류한다.
4. 접촉 기여 질문을 채택할 때만 E03/E04를 함께 추가한다. 과거 P0와 새로운 날짜/배치의 P1을 단순 결합하지 않는다. 비교 가능한 상태/일정을 확보하거나 네 조합을 새로 설계한다. E05/E06 방향 대비와 Raman은 별도 후속 질문이다. 표면 차이는 자동 제외가 아니며 공통 P0에도 접촉 기여가 남을 수 있다.
5. 효과 Δ와 구간 [L,U], 사전 의미 차이 δ를 둔다. 구간 전체가 [-δ,δ] 안이면 해당 조건의 작은 차이, L>δ 또는 U<−δ이면 의미 차이, 나머지는 의미 차이 판단 불가. 척도·δ·구간법·신뢰 수준·독립 실행 변동과 반복 수는 실행 전에 정한다. 지금 수치나 실험값을 만들지 않는다. 부적합/한계 이하 자료의 임의 환산이나 숫자 대체는 하지 않는다.
6. 실제 조건 배정·전환·안정화·잔류·채취 경계로 성형 실행을 정의하며 run ID만으로 독립성을 선언하지 않는다. 배치/날짜 공유와 실행 내 시편/재접촉/읽기의 의존성을 유지한다.
7. 기존 tasks/specimens/conditions/results CSV를 유지한다. 결과 한 행은 시도의 지표 한 개. 별도 실행 경계·도면·방법·조건 사전과 시도별 조건 적용 범위 연결이 필요하다. 오기 정정과 재시도를 구별한다. 이는 설계이며 자동 수신기/검증 구현이 아니다.
8. Atlas 질답·원문 참조·버전·해시를 공통 입력으로 유지한다. 후보 3건은 위키 반영 전이고 원문 재독·다문헌 교차 검증을 수행한 것은 아니다. Atlas 수집을 중복하지 않는다.
9. 현재 결과는 가상 실험 설계의 판단이다. 실제 실험·H2 선택법 성능·전체 M1 완료·native council 통과가 아니다. 기존 22개 연구 이슈나 승인 상태를 변경하지 않는다. Atlas 외부 근거의 정식 등록 연결은 다음 개발 과제로 남긴다.

최종 역할 검토에서는 채택 가능한 항목, 반드시 고칠 항목, 남은 과학적/실행 미확인과 그 보류 범위를 구분한다. 다수결로 사실을 확정하지 않는다.
