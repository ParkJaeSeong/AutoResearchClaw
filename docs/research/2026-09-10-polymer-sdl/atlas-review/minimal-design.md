# 제조 두 조건으로 시작하는 가상 실험 설계

**설계 v0.2. 실제 장비 설정·반복 수·실험값은 아직 없다.** 이번 범위는 제조 조건에 따른 전도도 비교다. [조정자 결론](decision.md)과 [원응답](README.md)에 판단 근거를 연결한다. v0.1의 제조·접촉 네 조합을 모든 비교의 최소로 삼던 부분을 이번 질문에 맞춰 좁혔다. 기존 후속 비교는 폐기하지 않았다.

## 비교와 설명을 구분한다

| 항목 | 이번 결정 |
| --- | --- |
| 연구 질문 | 동일 배합에서 지정 제조 조건 두 수준에 따른 전도도 차이는 어느 정도인가? |
| 최소 조건 조합 | E01: M0·D0·P0, E02: M1·D0·P0. 이것은 시편 수나 반복 수가 아니다. |
| 제조 M0/M1 | 가능하면 같은 장비·금형의 한 설정을 조작. 구체 설정값은 미정. 여러 설정을 함께 조작하면 공정 묶음 비교. |
| 실제 이력 | 조작값과 실제 온도·압력·냉각·건조 이력을 별도로 기록. 조작의 결과로 따라 변한 이력과 날짜·배치 등 외부 요인을 구분. |
| 방향 D0 | 도면의 시편 좌표와 대응 전류 경로. 유동 관계가 미상이면 그대로 남기고 ‘유동 평행’이라고 명명하지 않음. |
| 접촉 P0 | 두 조건에 적합한 공통 절차와 버전. 공통 절차만으로 접촉 기여를 배제하지 않음. |
| 주장 범위 | 배정·실행 조건이 성립하면 지정 제조 대비의 효과를 추정. 배향만의 인과 효과나 접촉 독립 물성으로 확대하지 않음. |
| 기계적 물성 | UTM 평가를 후속 별도 지표로 유지. 용융 G′를 인장탄성률·강도에 대입하지 않음. |

배향·연결망 변화, 다른 공정 변화, 접촉 기여는 가능한 설명으로 보존한다. 이번 두 조합은 이 설명들 중 하나를 고르는 실험이 아니다. 전도도 차이가 없더라도 배향 변화 자체가 없었다는 결론은 내리지 않는다.

## 배정과 판정

원료·배합 배치 안에서 두 제조 조건을 비교하도록 배정하고 순서·날짜가 한 조건에 몰리지 않게 한다. 실행의 시작·종료, 설정 전환 후 안정화, 이전 조건의 잔류, 채취 구간을 정의한다. ID를 새로 발급했다는 이유만으로 독립 반복으로 세지 않는다. 공통 배치·날짜, 실행 내 시편·재접촉·반복 읽기의 의존성을 분석에 유지한다.

실행 경계와 잔류 처리 근거가 미확정이면 독립 제조 반복 수와 확증 판정을 보류한다. 기록 항목을 채웠다고 완전한 독립성이 자동으로 증명되지는 않는다.

주 척도를 사전 지정하고 제조 대비 Δ와 불확실성 구간 [L,U]를 보고한다. δ는 사용 목적에 따른 의미 차이이며 결과를 보기 전에 근거와 함께 정한다.

δ>0는 지정 척도에서 무시할 수 있는 차이의 경계다. 작은 차이는 정확히 0이라는 뜻이 아니다. 구간의 0 배제와 의미 차이 경계 초과는 별개이며, 구간법과 대응 검정 규칙을 정하기 전에는 이 분류를 통계적 유의성 판정으로 바꾸지 않는다.

| 결과 | 허용 판단 |
| --- | --- |
| [L,U] 전체가 [-δ,δ] 안 | 해당 조건에서 작은 차이 확인 |
| L>δ 또는 U<−δ | 해당 방향의 의미 있는 차이 지지 |
| 그 외 | 의미 차이인지 작은 차이인지 판단 불가. 유의하지 않음을 차이 없음으로 바꾸지 않음. |
| 단위·환산·범위 부적합으로 유효 구간 불가 | 해당 정량 판단 보류. 한계 이하 값을 임의 수치로 채우지 않음. |

주 척도·δ·구간 산출법·신뢰 수준·독립 실행 변동·목표 정밀도·반복 수·한계값 처리법은 정량 실행 전에 확정한다. 지금 정한 것은 판정 구조이며 수치 기준이 아니다.

## 질문에 따라 확장한다

- 접촉 기여를 물으면 두 제조 조건 모두에 P1을 추가해 E01–E04를 비교한다. 접촉별 제조 차이 Δ0·Δ1와 Δ1−Δ0를 함께 추정한다. 다른 날짜·배치에서 얻은 P1을 이전 P0에 단순 결합하지 않는다. 비가역 손상이 있으면 적합한 대응 시편과 공통 일정으로 재설계한다.
- 방향 의존성을 물으면 실제 구현 가능한 D1에서 E05·E06을 추가한다. 시편 회전 자체가 전류 경로 변경을 보증하지 않는다.
- 배향 설명을 물으면 별도 관측의 접근성·감도·깊이·위치 대표성을 확인한다. Raman은 미확인 후보이며 최소 두 조합의 필수 장비가 아니다. Raman 편광 방향과 전류 방향은 별개다.
- PC 구성 효과는 독립 배합이 가능한지 확인한 뒤 별도 비교한다. H2 실험 선택법의 효율성 검증도 별도 연구 설계다.

## 기존 CSV와 연결할 명세

[기존 네 CSV](../virtual-lab/README.md)를 재사용한다. 자동 가져오기·검증 기능은 이번 작업에서 구현하지 않았다.

| 파일 | 유지할 역할 | 추가로 정의할 연결 |
| --- | --- | --- |
| tasks.csv | 계획·작업·입출력 배치·장비·작업자 | 성형 작업과 실제 조건 배정·실행 경계의 대응 |
| specimens.csv | 시편·제조 배치·채취 위치 | 도면 좌표·대응 영역·최종 형상 |
| conditions.csv | 조건명·계획값·실제값·단위·미상 상태 | 조건 사전, 방법 버전, 각 조건이 적용되는 작업·시편·시도 범위 |
| results.csv | 한 시도의 지표 한 행, 방법·방향·접촉 회차·품질·원자료 | 원자료 해시, 시도별 실제 조건 연결. 오기 정정과 재시도 부모는 구분. |

현재 열만으로 모든 연결을 기계적으로 표현할 수 있다는 뜻은 아니다. 시도별 조건, 실행 경계, 시간·순서·재시도·비용·상태 이력은 후속 실행 계약에서 보완한다. 합성 CSV는 파일 흐름 시험용이며 물리 시뮬레이션이나 실측 결과가 아니다.
