# 이번 검토의 공통 입력과 범위

사용자는 Atlas 질답으로 가설·대안 설명·최소 가상 실험 설계를 교차 검토하는 일을 승인했다. 실제 실험이나 모델 학습은 하지 않는다. 장비는 가상으로 두고 CSV 전달을 설계한다. 실제 보유 장비는 수동 압출기·사출기·UTM·전기 전도도 측정 장비이며, Raman 보유나 사용 가능은 확인되지 않았다.

Atlas가 자료 수집·추출·위키를 담당한다. Pilot은 자료를 다시 수집하지 않고 제공된 질답과 원문 위치·버전·한계를 소비한다. atlas-qa.md는 동결된 실제 답변이며 새 후보 3건은 정식 위키 반영 전이다. project 연결은 null이다. 원문을 직접 읽은 것처럼 쓰지 않는다. 여러 의견은 독립 논문 근거가 아니다.

이번 결정: 이전의 제조·접촉·방향·Raman 설계에서 지금 가장 작은 비교를 무엇으로 둘 것인가? 핵심 질문은 동일 배합에서 성형 조건에 따른 전도도 차이이며 배향은 미측정 설명이다. 최소 조건 조합과 후속 선택 비교를 구분한다. 배향이 실측 불가라는 이유로 모든 제조 비교를 막지 않는다. 근거 없는 수치·반복 수·방향별 장비 능력을 확정하지 않는다. 기존 H2의 에이전트 실험 선택 성능을 검증했다고 하지 않는다.

같은 입력만 읽고 독립 초기 의견을 쓴다. 전원 제출 뒤 상호 질문·반박, 최종 재판단을 한다. 다른 역할의 미공개 파일을 읽지 않는다. 기술적 파일 접근 차단은 없고 지시 수준 격리다. 발언은 내 판단→그 이유→다른 의견에 대한 답→다음 할 일 순서의 쉬운 한국어. 근거 없는 강제 합의는 하지 않는다. 각 결론에 입력 파일의 주장·위치를 연결한다. 외부 탐색은 이번 검토 범위에 없다.
