# 실행 역할의 최종 판단

최소 E01·E02와 결정안의 방향·접촉·독립 반복 구분을 채택한다. 두 제조 조건은 시편 좌표의 대응 전류 경로와 P0에서 비교하며, 배향과 접촉 기여의 분리 판정은 후속 질문이다. 이를 뒤집을 중대한 논리 결함은 발견하지 못했다. 다만 정량 준비와 설계 가능 범위를 결정문 자체에 명시해야 한다. [decision-draft.md 1–6·9항]

필수 보완 문구는 다음과 같다. “원료·배합 연결이 없으면 동일 배합 주장, 경로·치수·측정법 적합성이 없으면 해당 정량 전도도 비교, 실제 실행 경계와 변동 근거가 없으면 독립 반복 수와 확증 판정을 보류한다. 예산·예약·작업자·안전·권한이 미확인이면 실제 착수를 보류한다. 비교 구조와 CSV 연결 명세 검토는 계속할 수 있다.” 현재 결정안 9항의 가상 설계 표시는 이 입력별 보류 범위까지 명확히 말하지 않는다. [previous-execution-spec.md §5; method-response.md]

초기에는 국소 유동 기준까지 필수로 읽힐 방향 조건과 읽기 중심 통합표를 제안했다. 응답에서 소재·방법 의견을 받아 시편 경로와 유동 관계를 분리했고, 기존 계약을 읽은 뒤 네 CSV 재사용으로 수정했다. 최종에도 이를 유지한다. 단일 조작에 따라 냉각이 바뀐 경우를 자동으로 공정 묶음이라 부르던 표현도 수정했다. 다만 날짜·주변 조건 때문인 냉각 차이를 매개 변화로 단정하지 않는 소재 응답의 한계를 함께 유지한다. [execution-initial.md; 세 역할 response.md]

기존 `tasks`, `specimens`, `conditions`, `results`의 행 의미·ID·출처 표시는 유지한다. 추가 명세에는 배합·로트, 실행과 배치의 대응, 도면·방법·조건 사전, 시도별 적용 범위가 필요하다. 시간·순서·부모 재시도·비용·상태 이력·안전 확인·파일 해시 연결도 후속 실행 기록 계약에 남긴다. 오기 정정 필드를 재시도 연결로 전용하지 않는다. 기존 표를 유지한다는 말이 현재 계약으로 모든 추적 요건을 충족했다는 뜻은 아니다. [virtual-lab/README.md; execution-response.md]

공개 응답과 남은 직접 판단 차이는 없지만, 이는 장비 적합성이나 실증 근거의 합의를 뜻하지 않는다. 실제 설정·시편 형상·접촉 적합성·실행 경계·변동·의미 차이·반복 수와 Raman 접근성은 미해결이다. Raman 미확인은 배향 설명 판정을 보류시키며 두 조건의 설계 검토를 막지 않는다. 다음 작업은 위 필수 문구를 결정안에 반영하고 기존 CSV와 추가 명세의 대응표를 구체화하는 것이다. 실제 실험·자동 수신기 구현·정량 실행 준비 완료는 주장하지 않는다.
