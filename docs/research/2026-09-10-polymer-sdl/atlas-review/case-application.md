# Atlas 근거를 실제 연구 질문에 연결한 결과

기존 세 연구 질문을 보존하고 **동일 배합의 PC/CNT 제조 두 조건에서 지정 측정 조건의 전기전도도 차이를 묻는 질문**을 추가했다. 소재·평가 방법·실행 세 역할이 독립 의견 → 상호 답변 → 최종 판단을 수행했고, 실제 9개 발언을 정식 협의에 등록했다.

세 역할의 결론은 **가상 비교 설계와 CSV 명세 구체화는 진행**이다. 실제 제조·측정, 배향 단독 원인 판정, 정량 처방과 UTM 외삽은 확인 전까지 보류한다. 기존 세 연구 질문의 성능·효율 검증이나 전체 M1 완료를 대신하지 않는다.

## 질문에 연결한 근거

Atlas 답변 `qa-abbasi-process-direction-20260912-001` 한 건으로 근거 묶음 하나를 등록했다. 세 주장은 서로 독립된 세 연구 결과가 아니다. 각 주장에 정확한 QA 인용·제한적 사용 판단·허용 용도·한계를 연결했다.

| 주장 | 이 질문에서 사용하는 이유 |
| --- | --- |
| 전도도 차이를 배향만으로 설명할 수 없다 | 제조 대비와 배향 원인 주장을 분리한다. |
| Raman 편광 방향과 전류 방향은 별도로 기록해야 한다 | 시편 좌표·전류 경로를 측정 명세에 연결한다. |
| 현재는 제조 두 조건 비교를 설계 대상으로 삼는다 | 배향·연결망은 가능한 설명으로 남기고 비교 설계를 구체화한다. |

Pilot은 Atlas 답변과 제공 기록을 읽었으며 이번에 원문을 다시 읽지 않았다. 위키 두 페이지는 독립 논문 두 편이 아니고 추가 후보 세 건은 위키 반영 전이다. [QA 원본](atlas-qa.md), [기존 사용 판단](registration.md), [가상 설계](minimal-design.md)를 보존한다.

## 대화로 구체화한 후속 조건

아래는 조정자의 요약이다. 원래 발언은 다음 절에 그대로 둔다.

- 제조 설정 때문에 따라 변하는 냉각·완화 이력은 제조 대비에 포함한다. 외부 배치·날짜가 조건과 겹치는 문제는 별도로 다룬다. 기록이나 단순 보정만으로 혼동이 해소됐다고 판단하지 않는다.
- 원료·배합 배치 → 제조 실행 → 시편 → 접촉 준비 → 측정의 계보를 연결한다. 같은 제조물의 시편과 재측정을 독립 제조 반복으로 세지 않는다.
- 전류 경로·형상·치수·전극·접촉·온도·환산식을 명세한다. 필드 작성과 측정 적합성 확인은 별개다.
- 차이 미검출과 작은 차이의 확인을 구분한다. 의미 차이 경계·주 척도·구간법·반복 단위를 실행 전에 정한다. 결과가 불명확하면 판별 불충분으로 남긴다.

## 실제 에이전트 발언

각 초기 의견의 입력은 동일했고 상대 초기 의견을 포함하지 않았다. 전원 제출 뒤 공개했으며 다음 회차는 공개된 발언을 입력으로 받았다. 역할마다 별도 Codex 실행을 사용했고 모델 이름은 확인되지 않았다. 도구 호출이 없음을 실행 로그에서 확인했다. 모델 다양성이나 강제 보안 격리를 주장하지 않는다.
