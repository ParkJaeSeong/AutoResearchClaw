# 세 설명 후보: 교차 검토 입력 초안

목적: 현재 PC/CNT 근거에서 다음 실험으로 구별할 질문을 정한다. 실제 실험·학습은 실행하지 않는다. 아래는 조정자가 제안한 설계이며 실증 결과가 아니다.
공통 근거: ../stage6-synthesis.md, ../stage6-synthesis.json, ../source-analysis.md. 인용 원문이 필요하면 .superpowers/research/2026-09-10-polymer-sdl/source-analysis-01/sources/S1.txt~S5.txt만 추가 확인한다. 읽은 범위를 명시한다.

## A · 제조에 따른 CNT 구조 변화
- 예측: CNT 함량·PC 원료 구성·최종 형상·측정 방향을 맞춘 상태에서 제조 조건을 바꾸면 전도도와 관측 가능한 구조 지표가 함께 달라질 수 있다.
- 대조: 동일 원료에서 독립 제조 배치를 만들고 제조 조건을 비교한다. 최종 두께와 측정 위치·방향을 기록하며 방향별 구조 관측과 전기 측정을 짝짓는다. 반복 측정과 독립 제조 반복은 분리한다.
- 약화 조건: 충분한 측정 정밀도와 제조 조건 차이를 확보해도 사전 지정한 전도도·구조 차이가 모두 실질적으로 작다면 해당 범위의 설명을 약화한다. 구조 차이를 못 봤다는 이유만으로 전체 구조 기작을 부정하지 않는다.
- 미정: 구조 측정법·검출 한계·최소 의미 차이·배치 수. 특정 배향만 원인이라고 단정하지 않는다.

## B · 측정 방향과 접촉 조건
- 예측: 같은 시편에서도 방향 또는 접촉 절차 변경에 따라 값이 달라질 수 있다. 접촉 절차를 통일했을 때 제조 간 차이가 줄어들면 접촉의 기여를 검토한다.
- 대조: 같은 시편의 방향 비교와 같은 방향의 접촉 재설정 비교를 분리한다. 측정 순서를 바꾸어 배치하고 재접촉·반복 읽기·독립 시편을 구분한다. 장비 적합 범위·전압·온도·최종 치수·전극 간 거리를 기록한다.
- 약화 조건: 충분한 감도 아래 접촉 변경 영향이 실질적으로 작고 제조 차이가 유지되면 접촉만으로 설명하기 어렵다. 방향 차이는 실제 재료 이방성일 수 있어 측정 오류와 동일시하지 않는다.
- 미정: 접촉법 적합성·손상·순서 효과·정밀도. 기존 메타데이터 누락 자체는 원인의 증거가 아니다.

## C · CNT 함량과 PC 원료 구성의 동반 변화
- 예측: 총 CNT 함량을 고정하고 PC 원료 혼합비를 달리했을 때 전도도나 구조가 달라질 수 있다. PC 원료 구성을 고정한 함량 계열에서 기존 함량 추세가 달라지는지도 본다.
- 대조: 가능한 배합 범위에서 CNT 함량과 PC 원료 구성의 별도 변화를 설계한다. 제조·측정 조건을 맞추고 원료 로트와 열·혼련 이력을 기록한다.
- 약화 조건: 의도한 PC 구성 차이와 감도를 확보해도 고정 함량에서 실질적 차이가 작다면 해당 구성 범위의 기여를 약화한다. 이것만으로 CNT 단독 원인을 입증하지 않는다.
- 미정: 동일 등급 수지 확보·마스터배치 희석 때문에 두 변수를 독립적으로 바꿀 수 있는지. 같은 함량의 공정 차이를 구성만으로 설명하지 않는다.

## 공통 판단과 후속 작업
세 설명은 공존할 수 있다. 유의하지 않다는 결과만으로 반증하지 않고, 효과 크기·불확실성·검출 능력을 함께 판단한다. 수치 기준과 반복 수는 장비·예산·예비 정밀도 확인 후 본 실험 전에 정한다.
우선안: B의 접촉 반복성·방향 구분이 가능한지 점검하고 A의 제조 비교와 연결한다. C는 원료 공급·독립 조작 가능성을 먼저 확인한다. 어느 설명이 이겼는지 강제 판정하지 않는다.
이 물리 사례는 H2(가설을 구별하는 실험 선택의 효율) 평가 준비다. H2 평가는 동일 시작 자료·허용 후보·비용·실패 기록과 비교 선택법을 별도로 정해야 한다. 물리 현상 확인을 에이전트 성능 증거로 쓰지 않는다.
정식 연구 노드 등록·M1 완료는 별도이며 기존 쟁점을 해결 처리하지 않는다.
