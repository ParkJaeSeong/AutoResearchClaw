# 조건 변수·시료 계보 비교와 재검토안

후속 [rid44100 원문·목표값 대조](target-pair-review.md)에 시료별 행 대응과 보류 범위를 기록했다.

2026-09-10. 조정자의 재현 가능한 집계와 후속 검토안이다. 모델 학습이나 실험 결과가 아니다.
[저자 저장소](https://github.com/shimakawa-hvg/expt-group-partitioning)의 가공 EC/TC CSV와
시료 상세표, [공식 보충 XLSX](https://acs.figshare.com/articles/dataset/25657025)를 확인했다.
상세표 역시 저자가 배포한 표이며 모든 원측정 기록을 대체하지 않는다.

## 파일과 연결 확인

공식 XLSX의 MD5는 `2918afb1afa1aa931b57263fd4eaad2b`로 공개 메타데이터와 일치한다.
EC 925행×115열, TC 292행×65열을 같은 순서의 CSV와 전수 비교했다.
숫자는 상대·절대 허용오차1e-10, 문자열은 일치 조건으로 비교하여 불일치0셀이다.
EC 시료 상세표의 Sample ID는1599개 모두 고유하고 가공표925행 모두 id로 정확히 연결된다.
PID와 id 첫 구간의 rid도 모두 일치한다. 상세표 중808개 시료 ID는 가공 EC에 나타나지 않는다.
누락 오류라고 판정하지 않으며, 선별·전처리 설명을 확인할 대상으로 남긴다.

실제로 동일한 물리 조건을 뜻하지 않는다. 특히 html이나 표에 없는 주파수·전압·공정·측정
반복의 의미가 미확인이다. 중복 또는 목표값 차이를 잘못된 측정으로 판정하거나 임의 평균·삭제하지 않는다.
상세표는 시료당 한 행이므로 여러 측정값을 충분히 표현하지 못할 가능성도 있다.

## 가공 값과 원측정 선언의 구분

- 상세표 온도가 빈 PC/CNT90행과 PP/CNT45행의 가공 온도는 모두23이다.
  전체432행 중429행은23, 3행은90이다. **일괄23 대체 규칙을 확인한 것은 아니다.**
- 상세표 로그 두께가 빈317행의 가공 값은 모두-3.096910013008056이다.
  가공값의 존재를 실제 측정 두께의 존재로 바꾸지 않는다. 해당 상수의 산출 규칙은 미확인이다.
- 양쪽 로그 두께가 있는608행은 수치가 일치한다. 상세표 두께 예시에서 mm 표현이
  수치상 m로 변환된 사례는 있지만 전체 단위·파싱 규칙이 검증됐다는 뜻은 아니다.
- 공식 XLSX 헤더는 temperature와 log10(thickness), log10(EC)이며 단위를 명시하지 않는다.
  상세표 일부 조건에는 [C]가 있지만 전체 행의 온도·전도도 단위와 변환 규칙은 원출처 대조가 필요하다.
- 상세표 측정법이 채워져 있어도 ac/dc/four-probe 등의0이 ‘수행하지 않음’인지,
  장비명·다른 표현을 인식하지 못한 것인지 알 수 없다. 사전과 생성 코드 확인 전 부재로 단정하지 않는다.

## 조건 변화와 지원 범위

| 가공 조건 | 전체: 문헌 내 변화 문헌 수 | PC/CNT | PP/CNT |
| --- | ---: | ---: | ---: |
| 충전율 vol% | 108/135 | 10/16 | 12/14 |
| temperature | 11/135 | 0/16 | 1/14 |
| log10(thickness) | 7/135 | 2/16 | 3/14 |
| ac | 1/135 | 0/16 | 1/14 |
| dc | 3/135 | 0/16 | 1/14 |
| four-probe | 3/135 | 0/16 | 0/14 |
| two-probe | 2/135 | 0/16 | 0/14 |
| impedance | 0/135 | 0/16 | 0/14 |

PC/CNT의 온도는23:128행·230:8행·270:1행이다. 자기 문헌을 제외한 자료에 같은 온도값이
있는 행은128/137, 같은 로그 두께값이 있는 행은63/137이다. 충전율이 다른 문헌의
최솟값~최댓값 안에 있는 행은134/137이다. PP/CNT는 각각102/112·95/112·109/112이다.
다른 문헌 전체의 최솟값~최댓값 사이에도 관측이 없는 구간이 있을 수 있다.
이는 주변 분포 진단이며, 동일 조건의 공동 분포 중첩·독립성·인과 식별을 입증하지 않는다.
정확한 부동소수점 문자열 일치 기준의 고유값 진단도 연속 변수 거리 검사를 대신하지 않는다.

PC/CNT는 시료·문헌 수가 더 많고 PP/CNT는 일부 조건 변이가 더 있지만, 양쪽 모두
가공·반복 측정 계보 문제가 남는다. **PC/CNT는 감사 우선 사례로 유지하고, H1 실증 평가 착수는 보류한다.**
지금 전 소재로 범위를 넓히면 문제가 해결된다고 가정하지 않는다.

## H1 수정안: 평가 착수 조건과 비교 정의

현재 질문은 ‘계보를 확인한 PC/CNT에서 충전율에 조건 정보를 추가하면 새로운 문헌의
예측에 실질적인 가치가 있는가’다. 조건의 인과 효과나 멀티 에이전트 효과가 아니다.

1. 목표값마다 원문 표·그림/측정 이벤트, 단위, 시료·조건을 연결한다. 반복값·완전 중복의
   의미를 확인하고, 사전에 고정한 처리 기준과 원본 대응표를 보존한다.
2. 온도·두께의 실측/미상/가공 값을 구분한다. 가공 상수를 실제값으로 쓰지 않는다.
   재구성이 불가능하면 해당 특성의 실측 효과 질문을 보류한다.
3. PC/CNT를 주 모집단 후보, PP/CNT와 전체 EC를 탐색적 별도 모집단으로 둔다.
   결과가 잘 나오는 모집단을 사후 주 대상으로 바꾸지 않는다.
4. 문헌 단위 외부 분할은 진단용으로 쓰되 같은 원자료·저자 연결 계보가 나뉘는지 감사한다.
   확인된 계보 연결요소를 학습/평가에 함께 묶는다. 독립 평가 그룹이 확보되지 않으면 주 검정은 보류한다.
5. 같은 학습기·튜닝 후보·내부 그룹 분할에서 충전율 기준선과 조건 추가 입력을 비교한다.
   전처리·결측 처리·특성 선택은 훈련 내부에서만 적합한다. 식별자와 expt_*는 입력에서 제외한다.
6. 주 지표 초안은 문헌별 MAE의 동일 가중 평균이며, 대응 차이는 기준선MAE−조건추가MAE다.
   효과 크기와 계보 단위 불확실성을 함께 보고한다. 행·반복 fold를 독립 반복으로 세지 않는다.
   충분한 독립 그룹이 없으면 신뢰구간을 확정적인 증거로 해석하지 않는다.
7. 최소 의미 있는 개선폭은 측정 반복오차·응용 요구와 로그 단위 확인 뒤 사전등록한다.
   현재 근거 없이 수치를 정하지 않으며, 그 값과 불확실성 판정 규칙이 고정되기 전 성능 비교를 시작하지 않는다.
8. 보조 비교로 출처 미상 여부만 추가한 입력과 기록 조건을 추가한 입력을 구분한다.
   전자는 측정 조건 효과가 아니라 기록 관행의 신호일 수 있다. 평가 조건 범위 밖 결과는 별도 보고한다.

## H2 관측 예측표 초안

| 설명 후보 | 구분할 관측·대조 | 유보할 경우 |
| --- | --- | --- |
| 구조 변화가 주요 설명 | 대응 시료의 분산과 연결성 지표, 고정된 측정 조건의 전도도 비교 | 이미지 해상도·대표성 부족, 시편 대응 없음 |
| 측정 조건 변화가 주요 설명 | 동일 시편에서 조건을 변화시킨 반복 측정과 안정성 확인 | 측정이 구조를 바꾸거나 순서 효과가 통제되지 않음 |
| 구조와 측정 조건이 함께 작용 | 구조·측정 조건의 교차 대조와 상호작용 예측 | 두 요인이 완전히 결부되거나 예측이 겹침 |
| 현재 후보로 설명 불충분 | 독립 관측에서 모든 후보의 사전 예측 범위를 벗어남 | 관측 오차와 모델 불일치를 구분할 자료 부족 |

이 표는 방향과 수치가 정해진 완성 모델이 아니다. 실제 관측법·오차·정량 예측과
판정 기준을 확보한 후 판별 실험을 설계한다. 빠르게 한 후보를 고르는 것을 성공으로 정의하지 않는다.
전체 캠페인의 오판·미판별·누적 비용과 순차 중단 규칙을 함께 사전 정의한다.

## H3 독립 판정 기준 초안

- 동일한 검사 전 제안 집합에 명시적 가상 장비 제약과 별도 작성한 정답 명세를 연결한다.
- 정답은 검사기 자체나 같은 검사 결과의 재사용으로 만들지 않는다. 독립 검토와 근거를 남긴다.
- 필수 입력·허용 범위·단위·시료 식별·단계 연결·실패 후 복구 조건별로 적합/부적합/판단 불가를 구분한다.
- 전체 제안을 분모로 한 오류율과, 실제 적합 제안 중 오거절률·실제 부적합 제안 중 통과율을 함께 보고한다.
  두 종류의 분모를 섞지 않는다. 판단 불가 비율도 별도 남긴다.
- 원료→배치→시편→측정의 연결 정확도·복구 가능성, 거절·재시도·사람 개입·시간을 기록한다.
- 비교군은 같은 제안과 정보에 대해 모의 검사 포함/제외로 평가한다. 장비 실행이나 실제 제조 성공률을 주장하지 않는다.

이 문서는 후속 검토 입력이다. 주요 쟁점의 해결·원문 검증·corpus 승인 기록은 별도다.

추적 메모: 재검토 입력 동결 후 위 지원 범위 설명에 최솟값~최댓값 사이의 공백 가능성을 보충했다.
수치나 검토 입력은 바꾸지 않았다. 별도 검토자가 원자료를 독립 집계하여 주요 수치·해시·XLSX 대조를 확인했다.

## 세 역할 재검토 결과

연구 질문3차 개정에서 독립 의견3개·공개 반박3개·최종 판단3개를 완료했다.
세 역할 모두 질문 구체화에 `ready_with_limits`를 제출했으며 H1 성능 비교와 물리 검증은
보류했다. 새 쟁점0개, 기존22개는 열린 상태다. 현재 정책상 주요 쟁점이 남아
노드의 다음 단계 조건은 `ready=false / blocking_issue_unresolved`다.

실제 반론 수용: 방법론 역할은 같은 고정 예산에서 총비용 감소를 주장하는 모호함을 지적했다.
SDL 역할은 고정 예산에서의 오판·미판별률과, 사전 성과 기준까지의 누적 비용을 별개로
평가하도록 수정했다. 소재 역할도 이 구분을 수용했다. 실패·기준 미도달 캠페인을
비용 비교에서 버리지 않고, 단가가 미정이면 자원량·시간·횟수로 보고한다.
H3는 별도 문서 작성만으로 정답의 독립성이 확보되지 않으므로 검사 출력과 분리된
판정 근거, 허용 탐색 손실과 복구 성공 상태를 사전에 고정해야 한다는 조건을 남겼다.

새9개 제출과 호스트 응답을 대조했고, 단계별 공개 조건을 확인했다. 전체 native 제출은54개다.
이번 역할 검토는 동결 자료만 사용했고 역할별 새 도구 호출은0회다. 조정자의 검색·집계를
각 역할이 직접 수행했다고 표현하지 않는다. 실제 모델 다양성과 강한 접근 격리는 미확인이다.

## 후속 원문 확인 대상 — 재검토 입력 동결 이후 발견

PC/CNT 목표값 충돌6개 시료는 `44100-2-1-1`부터 `44100-7-1-1`까지이고, 모두 rid44100이다.
상세표 Reference의 저자·저널·권·쪽·연도를 [저자 소속 대학의 논문 목록](https://www.r-info.tohoku.ac.jp/en/167588372b3e9b1e6c32c8aa2d30b675.html) 및
[출판사 검색 결과](https://www.sciencedirect.com/science/article/pii/S0032386111005350)와 대조하여
Takeda 등, *Modeling and characterization of the electrical conductivity of carbon nanotube-based
polymer composites*, Polymer52(17),3852–3856(2011), DOI10.1016/j.polymer.2011.06.046으로 연결했다.

상세표의 해당 시료에는23 [C]·10Hz, 임피던스 분광법, AC 전도도와 그림4 추출을 뜻하는
기록이 있다. 가공표에는 주파수 열이 없고 해당 PC/CNT의 ac 값은0이다. 따라서 ac=0을
