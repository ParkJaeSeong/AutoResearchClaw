운영 기준: [연구 에이전트·조정자 가이드](../guides/README.md).

최신: [원문 기반 질문·답변과 자료 사용 범위](source-analysis.md). 같은 원문·데이터를 읽은 세 역할이 독립 의견·교차 답변·최종 판단 9건을 정식 등록했다. Abbasi의 동일 함량·제조·형상 조합 비교는 제한적으로 유지하며, 개별 요인의 효과 추정과 전체 자료 통합 평가는 보류한다. 다음은 이 사용 범위를 검색·선정안에 반영하고, 정량 비교에 필요한 그림의 점별 판독 기록을 준비하는 작업이다.

[질문 단계의 진행 조건 변경](question-scope-review.md)은 보존한다. 쟁점 22개는 열린 상태이며, 조정한 8개는 최종 검토·M2 인계를 계속 차단한다.

사용자가 제시한 실제 연구 주제로 M1을 시작했다. 현재는 **자료 사용 조건 검토와 실험 착수 준비 초안 작성**이다. 정식 연구 기록은 질문 4차 검토에 머물러 있으며 수집 이후 단계의 등록은 아직 진행 조건을 충족하지 못했다.
[새 기준 재개 점검](resume-check.md)에서 구현 차이와 다음 작업을, [실험 착수 준비 초안](experiment-preparation.md)에서 H1–H3의 비교 계획과 남은 준비를 확인한다.
R1에서 기존 파일 5개(원문과 공개 저장소, 출처 묶음 2개)를 정식 수집 기록으로 등록했다. UI의 **확보한 자료**에서 읽은 범위와 확인할 내용을 볼 수 있다. 자료 사용 판단과 기존 collect 단계 완료는 별도다.

## 핵심 질문과 기여 후보

**경쟁 가설의 근거·반론·불확실성을 갱신하는 연구 에이전트가 동일한 실험
예산의 일반 능동학습/베이지안 최적화보다 물성 예측 또는 가설 판별을 개선하는가?**

단순히 여러 LLM을 연결했다는 점을 연구 기여로 삼지 않는다. 다음은 검증할
후보이며, 효과가 입증됐거나 새로운 아이디어라는 주장이 아니다.

| 후보 | 비교와 검증 방향 | 반박되거나 보류할 조건 |
| --- | --- | --- |
| H1: 공정·측정 정보를 포함하면 미관측 실험군의 예측이 개선된다 | 같은 분할과 모델 조건에서 조성 기반 모델과 비교. 논문·실험실·배치 단위 분리 및 불확실성 평가 | 개선이 무작위 분할에서만 나타나거나 외부 실험군에서 유지되지 않음 |
| H2: 가설 판별 중심의 다음 실험 선택이 더 효율적이다 | 같은 초기 데이터·실험 예산에서 무작위 선택, 일반 능동학습/BO와 비교. 가설 판별과 예측 성능은 별도로 평가 | 차이가 없거나 특정 계산량·정보 접근 이점으로만 설명됨. 관찰 데이터만으로 경쟁 가설을 식별할 수 없는 경우는 보류 |
| H3: 구조화된 실험 명세와 실행 전 검사가 실행 가능한 제안을 늘린다 | 검사 포함/제외 구성에서 부적합 제안, 실행 실패, 데이터 추적성, 처리량 비교 | 부적합 감소가 단순한 제안 억제이거나 유효한 탐색·처리량 손실로 상쇄됨 |

대표 사례를 정한 뒤 주 평가 지표 하나와 보조 지표를 고정한다. H1–H3는
서로 다른 평가 축이며 모두를 한 번에 성공시켜야 하는 단일 가설로 합치지 않는다.
이 단계의 비교 방향은 완성된 실험 설계나 실험 실행 허가가 아니다.

## 대표 사례 선정

| 후보 | 먼저 확인할 정보 |
| --- | --- |
| 섬유 강화 고분자의 강도·탄성률 | 섬유 방향·분율, 시편 제조 및 시험 조건, 배치 구분, 시험 자동화 여건 |
| 입자/나노필러 복합소재의 열전도도 | 수지·필러, 분율 단위, 분산·계면·배향, 측정 방향·온도·방법 |
| 복합소재의 전기전도도 | 공개 데이터 실제 접근·사용권, 실험군 식별자, 공정·측정 정보와 반복 측정 |

선정 기준은 데이터와 사용권을 실제 확인할 수 있는지, 실험군 분리가 가능한지,
기록된 변수가 검증 질문에 충분한지, 실험실에서 다룰 수 있는지다. 특정 소재를
최종 확정하지 않는다. 이후 공개 CSV를 검사한 결과는 최신 선정 문서에 기록했다.

## 에이전트와 실험실의 역할

- 문헌·데이터 담당: 출처, 접근 범위, 단위, 배치 및 데이터 누출 위험을 기록한다.
- 소재·물성 담당: 조성–공정–구조–물성 관계와 물리적으로 가능한 설명을 제시한다.
- 가설 담당: 경쟁 설명, 구분에 필요한 관측, 반증 조건을 명시한다.
- 방법론·반증 담당: 평가 분할, 비교군, 불확실성 및 인과 주장에 반론을 제기한다.
- SDL 담당: 계량·혼합·성형·측정·정리 작업과 장비 제약, 실패 처리를 검토한다.
- 판단 기록 담당: 동의와 미해결 이견, 판단 변경 이유, 다음 확인 작업을 보존한다.

현재 M1 범위 협의는 기존 프로토콜의 **소재 전문가 / 방법론 전문가 /
SDL·반증 검토자** 세 역할로 실행한다. 위 여섯 책임을 모두 별도의 구현된
에이전트로 표현하지 않는다. 독립 초기 의견 → 공개 반박 → 최종 의견을 기록하며,
호스트 격리는 `instructions_only`, 모델 종류와 통계적 독립성은 미확인이다.

제안 흐름은 `자료·출처 정리 → 가설·경쟁 설명 → 검증 질문 → 실행 가능한
실험 명세 → 측정·품질 확인 → 가설 갱신`이다. 근거 부족은 자료 수집으로,
명세 부적합은 설계로, 가설 반박은 가설 개정으로 돌아간다. 이 프로젝트에서
M2 장비 실행을 시작하지 않는다.
