**검색·선정 수정본 검토 완료.** 후속 [재검토와 해결 결과](selection-correction.md)를 기준으로 한다. 아래는 처음 발견한 문제와 수정 경과를 보존한 기록이다. 초기 5편 제한을 없애고 기존 탐색 결과와 보존 원문을 현재 연구 질문에 연결했다.

## 이번 자료 범위

기존 DOI·URL 식별자 후보 197건과 보존 Abbasi 원문 1건, 총 198건을 선정표에 남겼다. 이 중 우선 검토 식별자 23건과 Abbasi 1건을 포함하고 나머지 174건은 이번 회차 사용 범위에서 보류했다. 논문·저장소·버전이 섞여 있으므로 독립 논문 수가 아니다. 우선 검토 그룹 자체가 23개라는 뜻도 아니다.

후속 보류는 현재 등록 형식의 exclude로 표시하되 그 이유에 후속 보류임을 명시했다. 부적합·반대 결과라는 판단이나 원문 삭제가 아니다.

## 조회 기록을 복원한 방법

보존된 탐색 보고의 후보별 조회 관계를 등록했다. 시각은 해당 보고의 종료 시각이며 검색 호출의 정확한 시각이 아니다. result_count=1은 보존한 후보 관측 한 건으로, 검색엔진 전체 결과 수가 아니다. Abbasi는 기존 PDF의 로컬 조회로 연결했으며 새 웹 검색으로 표시하지 않았다.

처음 신고된 접근 수준을 유지하며 원문 전체 검증으로 올리지 않았다. 원래 197건의 기록·탐색 보고·원문은 그대로 보존한다. 공개 자료의 재조회나 새 실험은 이번에 수행하지 않았다.


## 검토에서 발견해 수정한 것

첫 선정안에 그룹 설명을 반복하면서 NanoMine·OOD 참고자료가 PC/CNT137행·Abbasi25행의 출처처럼 보이는 문제가 있었다. 세 역할이 이를 지적했다. 수정본은 각 후보의 기존 탐색 내용·읽은 범위·한계를 개별적으로 귀속시키고 직접 데이터 출처와 방법 참고 역할을 나눴다. 같은 URL 별칭은 포함된 대표 기록을 쓰는 이유를 남겼으며 H2 반론 후보는 현재 직접 입력에서 보류하는 이유와 평가 명세 단계의 재검토 조건을 적었다.

[실제 검토 원응답](search-reconnect-dialogue.md)은 검색 9개·첫 선정안 9개, 총 18개 발언이다. 검색은 세 역할 모두 ready_with_limits로 검토를 마쳤고 런타임 검토 조건을 통과했다. 첫 선정안은 세 역할 모두 revise였다. 수정본을 정식 등록했지만 이를 통과한 것으로 표시하지 않았다.

새 지적은 원자료를 더 모으라는 요구가 아니라 등록한 선택 이유를 바로잡으라는 요구다. 원래 22개 쟁점은 유지했고 이번 독립 초기 검토에서 관련 지적 4개가 추가 등록됐다(유사한 출처 귀속 지적을 포함). 같은 문제의 후속 처리를 묶는 작업과 실제 수정 확인이 남아 있으며 개별 지적을 해소한 것으로 기록하지 않았다.

쟁점 이벤트 등록에서 필드명 오류 1건이 발생했다. 실패 payload와 실제 응답은 보존하고 필드를 고쳐 재개했다. 이전 검색 검토는 저장된 응답을 재사용했으며 새 에이전트 발언으로 중복 등록하지 않았다.

## 현재 남은 순서

1. 수정 선정본의 후보별 사유와 반론·별칭 처리를 확인하고 관련 지적의 해결 근거를 등록한다.
2. 수정본의 정식 검토와 선정 자료 사용 결정을 연결한다. 검토자의 진행 의견을 사용자 승인으로 대신 쓰지 않는다.
3. 이 범위에 실제 수집·추출 결과를 등록하고 근거 종합을 연결한다.

현재 자료 상태 조회에서 이전의 오래된 질문 참조 오류는 사라졌다. 대신 선정 사용 승인, 수집·추출 등록, 출처 연결이 없다는 실제 남은 조건이 표시된다. 자동 가져오기·실험 수행·M1 완료를 진행한 것은 아니다.
