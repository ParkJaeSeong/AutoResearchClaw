# D2 가상 전극 배치도

2026-09-13 · `PILOT-EC-LAYOUT-v1` · 조정자 설계안

두 제조 조건의 막대 시편을 같은 x방향 배치로 비교한다. 장비·시편 치수·전극 재료는 아직 정하지 않는다. 아래 그림은 측정 위치의 관계를 나타내며 제작 도면이나 실험 결과가 아니다.

```text
                       전압계(모델 미정)
                          +       −
                          │       │
        전류 유입         V+      V−         전류 유출
           I+             │       │             I−
      ┌────┬──────────────┬───────┬──────────────┬────┐
      │    │              │       │              │    │  막대 시편
      └────┴──────────────┴───────┴──────────────┴────┘
                          ←  Lv  →                   x →
           └──────── 전류원(모델 미정) ──────────┘

      폭 w: y방향 / 두께 t: z방향
      I+·I−: 전류 단자 / V+·V−: 별도의 전압 접점
      선은 x위치만 표시한다. 전극의 폭·부착면·둘레 범위는 미정이다.
```

그림은 양의 전류 설정에 대한 기준 극성이다. 전류 반전 시 부호를 원자료에 보존한다. x축을 금형 유동 방향과 같다고 가정하지 않는다.

## 이번에 선택한 것과 남겨둔 것

| 구분 | 이번 설계안 | 실제 적용 전에 확인할 것 |
| --- | --- | --- |
| 기본 형상 | 일정 단면의 막대 구간 | 실제 단면 변화·표면층·채취 위치 |
| 전극 순서 | x방향 I+ → V+ → V− → I− | 부착면·폭·간격·전극 끝과 시편 끝의 거리 |
| 전압 거리 Lv | 두 전압 접점의 유효 위치 사이 | 유한 폭 전극에서 유효 위치를 정의하는 근거 |
| 전류 접촉 | 시편 양 끝 영역에 배치하는 후보 | 끝면 전체·띠·점 접촉 중 적합한 형상과 전류 분포 |
| 비교 규칙 | 두 제조 조건에 같은 배치 버전 적용 | 같은 제작법으로 접촉 영향까지 같아지는지 |
| 관측과 환산 | 기존 V=RI+b와 σ=Lv/(Rwt) 명세 유지 | 선형성·안정성·형상 전제가 충족될 때만 환산 |

끝면 전체 접촉, 표면 점접촉 등 여러 구현이 가능하지만 지금은 하나를 검증된 방식으로 확정하지 않는다. 기존 막대 모델을 기준안으로 삼고, 확보한 방법 자료가 맞지 않으면 배치 또는 해석 범위를 바꾼다. 도면·접촉 방식이 바뀌면 배치 버전을 올려 두 제조 조건에 어떤 버전이 적용됐는지 남긴다.

## 어떤 결과가 설계를 바꾸는가

아래는 조정자가 앞선 검토를 바탕으로 작성한 점검안이며 검증 결과가 아니다.

| 점검 | 확인하려는 것 | 문제가 나타났을 때 |
| --- | --- | --- |
| 전압 간격·위치 변경 | 환산값의 위치 의존성 | 측정 편향과 실제 재료 불균일을 함께 검토; 단일 대표값 사용 보류 |
| 접촉 재제작·조건 변경 | 접촉 제작에 따른 변화 | 공정 차이로 귀속하지 않고 접촉 방법 재설계 |
| 전류 크기·극성·시간 변경 | 비선형·오프셋·드리프트·발열 영향 | 임의의 좋은 구간만 고르지 않고 적용 범위·방법 재검토 |
| 대응 위치의 구조 관찰 | 배향과 분산 등 경쟁 설명 | 전도도 차이만으로 배향 원인 확정 보류 |

허용 오차와 구동값은 장비·문헌·변동 근거를 확인한 뒤 정한다. 점검이 통과해도 배향의 인과 효과가 자동 입증되지는 않는다.
