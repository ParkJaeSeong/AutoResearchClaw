# D2 전도도 측정 명세

설계 검토안 v1. D1의 낮음·높음 사출 속도 설정 비교에 사용할 **지정 배치의 시편 x 방향 유효 전기전도도**를 주 지표로 선택한다. 이는 가상 방법 선택이며 현재 보유 장비의 지원 기능이나 PC/CNT 시편의 적합성을 확인한 것은 아니다.

## 측정 대상과 좌표

시편 도면에 길이 x, 폭 y, 두께 z를 정의하고 x 방향 전류 경로를 D0로 한다. 도면 원점·전극 위치·채취 위치를 함께 기록한다. 금형 유동 방향이 확인되지 않으면 D0를 ‘유동 평행’으로 부르지 않는다. 두 제조 조건에서 같은 채취 규칙·최종 형상과 공통 측정 절차 P0를 사용한다. 전기시험용 시편과 UTM 시편은 구분한다.

가상 기본 방법은 **막대 형태의 시편에 전류를 흘리고, 그 안쪽 두 위치에서 전압을 읽는 4단자 방식**이다. 표면의 등간격 4점 탐침이나 van der Pauw 방법과 같은 환산식을 쓰지 않는다. 바깥 전류 단자의 x 위치·접촉 면과 안쪽 전압 단자의 위치·접촉 범위를 도면에 연결한다. 전압 측정 구간에서 단면 전체를 따라 길이 방향 전류가 흐른다고 근사할 근거를 확인한다. 표면 점접촉이라는 이유만으로 이 전제를 인정하지 않으며, 전류 경로를 확인할 수 없으면 환산식과 방법을 개정한다. 실제 장비·전극·시편이 아래 전제를 충족하지 못하면 측정법을 개정하고 이전 명세와 연결한다.

| 항목 | 작업 명세 |
| --- | --- |
| 방법 식별 | `PILOT-EC-LONGITUDINAL-4T-v1`; 장비 적용 검증 전 가상 방법 |
| 치수 | 전압 단자 사이 길이 Lv, 전류가 통과하는 폭 w·두께 t를 실제 측정. 입력 단위 cm, 저항 Ω, 출력 S/cm |
| 전기 관측 | 전류 I와 전압 V의 부호를 좌표·극성에 연결. 여러 양·음 전류 수준의 원자료를 저장하고 V = R I + b의 기울기 R을 추정 |
| 환산 전제 | 선택 구간에서 선형·안정 응답, 양의 R, 균일 단면과 적합한 전극 배치·전류 경로. 충족할 때 σ = Lv / (R w t) |
| 환경 | 조절·대기 절차, 측정 온도·습도 및 시편 상태와 실제 이력 기록 |
| 접촉 P0 | 전극 재료·부착·위치·압력 또는 고정 방식·접촉 준비·회차를 방법 버전에 고정 |
| 원자료 | 시편/시도/접촉 회차, 시간, I(A), V(V), 계측 범위, 제한 도달 상태, 환경·치수 기록 및 파일 해시 |

4단자 구성이 곧 접촉·형상·누설·비선형·자기발열 문제의 부재를 증명하지 않는다. 현재 목표는 명시한 방법에서의 방향별 전도도이며 등방성 고유 물성으로 확대하지 않는다.

## 수행과 품질 판정 순서

1. 원료→제조 실행→시편의 연결과 도면·방법 버전을 확인한다. 미확인이면 연결부터 보완한다.
2. 장비 범위·교정 또는 확인 기록·개방/단락 등 해당 장비의 점검 절차, 치수 측정 도구의 적합성을 확인한다.
3. 시편 조절 및 접촉 절차를 적용하고 원자료를 기록한다. 전류 범위·각 수준의 대기 시간·측정 순서는 장비/재료에 맞춰 실행 전 확정한다.
4. 제한 도달·신호 범위·시간 안정성·선형성과 부호·극성 일관성을 확인한다. 결과를 보고 임의의 구간만 골라 유효 처리하지 않는다.
5. 사전 명세의 전제를 충족한 시도만 환산한다. 비선형이면 이 방법의 단일 전도도를 산출하지 않고 I–V 원자료와 이유를 보존한다.
6. 반복 읽기는 시도 안, 재접촉은 새 접촉 회차, 재시도는 새 시도 ID로 구분한다. 실패를 지우지 않는다. 재시도 선택 규칙은 아래 분석 명세를 따른다.

미상 치수, 부적합 단위, 미확인 전극 간 거리, 장비 제한, 범위 밖 신호는 임의 수치로 대체하지 않는다. 한계 이하 결과는 해당 한계·단위·기준을 함께 기록하며 0이나 한계의 절반으로 대체하지 않는다.

## 실행 전에 채울 값

| 필수 값/근거 | 확정 책임 | 미확인일 때 보류되는 것 |
| --- | --- | --- |
| 장비 모델·측정 범위·전류/전압 제한·교정/확인 기록 | 실행 담당 | 정량 측정의 적합성 |
| 도면·전극 배치·Lv/w/t 측정법과 허용 오차 | 실행·소재 | 환산값 사용 |
| 접촉 재료·부착/고정·조절·측정 환경·대기 시간 | 실행·소재 | 공통 P0 구현과 비교 |
| 전류 수준·반복 읽기 수·선형성/안정성/제한 기준 | 실행·방법 | 유효 시도의 사전 판정 |
| 측정 불확실성 및 사용할 수 있는 최소 신호/상한 | 실행·방법 | 한계값 처리와 목표 정밀도 |

빈값은 실제 착수 전에 확정한다. 이 표를 작성한 것으로 확인을 대신하지 않는다. UTM 방법은 보조 연구로 남기고 전도도 비교 완료 조건에 합치지 않는다.

## 이번에 확인한 방법 자료
