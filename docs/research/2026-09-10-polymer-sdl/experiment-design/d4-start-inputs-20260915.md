# D4 착수 준비표

2026-09-15 · 조정자 작성 · 가상 설계의 착수 입력 정리

**비교할 대상과 기록 방법은 정해졌다. 실제 재료·장비·측정 적합성·반복 수·운영 조건을 채우고 확인해야 실험을 시작할 수 있다.** 이번 결과는 기존 D1–D3와 005의 결론을 실행 전 확인 항목으로 옮긴 것이다. 새로운 에이전트 토론이나 장비 검증 결과는 아니다.

직전 제안한 착수 준비표 작성에 대한 사용자의 “시작하자.”를 진행 지시로 사용했다. 실제 장비 결정은 나중에 하고 가상 설계와 CSV 전달을 먼저 준비한다는 범위는 유지한다. 이 표의 작성 완료와 D4·M1 전체 완료는 다르다.

## 어떤 순서로 채울까

1. **장비를 정하면 D4-01·02·04·05부터 받는다.** 재료 명세, 사출기/금형 정보, 시편 도면, 측정기 모델과 데이터 출력 예가 첫 입력 묶음이다. 이미 보유한 압출기·사출기·UTM·전도도 측정기는 보유 사실만 알고 있으며 모델·성능은 미확인이다.
2. **실행 가능한 수치와 방법을 정한다.** 위 자료에 맞춰 D4-03·06·07·08을 검토한다. 장비에 맞지 않으면 제조 또는 측정 설계의 해당 부분만 개정한다.
3. **목적·변동·자원을 함께 보고 수량을 정한다.** D4-09·10·12를 연결한다. 새 예비 실험이 필요하다면 그 실험의 착수 준비부터 별도로 갖추며, 이번 입력표 작성으로 수행한 것으로 처리하지 않는다.
4. **전달과 최종 조건을 확인한다.** D4-11·13·14를 검토하고 정식 준비 자료와 인계에 연결한다. 장비 정보가 오기 전에도 문서·양식 점검은 가능하다.

UTM 기계적 물성은 후속 보조 평가로 둔다. 배향 직접 관측 장비, 장비 자동화 API, Zotero 연결을 이번 전도도 설계의 새 필수 조건으로 추가하지 않는다.

## 입력과 검증 기록의 구분

CSV의 `planned_value`는 제안·계획, `confirmed_value`는 실제 자료로 확인한 내용이다. 숫자에는 단위를 붙이고, `evidence_ref`에는 파일/버전/위치와 해시를 연결한다. 빈칸은 미정이며 0이나 해당 없음으로 해석하지 않는다.

`status`는 현재 `입력 대기` 또는 `검토 대기`다. 자료를 받으면 `자료 접수`, 별도 검토에서 확인하면 `확인됨`, 맞지 않으면 `보완 필요`로 기록한다. 표에 ‘확인됨’을 적는 것만으로 정식 연구 상태가 바뀌지는 않는다. 이 파일은 착수 입력용 작업표이며 D3의 tasks/specimens/conditions/results CSV나 자동 업로드 계약이 아니다.

계획 시편과 실제 시편·시도·결과를 구분한다. 실험 전에는 가짜 결과 행을 만들지 않는다. 결과별 실제 품질 확인은 M2에서 수행할 의무지만, 그 검사 기준·방법·필요 장비와 착수 전 적합성 확인은 M1에서 준비해야 한다.

## 현재 남은 시스템 조건

기존 CSV v2는 파일 구조·참조·원시 파일 해시를 검사한다. layout_manifest의 존재·해시·필수 조건·과학적 적합성은 자동 검증하지 않으므로 D4-11의 수동 검토가 필요하다. 자동화 개발 여부와 무관하게 확인 의무는 유지한다.

2026-09-15 시작 시 실제 연구 조회의 자원/작업 원장 판정은 `ready=false`, 사유는 `work_source_invalid`였다. 현재 이 사유가 가리키는 원장 연결과 기존 한도 정책은 최종 인계 전 별도 점검 대상이다. 과거 문서의 되돌림 한도/횟수와 같은 원인이라고 단정하지 않으며 이번에 정책·기록을 변경하지 않는다.

## 이번 작업의 결론

착수에 필요한 입력·담당 역할·확인 기준·보류 범위를 14항목으로 정리했다. D1–D3 및 005의 결정은 유지했고 실제 수치나 실험 결과는 추가하지 않았다. 다음 한 작업은 **장비 결정 후 첫 입력 묶음(D4-01·02·04·05)을 받아 설계 적용 가능성을 확인하는 것**이다. 장비 결정을 미루는 동안에는 이 표와 전달 형식의 준비까지만 완료로 보고한다.

기준 문서의 정확한 바이트와 이번 산출물 해시는 연구 작업 폴더 `d4-readiness-20260915`에 보존한다. UI 작업 회차에는 조정자의 정리로 연결하며 새 토론·독립 검증·정식 준비 승인으로 표시하지 않는다.
