담당은 D1 소재·방법·실행 검토자와 조정자, D2 방법·실행, D3 실행·개발, D4 실행·조정자다. D2는 먼저 방법 구조를 정하고, 장비 성능·변동 정보가 필요한 수치는 D4 착수 전에 근거와 함께 확정한다. 미정 수치를 확정한 것으로 보고하지 않는다.

각 작업은 결론·이유·반론·남은 조건·다음 한 작업으로 마감한다. 이후 문제가 생기면 영향을 받는 작업만 재검토한다. 선택적 보완 때문에 완료된 6단계 전체를 다시 열지 않는다. D4까지의 표는 준비 작업을 나눈 것이며, 네 항목을 기록했다는 이유로 M1 완료 조건이 충족되는 것은 아니다.

## D2·D3 결과와 현재 위치

- **D2 구조 완료:** [측정 방법](measurement-method.md), [비교·분석 명세](analysis-plan.md). 전극/전류 경로의 환산 전제를 보완했고, 지정 배치의 x 방향 유효 전도도를 제조 실행 단위로 비교한다. 실제 수치·반복 수는 아직 미정이다.
- **D3 검증 완료:** [CSV v2 양식과 검증기](../virtual-lab/v2/README.md). 독립 코드 검토에서 나온 재제조·배정·적용 방법 연결 오류를 수정하고 55개 테스트와 재검토를 통과했다. 합성 파일은 연구 결과로 등록하지 않는다.
- **B5b 기능 구현:** [준비 증거 검증·M2 인계 사용 기준](../../guides/m1-preparation-handoff.md). 원문 보존, 항목별 독립 검증, 갱신 시 재검토, 인계 명세·수신 의무를 연결했다. 실제 프로젝트의 준비 증거·인계 기록을 대신 만들지는 않았다.
- **현재 D4 준비 중:** [실제 착수까지 남은 준비](start-readiness.md). 장비·재료·측정 적합성·수치·반복·자원/권한과 정식 최종 검토·외부 인계가 남았다. **M1 전체는 미완료다.**

D2도 전원 제출 후 순서대로 공개했다. 같은 모델·공유 파일시스템에서 지시 수준으로 초기 의견을 분리했다. 검토자는 지정 설계 문서를 읽었으며 외부 방법 자료의 직접 확인은 조정자가 수행했다. 원발언을 정식 council 승인으로 대체하지 않는다.
