# D1 결정안: 사출 속도 설정 두 수준 비교

동일 배합의 PC/CNT를 같은 사출기·금형으로 제조하되, 충전 구간의 **사출 속도 명령을 낮게(M0), 높게(M1)** 지정하는 가상 비교를 선택한다. 소재를 바꾸거나 여러 공정 설정을 함께 바꾸는 비교보다 조작 대상을 명확히 정의할 수 있어 선택했다. 이는 Pilot의 설계 판단이며 Atlas가 추천한 장비 설정이나 확인된 물성 효과가 아니다.

## 무엇을 바꾸고 유지하는가

| 구분 | 정의 |
| --- | --- |
| 조작 요인 | 충전 구간 속도 프로파일에 적용하는 배율 하나 |
| 두 수준 | 0 < 낮음 배율 < 높음 배율. 수치 미정. 이는 크기 관계이며 실행 순서가 아님 |
| 공통 프로파일 | 같은 기준축·단계 경계·적용 구간에서 속도 명령만 배율 변경. 기준축과 경계 값은 장비에 맞춰 명세하며 구현 불가 시 이 정의를 재검토 |
| 공통 계획 | 배합과 원료 로트 연결, 건조 절차, 사출기·금형·시편 형상, 용융·금형 온도 설정, 속도→압력 전환 기준, 보압·냉각 설정 |
| 실제 이력 | 명령 속도와 실제 속도, 충전 시간, 압력·온도, 전환 상태, 날짜·순서·배치. 관측 가능성과 기록 정밀도는 장비 결정 후 확인 |
| 측정 조건 | D0: 도면의 시편 좌표에 연결한 전류 경로. P0: 두 조건에 적합성을 확인할 공통 접촉 절차. 구체 측정법은 D2 |

공통 설정이 실제 이력까지 같음을 뜻하지 않는다. 설정 변경으로 따라 달라지는 이력과 원료 배치·날짜 등의 외부 요인을 구분한다. 같은 원료 배치 안에 두 조건을 배정하고 실행 순서가 한 조건과 고정되지 않도록 한다. 실행 단위·안정화·잔류 처리·배정 상세는 D2에서 정한다. M0/M1 두 조건은 독립 반복 두 번이 아니다.

## 결과로 말할 수 있는 범위

주 대상은 지정한 설정 두 수준에 따른 전도도 차이다. 실제 속도 대비가 구현됐는지는 별도로 확인한다. 배정·측정의 전제가 충족돼야 해당 설정 대비의 효과를 해석할 수 있다. 따라 달라지는 열·압력 이력을 제거한 ‘속도만의 직접 효과’, 배향만의 원인, 전단률 효과로 확대하지 않는다. 예상 차이의 방향이나 크기는 현재 정하지 않는다.

압력 제한·장비 제약 등으로 목표를 달성하지 못해도 원래 배정과 이탈 기록을 보존한다. 달성 시편만 사후 선별하거나 실제 속도에 따라 조건명을 바꾸어 원래 비교로 보고하지 않는다. 배정 설정 결과를 기술하는 것과 의도한 낮음·높음 실제 속도 대비가 구현됐다는 판단을 구분한다. 이탈·결측·재시도의 사전 분석 규칙은 D2에서 정한다.

공통 접촉 절차가 접촉 기여를 제거하지는 않는다. 배향·연결망·다른 공정 변화·접촉은 가능한 설명으로 남긴다. 차이가 작아도 배향 변화가 없었다고 결론 내리지 않는다. 기계적 물성은 별도 후속 평가다.

## 검토에서 바꾼 것

- 소재·방법 검토: 모호했던 ‘배율 순서’를 **배율의 크기 관계**로 변경했다.
- 실행 검토: ‘같은 프로파일’에 **공통 기준축·단계 경계**를 명시했다.
- 방법·실행 검토: **설정 배정 결과와 실제 속도 달성**을 구분하고 사후 재분류를 금지했다.

근거는 [Atlas QA](../atlas-review/atlas-qa.md)와 [설계 v0.2](../atlas-review/minimal-design.md)다. 이번에는 전달 QA를 검토했으며 원문 PDF를 직접 재확인하지 않았다. 원문 위치·출처 해시는 QA 원기록을 유지한다. 실제 초기·반박·최종 의견은 reviews/에 보존한다. 에이전트 의견 일치는 실험적 증거가 아니다.

## 남은 일의 경계

D1은 조작 요인·두 수준의 관계·공통 조건·해석 범위를 정하는 작업이다. D2는 측정·분석 방법과 실행 경계를, D3는 CSV 연결을 정한다. 실제 배합 명세·장비 모델·수치·반복 수·측정 적합성·자원·권한은 D4 착수 판단 전에 확인한다. 현재 가상 정의를 실제 실행 가능한 수치 명세나 M1 완료로 사용하지 않는다.
