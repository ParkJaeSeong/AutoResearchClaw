# D2 비교·분석 명세

설계 검토안 v1. 주 비교는 D1의 **높은 사출 속도 설정(M1) − 낮은 설정(M0)**이며 [측정 방법](measurement-method.md)에 따른 양의 유효 전도도를 사용한다. 실제 분석·가상 물성 시뮬레이션은 아직 수행하지 않는다.

## 배정과 반복 단위

동일 원료 배치 안의 대응 블록마다 M0·M1 제조 실행을 하나씩 배정한다. 각 블록의 실행 순서를 사전에 무작위 배정하고 전체 일정에서 순서가 한 조건에 쏠리지 않도록 배치한다. 모든 블록을 동일 순서로 수행하거나 조건마다 날짜·배치를 분리하지 않는다. 난수 방식·시드·예정 순서와 실제 순서를 모두 남긴다.

독립 제조 실행은 별도 설정 적용·안정화·채취 구간으로 정의한다. 실제 장비에서 시작/종료·설정 전환·안정화·잔류 판정과 공통 원료 취급을 확인해야 하며, ID 발급만으로 독립성을 인정하지 않는다. 같은 실행의 여러 시편, 재접촉, 반복 읽기는 제조 반복 수에 더하지 않는다.

여러 블록이 같은 원료 로트에 속하면 결론은 그 로트와 명시한 실행 환경에 한정한다. 로트 간 일반화가 목표라면 로트를 포함하는 배정·분석으로 개정한다. 블록 간 의존이나 잔류가 무시할 수 없다면 아래 단순 대응 구간법의 적용을 보류하고 계층·시간 의존을 포함한 분석을 사전 선택한다.

## 주 척도와 집계

주 척도는 log10(σ / (1 S/cm))다. 양의 유효 전도도만 이 변환을 적용할 수 있다. 제조 실행 안에서 사전에 정한 채취 위치·시편 수에 따른 시편 대표 로그값을 동일 가중 평균한다. 시편 대표값은 첫 유효한 사전 계획 시도를 사용한다. 반복 읽기는 그 시도의 R 추정에 포함하며 별도 시편처럼 세지 않는다. 확인용 재접촉은 주 시도에 임의로 추가 평균하지 않는다.

첫 시도가 측정 절차상 부적합하면 이유를 기록하고 동일 방법의 재시도를 허용한다. 원래 값이 예상과 다르거나 제조 목표 속도를 달성하지 못했다는 이유는 측정 재시도·유효 결과 교체 사유가 아니다. 장비·방법 변경이 필요한 재측정은 새 방법 버전과 영향 판단을 먼저 기록한다. 허용 재시도 횟수와 비용·시간 한계는 실행 자원과 함께 사전에 확정하며 무제한 재시도로 좋은 값만 남기지 않는다.

각 대응 블록 b의 차이 d_b = 실행평균(M1) − 실행평균(M0), 전체 대비 Δ는 블록 차이의 동일 가중 평균이다. 10^Δ는 위 로그 집계에서 정의한 기하평균 비율이며 원래 전도도의 산술평균 비율이 아니다. 시편 수가 많다는 이유로 특정 제조 실행의 가중치를 늘리지 않는다.

## 불확실성과 판단

독립적인 블록 차이와 대응 t 구간의 적용 조건이 성립할 때 **양측 95% 구간**을 기본으로 한다. 블록 수 B, 블록 차이의 표준편차 s_d에 대해 Δ ± t(0.975, B−1)·s_d/√B를 사용한다. 이것은 개별 시편 산포나 측정 불확실성 전체를 대신하지 않는다. 특히 B가 작아 분포 가정을 평가하기 어려우면 확증 판단을 유보한다. 결과를 본 뒤 가장 유리한 구간법을 고르지 않는다.

의미 차이 δ>0는 같은 로그 척도의 경계다. 사용 목적에서 허용할 전도도 비율 R*>1을 먼저 정하고 δ=log10(R*)로 변환한다. R*의 응용 근거가 없으므로 지금 숫자를 만들지 않는다. 탐색적 Δ·구간 보고와 의미 차이 판정은 구분한다.

| 유효 95% 구간 [L,U] | 판정 |
| --- | --- |
| 전체가 [-δ,δ] 안 | 지정 조건에서 작은 차이 지지 |
| L>δ 또는 U<−δ | 해당 방향의 의미 있는 차이 지지 |
| 그 밖 | 의미 차이와 작은 차이를 구분하기에 불충분 |
| δ 미정 또는 측정·분석 전제 미충족 | 해당 의미 차이 판정 보류 |

이 분류는 지정 95% 구간에 대한 판단 규칙이며 별도의 유의성 검정을 수행했다는 뜻이 아니다. 유의하지 않음을 동등성으로 바꾸지 않는다.

## 결측·한계·이탈

모든 배정·시편·실패·재시도를 흐름표와 수량으로 보존한다. 유효 관측만 남긴 분석을 원래 배정 전체의 결과로 보고하지 않는다. 계획 시편 중 결측/한계값이 있으면 해당 제조 실행과 대응 블록을 결측 영향 대상으로 표시한다. 완전 관측 블록만의 요약은 탐색적으로 분리하며, 결측 원인·패턴과 타당한 결측/검열 분석법을 사전 확정하기 전 전체 배정에 대한 확증 판단을 보류한다. 한계값에 임의 상수를 대입하지 않는다.

제조 속도 목표 미달은 원래 M0/M1에 남기고 이탈로 표시한다. 실제 달성 시편만 골라 조건을 재정의하지 않는다. 별도 달성 집단 분석은 후속 탐색이며 원래 배정 대비를 대신하지 않는다.

## 수량·중단·다음 방향

본 실험 블록 수와 실행당 시편 수는 아직 미정이다. 방법 담당이 응용 경계 R*, 목표 구간 반폭 h, 근거 있는 블록/시편 변동 추정과 측정 오차·탈락 예상, 예산을 입력받아 반복 설계를 확정한다. h≤δ/2를 계획 후보로 두되 실제 근거와 비용에 따라 실행 전 선택한다. 평균 차이만 보고 필요한 반복 수를 정하지 않는다. 변동 근거가 없어 새 예비 실험이 필요하면 그 예비 실험도 별도 착수 준비를 갖춰야 하며 수행한 것으로 처리하지 않는다.

계획한 블록을 마쳤을 때 분석한다. 유리한 결과가 나올 때까지만 반복하지 않는다. 안전·장비 제한, 추적성 상실, 측정 부적합 또는 사전 자원 한계에 도달하면 해당 작업을 중단하고 원자료·재개 위치를 보존한다. 자원 한계의 실제 수치는 장비·예산·일정 결정 후 명시하며 임의의 10분 제한을 추가하지 않는다.

의미 차이가 있으면 배향·연결망·접촉·다른 공정 설명을 구분할 후속 관측을 제안한다. 작은 차이면 해당 설정 범위에서 다음 조작 요인을 재검토한다. 불충분이면 측정 품질/정밀도/결측 원인을 먼저 구분하고 필요한 보완만 배정한다. 이 비교 하나로 연구 에이전트의 예측·실험 선택 효율성 H1/H2가 검증되지는 않는다.

## 방법 근거

[NIST 대응 관측 분석](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm)과 [두 평균 차이의 구간](https://itl.nist.gov/div898/handbook/prc/section3/prc312.htm)을 2026-09-13 확인했다. 대응 차이의 평균·표준오차와 t 구간의 형식만 참고했다. 로그 척도·집계·95% 수준·판정 경계 구조는 Pilot의 이번 설계 선택이며 NIST가 본 소재 실험의 적합성을 검증한 것은 아니다.
