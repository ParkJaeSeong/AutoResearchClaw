# D1 검토 입력: 제조 조건 두 가지

이번 결정은 가상 PC/CNT 실험의 조작 요인 정의다. 완료된 6단계(근거 종합·사용 판단)를 다시 열지 않는다. 수치·장비 모델·반복 수를 정하거나 실제 실험을 허가하는 작업이 아니다.

제안: 같은 배합·사출기·금형에서 충전 구간 사출 속도 설정을 낮음(M0)과 높음(M1)으로 비교한다. 같은 속도 프로파일 형태에 서로 다른 배율을 적용하고 두 배율의 순서를 고정한다. 실제 수치는 장비 결정 후 정한다. 이 선택은 Pilot의 가상 설계 제안이며 Atlas 문헌의 처방이 아니다.

배합·원료 로트 연결, 건조 절차, 금형·시편 형상, 용융·금형 온도 설정, 속도에서 압력으로 전환하는 기준, 보압·냉각 설정은 공통으로 계획한다. 공통 설정이 실제 온도·압력 이력까지 같다는 뜻은 아니다. 속도 변화로 따라 달라진 이력과 날짜·배치 등 외부 요인을 구분한다.

명령한 속도와 실제 속도는 별도다. 압력 제한 등으로 목표를 달성하지 못하면 원래 속도 대비를 실행했다고 주장하지 않는다. 이탈 자료와 원래 배정은 보존하고 실제 속도 효과 해석은 보류한다. 실제 속도·충전 시간·압력·온도·전환 상태의 관측 가능성은 장비 선정 시 확인한다.

같은 원료 배치 안에서 두 조건을 비교하고 조건 순서가 날짜에 고정되지 않도록 배정한다. 실행 경계·안정화·잔류 처리와 반복 수는 D2에서 정한다. 두 조건은 반복 두 번을 뜻하지 않는다.

측정은 기존 D0(시편 좌표에 정의된 전류 경로), P0(적합성을 확인할 공통 접촉 절차)를 유지한다. D2에서 정량 방법을 구체화한다. 목표는 지정 설정 대비의 전도도 차이다. 배향·전단률만의 효과, 차이의 방향·크기, 기계적 물성 개선은 주장하지 않는다.

공통 근거는 ../atlas-review/atlas-qa.md 및 ../atlas-review/minimal-design.md다. Atlas의 QA 전달 내용을 읽은 것이며 이번에 원문 PDF를 직접 검증하지 않았다. 다른 에이전트 초기 의견은 모두 제출되기 전 읽지 않는다. 같은 모델·공유 파일시스템이며 독립성은 입력 공개 순서와 지시 수준이다.

검토 질문: 이 범위에서 요인 정의를 확정할 수 있는가? D1을 실제로 막는 모호함과 D2 이후 확인을 구분하라. 발언은 쉬운 한국어로 판단→이유→다른 의견에 대한 답(초기에는 미공개)→다음 작업. 새 문헌 탐색·추측한 수치·강제 합의 금지.
