# D1 실행 최종 의견

**판단: D1의 가상 요인 정의에 한정해 완료할 수 있다.** 실제 수정안 `manufacturing-contrast.md`에서 배율의 크기 관계와 실행 순서 분리, 공통 기준축·단계 경계·적용 구간, 구현 불가 시 재검토, 배정 설정 결과와 실제 속도 달성의 구분, 달성 시편 사후 선별·재분류 금지를 확인했다. 초기 실행 검토에서 지적한 모호함이 해소됐다.

**이유와 다른 의견에 대한 답:** 소재 응답이 공통 기준 원칙을 D1에 남긴 데 동의하며, 방법 응답의 ‘배정 기록만으로 효과 추정이 유효해지지 않는다’는 지적도 수정안의 배정·측정 전제에 반영돼 있다. 세 응답을 읽었고 실행 관점의 추가 D1 차단 사항은 없다. 이 동의는 새로운 실증 근거가 아니다.

**다음 작업:** D2에서 실제 대비 달성 판정과 관측 한계, 수동 설정 확인·작업자·전환 시각 기록, 실행·안정화·잔류·채취 경계, 이탈·결측·재시도 규칙을 명세한다. 장비 구현성과 수치, 측정 적합성·자원·권한 등은 실제 착수 판단 전에 확인한다. D1 완료를 실제 실험 허가나 M1 전체 완료로 사용하지 않는다.
