# 004 후속 근거 검토와 설계 보완 결론

2026-09-14 · 새 작업 회차 005 `pilot-measurement-review-20260914-v1`

**문헌 3건과 공식 설명 1건은 가상 측정 배치를 구체화하는 데 사용한다. PC/CNT의 정량 전도도 환산은 실제 형상·모델·품질 근거가 갖춰질 때까지 보류한다.** 이 범위로 근거 검토와 설계 문서 보완을 마쳤다.

사용자의 “마무리하자.”는 004 결과에 이어 근거 검토·가상 설계를 진행하라는 지시로 기록했다. 004의 원래 결론은 보존하고, 005에서 003의 배치안을 다시 검토했다. 005의 새 결과에는 아직 사람의 개발 검토를 기록하지 않았다. 이번 지시를 앞으로 나올 결과의 승인으로 확대하지 않는다.

## 이번에 정한 것

| 결정 | 이유 | 결과물 |
| --- | --- | --- |
| 전류는 양 끝면 전체, 전압은 윗면의 두 띠를 가상 후보로 선택 | 부착면·피복·경계를 구체적으로 기록하며 적합성을 검토할 수 있음 | [전극 배치 v2](electrode-layout-v2.md) |
| 중심 간 거리 Lv_geom과 환산 거리 Lv_eff를 분리 | 도면상 거리가 전기적으로 유효하다는 근거 없는 대입 방지 | 같은 문서의 거리 정의·환산 조건 |
| 모델과 오차 근거가 있으면 중심 거리 근사 채택 허용 | 유효 거리의 별도 직접 실측만 요구하는 불필요한 제약 방지 | 모델 채택/방법 개정 기준 |
| CSV 열을 유지하고 조건의 적용 범위를 구분 | 작업 공통 조건·시편 정보·당시 접촉 정보를 추적 | [CSV 연결 명세](measurement-csv-binding-v2.md) |
| 환산 불가 시 원시 I–V와 실패 이유 보존 | 자료를 잃거나 임의값을 정량 결과로 오인하지 않음 | 원자료·시도·재접촉·재시도 연결 |

끝면 전체 접촉과 윗면 띠는 Pilot의 후보 선택이다. 문헌 저자가 PC/CNT에서 검증한 도면이라고 부르지 않는다. 자료별 읽은 범위·허용 용도·미확인 내용은 배치 v2의 근거 표에 연결했다.

## 토론에서 바뀐 부분

첫 의견의 ‘Lv 계측값’은 전기적 유효 거리로 오해할 수 있어 **Lv_geom**으로 통일했다. 방법·분야 검토에서 제시한 Lv_eff는 반드시 별도로 직접 측정해야 한다는 뜻으로 읽히지 않도록 모델·불확실성 근거에 따른 근사 채택 경로를 열었다. 단면 전류 가정 자체가 맞지 않으면 거리 하나를 보정하지 않고 방법을 바꾼다.

실행 검토자는 처음에 모든 조건을 시도에 모으는 안을 냈다가, 토론 후 task/specimen/attempt로 구분했다. 최종 검토에서 작업 ID·방법 ID·접촉 회차 연결을 추가했다. 방법 검토자는 기준을 미리 정하는 것에 더해 **실제 평가·점검 결과가 기준을 충족할 것**을 요구했다. 두 수정은 문서에 반영하고 각 담당자가 다시 확인했다. 남은 설계 문구의 필수 수정은 없으며, 아래 실증·착수 조건은 그대로 남는다.

## 실제 대화 기록

세 역할이 동일한 고정 입력으로 초기 의견을 작성했다. 전원 초기 제출 뒤 공개·응답, 전원 응답 뒤 동일 수정안에 대한 최종 검토를 했다. 총 9개 원발언과 수정 확인 2개를 보존했다. 초기 의견은 지시로 분리했으며 공유 파일시스템 접근을 기술적으로 차단한 것은 아니다. Codex 협업 도구의 별도 문맥으로 실행했고, 여러 모델 간 검증이나 native council 실행으로 표시하지 않는다.
