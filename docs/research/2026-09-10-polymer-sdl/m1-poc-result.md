# M1 POC 결과

**M1 POC를 가상 실험 설계와 CSV 전달 검증 범위로 마무리했다.** 사용자의 2026-09-15 요청에 따라 실제 장비 확정과 과학적 성능 입증은 이번 완료 조건에서 분리한다. 이 문서는 조정자가 기존 검토·설계·검증 결과를 묶은 최종 요약이다.

자료를 전부 읽었다거나 문헌 목록 전체가 검증됐다는 뜻은 아니다. 단계 기록 중 자체 수집·추출 경로의 미완료 표시는 보존하며, 이번 사례는 Atlas 외부 근거 경로를 사용했다. 조정자가 도구와 검토자를 연결해 수행한 POC이고, 전체 과정의 무인 자동 실행을 검증한 것은 아니다.

## 최종 가상 실험안

**질문:** 동일 배합 PC/CNT에서 사출 속도 설정을 낮게/높게 바꾸면, 지정한 측정 조건의 전기전도도에 어떤 차이가 나타나는가?

- **비교:** 같은 원료·사출기·금형·공통 프로파일에서 속도 명령 배율 두 수준을 배정한다. 설정값과 실제 달성 이력을 구분한다. 문서의 M0/M1은 제조 조건명이며 마일스톤 번호가 아니다.
- **판단 틀:** 목적상 의미 있는 차이, 실용적으로 작은 차이, 판별 불충분을 구분한다. 방향·크기를 문헌이 예측했다고 설명하지 않는다.
- **측정:** 양 끝면의 전류 접촉과 윗면 두 전압 띠를 가상 후보로 삼는다. 도면상 거리와 환산에 사용할 유효 거리를 구분하고, 모델·품질 조건이 충족될 때 정량 환산한다.
- **분석:** 제조 실행과 시편·재접촉·읽기의 반복 단위를 구분한다. 대응 블록별 로그 전도도 차이와 불확실성을 보고, 실제 의미 차이 경계와 수량은 실행 환경에 맞춰 확정한다.
- **기록:** 작업→제조 실행→시편→측정 시도→원자료를 연결한다. 실패·재시도·정정 이력을 보존하며 미확인 값을 임의로 채우지 않는다.

전도도 차이만으로 배향·연결망·접촉 중 단독 원인을 확정하지 않는다. 원래 연구 질문인 물성 예측 개선, 가설 선택 효과, 실행 전 검사 효과(H1/H2/H3)의 성능을 이 비교로 입증한 것도 아니다.

## POC 이후로 넘기는 것

| 구분 | 처리 |
| --- | --- |
| 실제 장비·재료·시편·구동값·측정 적합성·반복 수·자원과 권한 | [D4 착수 입력표](experiment-design/d4-start-inputs-20260915.md)와 [입력 CSV](experiment-design/d4-start-inputs-20260915.csv)에 보존. 실제 실험 착수 전에 확인 |
| 근거·가설·평가 설계 쟁점 | 현재 쟁점 29개 중 미해결 25개, 기존 해결 4개 상태 유지. 개별 질문·현재 범위·재개 조건은 [쟁점 인계 목록](m1-poc-issues.md) 참조 |
| 정량 효과·기전·예측/선택법 성능 | 새로운 실제 연구 검증 과제. 이번 POC에서 결과를 만든 것으로 처리하지 않음 |
| 전체 무인 실행, CSV 자동 수신, 장비 자동 제어, 첨부 의미의 자동 검증 | 후속 제품·실증 범위. 이번 POC 완료를 위해 추가 구현하지 않음 |

**POC 완료와 실제 실험 착수 준비는 별개다.** 실제 연구의 승인·쟁점·준비·인계 조건은 그대로 둔다. 따라서 원래 연구 그래프가 실험 준비 미완료를 표시하는 것은 유지된다. 이번 완료는 범위가 명시된 POC 결론이다.

## 재현과 결과의 성격

```sh
.venv/bin/python -m researchclaw.codex.lab_csv docs/research/2026-09-10-polymer-sdl/virtual-lab/v2/examples
.venv/bin/python -m pytest tests/codex_native/test_lab_csv.py -q
```

2026-09-15 재검증: 합성 예시 구조 검사 통과, 작업 4행·시편 2행·조건 5행·결과 3행, 오류 0건. 관련 검사 55개 통과. 합성 수치와 원자료는 소프트웨어 검사에만 사용했으며 실제 물성 측정·시뮬레이션 결과가 아니다. `scientific_usable=false`, `m1_ready=false`는 실제 실험 경계를 보존하는 정상 결과다.

최종 산출물과 검증 자료의 경로·해시는 [POC 묶음 목록](m1-poc-manifest.json)에 보관한다. 기존 원문·발언·설계 파일은 덮어쓰지 않는다. 이번 정리에서는 새 문헌 수집·Atlas 질의·과학적 토론·실험을 수행하지 않았다.

**다음 재개 조건:** 실제 실증을 하기로 할 때 D4 입력을 채우거나, 별도의 연구 주제로 동일 흐름을 재현한다. 이 POC를 닫기 위해 추가 자료를 계속 수집하거나 장비 선택을 기다리지 않는다.
