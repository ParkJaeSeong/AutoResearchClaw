# 연구 질문 차단 범위 검토와 적용

**연구 질문 단계가 진행 가능 상태가 됐다.** 8개 필수 쟁점에서 질문 단계의 차단만 제거하고, 미해결 조건이 M1 최종 검토와 M2 인계를 계속 막도록 변경했다. 쟁점 22개는 모두 열린 상태다.

## 판단이 나온 과정

[쟁점 영향 분류](issue-impact-review.md)를 바탕으로 변경안을 고정했다. 소재·방법론·반증 검토자가 독립 초기 의견 → 공개 의견 교환 → 최종 판단 순서로 실제 검토했다. 신규 제출 9개를 저장된 원응답과 대조했고, 각 라운드의 공개 범위를 확인했다. 기존 제출을 포함한 누적 기록은 72개다.

세 역할 모두 추가 조건 없이 명시된 변경안을 수용했다. 공통 판단은 다음과 같다.

- 자료의 실측·대체·미상 구분표, 평가 기준, 경쟁 설명과 필요한 관측, 실행 전 검사 요구사항은 작성할 수 있다.
- 미확정 자료로 검증 가능성을 확정하거나 학습·효과 판정·실험을 시작하는 것은 계속 보류한다.
- 질문 준비를 허용하는 것과 자료 사용 승인·과학적 쟁점 해소는 다르다.

이 요약은 조정자의 해설이다. 역할별 원래 발언은 UI의 **질문 단계의 진행 조건 검토 → 검토자 대화 보기**에 연결했다. 이번 검토자는 제공된 변경안과 쟁점만 읽었다. 문헌 원문을 새로 확인하거나 실제 차단 코드를 검증한 것이 아니다. 모델 다양성·통계적 독립성·강제 파일 접근 격리를 주장하지 않는다.

## 무엇이 바뀌었나

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 연구 질문 | 미해결 쟁점으로 진행 불가 | 검토된 현재 질문에서 진행 가능 |
| 조정한 8개 쟁점 | questions 단계 차단 | review 단계와 M1→M2 인계 차단 |
| 원래 쟁점·해소 조건 | 보존 | 그대로 보존 |
| 자료 승인·근거 검증 | 기존 조건 필요 | 그대로 필요 |
| 실제 학습·실험 | 시작하지 않음 | 시작하지 않음 |

변경은 현재 질문 개정과 해당 쟁점 상태·영향 분류에 묶인다. 질문이나 해당 판단이 바뀌면 원래 차단으로 돌아가 재검토한다. 원래 차단 범위와 적용 이력은 삭제하지 않는다. 검색 계획 같은 후속 단계의 개정만으로 승인된 질문 범위를 다시 차단하지는 않는다.

## 적용 기록과 남은 작업

- 적용 HEAD: `15b51f3e86d2df469ef1c8c68061132fe635550c52b141b98ce5b697dda2e2f5`
- 이번 협의: `005063ba-5f21-4b47-a212-f1501dcabba5`
- 원응답·입력·실행 상태: 연구 작업 공간의 `question-scope-review-01/`
- 실행 스크립트: `review_question_scope.py`. 결과가 저장된 호출은 재사용하며, 미완료 호스트 시도가 있으면 덮어쓰지 않고 확인을 요구한다. 임의 시간 제한으로 종료하지 않는다.

**다음 연구 작업은 현재 질문에 맞춰 검색 계획과 문헌 선정안을 갱신하는 것**이다. 기존 검색·선정은 이전 입력에 묶여 재검토가 필요하다. 그 뒤 기존 후보·수집 자료를 근거 추출과 종합에 연결한다. 별도 개발 과제 R3는 사전 허용 범위의 자율 선정과 실제 사용자 승인 기록을 구분하는 경로다.

이번 구현은 M1 questions 범위를 좁히는 경로다. 다른 단계의 임의 차단 해제나 M1 전체 완료 기능으로 확장하지 않았다. 새로운 실험 설계·실행 준비 단계 연결은 R4·R5에서 다룬다.

## 검증 결과

- 기존 단계·검색·근거·검토·인계 회귀 검사 84개 통과.
- 신규 차단 범위 검사 8개, 영향 평가 11개, 자료 등록 13개, 뷰어 4개 통과.
- UI 자동 검사 20개 통과. 검토 전 변경안과 일부 적용 건수도 표시한다.
- 실제 에이전트 원응답 9개와 등록된 발언의 일치를 확인했다.
- 현재 API와 과거 HEAD, 제공되는 UI 파일을 확인했다. 브라우저 시각 검수는 사용 가능한 브라우저 연결이 없어 수행하지 못했다.
