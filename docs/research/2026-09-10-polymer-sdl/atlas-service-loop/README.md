# Abbasi 측정 방향: Pilot–Atlas 실제 왕복

2026-09-13. 정식 후속 질문을 Atlas에 보내고, 받은 답변을 세 연구 검토자가 세 회차에 걸쳐 검토한 뒤 연구 결정을 기록했다.

## 결론과 다음 행동

기존 D2의 **시편 x방향 전도도 비교 설계를 유지**한다. Atlas가 전달한 압축 원판의 두께 방향 측정을 x방향과 같다고 보지 않는다. 사출 시편의 유동 평행·수직 해석과 문헌 수치의 직접 적용은 추가 자료 확보 전까지 보류한다.

Atlas는 공용 자료실의 Abbasi(2010) 원문 v1을 보충 근거로 조회했다. 압축 원판의 두께 방향 DC 측정은 저자 보고로, 이를 성형 좌표 z와 반경 유동 r에 대응시키는 것은 Atlas 해석으로 구분했다. 사출 시편의 전극 배치·전류 방향·측정 온도·독립 반복 수는 미확인으로 남겼다. Pilot 검토자들은 제공된 QA를 읽었으며 PDF를 직접 재검증한 것이 아니다.

교차 검토에서는 공통 접촉 절차와 재측정 안정성만으로 공정별 접촉 편향이 배제되지 않는다는 한계를 명확히 했다. 의견 일치는 새 실증 근거로 집계하지 않았다. 실제 장비 조건·독립 반복 수·판단 기준·접촉 적합성은 착수 전 확인 대상이다.

**다음은 Pilot의 자료 확보**다. 공정별 전극·배선 도면, 시편 채취 위치, 접촉 면적·거리 정의, 측정 온도·독립 반복 기록이 필요하다. 새 자료 없이 같은 Atlas 질문을 반복하지 않는다. 기존 질문은 일부 확인/일부 미확인으로 이 결정에 연결되며, 같은 질문을 중복 생성하거나 쟁점 해소·M1 완료로 바꾸지 않았다.
