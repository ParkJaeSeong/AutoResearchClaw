**최신 설계는 [제조 두 조건 비교 v0.2](atlas-review/minimal-design.md)다.** 아래 v0.1은 이전 검토 이력이며, 모든 비교에 네 조합과 Raman을 요구하는 것으로 읽지 않는다.

# 제조·측정 실행 명세 v0.1

**상태: 설계 초안 작성, 실제 실행 보류.** [가설 교차 검토의 결론](hypothesis-review/decision.md)을 실행 항목으로 옮긴 조정자 명세다. 새 에이전트 심사나 실제 장비 점검을 수행한 것은 아니다. 장비·원료·자원이 지정되지 않아 수치 조건을 임의로 채우지 않았다.

이 문서는 실제 PC/CNT 제조·측정을 연결할 때 사용할 설계다. 공개 CSV를 분석하거나 저장값을 다시 재생하는 것만으로 아래 물리 대조가 수행되지는 않는다. 계산 평가를 먼저 진행한다면 허용 질문을 기존 관찰 자료에서 답할 수 있는 범위로 좁히고 H2의 참조 결과·평가 환경을 별도로 마련해야 한다.

## 1. 무엇을 비교할 것인가

기준 배합은 CNT 함량과 PC 공급원 구성을 고정한다. 값은 원료·성형·측정 가능 범위를 확인한 뒤 본 실험 전에 지정한다. 제조 조건 M0/M1, 실제 전류 방향 D0/D1, 접촉 절차 P0/P1은 아래 의미를 가진다. 숫자 0/1은 두 대조의 이름이며 실제 장비 설정값이 아니다.

| 기호 | 고정할 정의 | 기록할 내용 |
| --- | --- | --- |
| M0/M1 | 가능하면 같은 장비·금형에서 하나의 제조 설정만 다르게 한 두 조건 | 조작 변수·수준·단위, 실제 온도·압력·시간, 원료와 성형 실행 ID. 여러 설정이 바뀌면 공정 묶음 비교로 제한 |
| D0/D1 | 시편의 재료 좌표에 대해 정한 두 전류 방향 | 시편 도면, 국소 유동 방향, 채취 위치, 전류 경로·거리·단면. 시편 회전만으로 방향 변경을 인정하지 않음 |
| P0/P1 | 같은 방향·측정 영역에 적용 가능한 두 접촉 절차 | 전극 재료·면적·압력·표면 처리 중 바꾸는 항목과 고정 항목. 두 절차의 적합성은 각각 확인 |
| S | 우선 후보인 편광 Raman 방향별 신호 대비 | 편광 설정·관측 위치·깊이, 신호 처리, 기기 응답·배경·신호 부족 규칙. 검증된 배향계수로 취급하지 않음 |

## 2. 필요한 비교 조합

아래는 필요한 **조건 조합**이며 시편 수나 반복 수가 아니다. 독립 제조 반복 수와 하위 측정 반복 수는 따로 산정한다. 전부를 같은 시편에 적용할 수 있다는 가정도 하지 않는다.

| 조합 | 조건 | 답할 질문 | 지위 |
| --- | --- | --- | --- |
| E01 | M0 · D0 · P0 | 기준 제조의 전도도 | A 주 비교의 기준 |
| E02 | M1 · D0 · P0 | 제조 변경의 전도도 효과 | A 주 비교: E02−E01 |
| E03 | M0 · D0 · P1 | 기준 제조에서 접촉 변경 | B1 주 비교에 필요 |
| E04 | M1 · D0 · P1 | 변경 제조에서 접촉 변경 | B1 주 비교: (E04−E03)−(E02−E01) |
| E05 | M0 · D1 · P0 | 기준 제조의 방향 차이 | B2 보조: E05−E01 |
| E06 | M1 · D1 · P0 | 변경 제조의 방향 차이 | B2 보조: E06−E02; 두 방향 차이의 제조 간 변화도 보고 |
| S01/S02 | M0/M1의 지정 대응 위치에서 S 관측 | 지정 구조 지표 변화가 동반되는가? | A의 별도 구조 결과; 전도도 관측과 연결 |

E01–E04가 최소 제조·접촉 비교다. E05–E06은 방향 비교가 가능할 때 연결한다. D1·P1 조합은 현재 질문의 필수 조합으로 늘리지 않는다. 방향과 접촉의 결합 효과를 추정하려면 별도 조합과 자원 근거가 필요하다. Raman 지표의 편광 두 방향은 전도도 보조 방향 비교와 달라 S 관측에서 생략할 수 없다.

## 3. 시편 배정과 측정 순서

1. 같은 원료 묶음에서 제조 조건을 부여할 성형 실행을 구분하고 실행일·원료 로트가 특정 조건에 몰리지 않도록 배정한다. C의 배합 대조는 별도 배합·혼련 단위다.
2. 각 실행에서 채취 위치와 시편 ID를 부여한다. 최종 치수·전극 도면·전류 경로를 기록한다. 기존 자료의 1.2 mm를 새 시편 두께로 대입하지 않는다.
3. 비파괴 접촉 변경이 적합하다고 확인되면 시편별 P0→P1 / P1→P0 순서를 균형 있게 배정하고 실제 순서를 남긴다. 손상·비가역 변화가 있으면 교차 반복 대신 같은 배치의 대응 시편 설계를 사전에 선택한다.
4. 접촉을 유지한 반복 읽기, 접촉 재설정, 다른 접촉 절차, 다른 방향 측정을 별도 회차로 기록한다. 장비 범위·온도·시간 드리프트·손상 기록을 남긴다.
5. 구조 관측과 전기 측정이 서로 영향을 주지 않는 순서를 확인한다. 절단·코팅 등 파괴 관측은 전기 측정 뒤 또는 대응 시편에 수행한다. Raman도 비손상을 확인하지 않고 자동으로 같은 시편 순서를 고정하지 않는다.
6. 방향 변경이 측정 영역·형상을 함께 바꾸면 그 관계를 도면에 남긴다. 대응 시편의 비교를 동일 시편의 비교라고 기록하지 않는다.

## 4. 결과와 판정 규칙

분석값은 같은 단위로 확인된 전도도의 로그값을 우선 후보로 한다. 로그 밑·환산식·검출 한계·장비 범위와 한계 이하 값 처리 방식을 실행 전에 확정한다. 한계 이하 값을 임의의 작은 양수로 바꾸지 않는다.

- **제조 효과:** Δ0=E02−E01. 구조 관측의 변화와 별도로 효과·불확실성을 보고한다.
- **접촉 기여:** Δ1=E04−E03, I=Δ1−Δ0. 크기 감소 R=|Δ0|−|Δ1|와 부호 반전도 함께 보고한다. 같은 자료에서 계산된 양들의 의존성을 유지한다. I가 작아도 공통 접촉 편향은 배제하지 않는다.
- **작은 차이 확인:** 전체 불확실성 범위가 사전 지정한 작은 차이 범위에 들어와야 한다. 단순히 유의하지 않다는 결과는 판단 불가와 구별한다. 의미 있는 감소는 R의 사전 최소 감소량 기준으로 판단한다.
- **구조 연결:** 적합한 구조 관측에서 S 차이가 정밀하게 작은데 전도도 차이가 남으면 지정 구조 설명을 약화한다. 구조만 변하고 전도도 차이가 정밀하게 작으면 지정 구조→전도도 연결을 약화한다. 감도·대표성이 부족하면 판단 불가다. 두 값의 동반 변화는 구조의 인과 효과 입증이 아니다.
- **반복과 분석:** 제조 조건을 부여한 독립 실행의 변동과 시편·접촉·읽기의 하위 반복 관계를 보존한다. 반복 읽기로 제조 표본 수를 늘리지 않는다. 신뢰수준·다중 비교 처리·배치 변동에 맞는 분석법은 수치 명세에서 고정한다.

결과를 본 뒤 주 지표·위치·작은 차이 기준을 바꾸어 같은 가설의 성공으로 처리하지 않는다. 변경은 사유·이전 버전·후속 가설에 연결한다.

## 5. 필수 입력과 영향받는 작업

| 입력 | 확인 책임 | 확인할 자료 | 없을 때 보류되는 범위 |
| --- | --- | --- | --- |
| 원료 등급·로트·함량·공급량 | 소재·실행 담당 | 공급 기록·조성 근거·사용 가능량 | 배합·제조 실행. C는 추가 PC 원료와 독립 배합 범위 확인 전 별도 보류 |
| 제조 장비·금형·조작 범위 | 실행 담당 | 실제 장비 목록·사용 절차·형상 범위 | M0/M1 설정 확정과 제조 실행 |
| 전극 배치·측정 범위·치수·환산식 | 실행 담당 | 실제 시편 도면·장비 자료·접촉 적합성 근거 | E01–E06 정량 측정 |
| Raman 감도·관측 대표성·손상 | 소재·실행 담당 | 장비 자료·신호 처리 규칙·사용 가능한 기존 검증 자료 | S01/S02와 배향 설명 판정. 제조·접촉 명세 작성은 계속 |
| 의미 차이·분산·반복 수·분석법 | 평가 담당 | 기존 변동 자료·목표 정밀도·허용 자원 | 확증 판정과 본 실험 수량 확정 |
| 예산·예약·작업자·안전·권한 | 실행 담당·조정자 | 실제 실행 환경의 허용 범위와 준비 기록 | 해당 환경에서의 착수 |

현재 위 실행 입력은 이 연구 기록에서 확정되지 않았다. 인터넷상의 장비 사양은 실제 보유·예약 가능성을 대신하지 않는다. 새로운 시료의 응답을 얻어 분산을 추정해야 한다면, 예비 실험의 별도 명세와 준비를 갖추고 M2에서 수행한 뒤 본 실험 설계로 되돌아온다.

## 6. 실패·원자료·재개

기록에는 계획 버전, 원료→배합→제조→시편→방향·위치→접촉→읽기 ID, 타임스탬프, 계획 조건과 실제 조건, 장비·작업자, 단위·품질 상태, 원시 파일 경로와 해시를 포함한다. 미상은 0으로 저장하지 않는다.

| 상황 | 처리와 재개 기준 |
| --- | --- |
| 범위 초과·신호 부족·단위 미확인 | 해당 정량 판정 보류. 원시값·한계·설정을 보존하고 적합한 범위 확인 후 재시도 |
| 접촉 손상·시간 드리프트·실제 조건 이탈 | 영향받는 비교 중단. 원인과 사용 불가 범위를 남기고 절차 수정·재검토 후 재개 |
| 실패·중단·재시도 | 첫 시도와 비용·시간·사람 개입을 보존. 재시도는 부모 시도 ID에 연결하고 성공값으로 덮어쓰지 않음 |
| 계획에 없던 장비·자원 필요 | 해당 작업 대기. 기존 허용 범위 내 기록 정리·독립 설계 작업 계속 |

기록 파일의 필드 점검은 시스템 점검이며 물리 검증 결과가 아니다. 현재 장비 연결·자동 실행·데이터 기록 코드를 구현했다는 뜻도 아니다.

## 7. 이번 명세의 완료와 다음 작업

이번에 정한 것은 비교 조합·측정 배정·분석량·실패 처리·필수 입력의 연결이다. 실제 수치 설정과 실행 준비 완료는 남아 있다. 판단 근거는 [교차 검토 원응답](hypothesis-review/README.md), 6단계의 남은 등록 작업은 [현재 단계 상태](stage6-status.md)에서 확인한다.

다음 우선 작업은 **현재 자료·질문 버전에 맞게 검색·선정 기록을 연결하는 등록 수정안**이다. 장비 정보가 없는 동안에도 진행할 수 있으며, 6단계 정식 완료를 직접 가로막는 항목이다.
