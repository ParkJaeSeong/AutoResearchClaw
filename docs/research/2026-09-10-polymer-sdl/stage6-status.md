# 현재 연구 진행 상황

**현재 PC/CNT 제조 조건 비교 사례의 6단계(근거 종합·자료 사용 판단)는 완료했다. D1 제조 대비, D2 측정·분석 구조, D3 CSV 검증을 마쳤고 현재 D4 착수 준비다. M1 전체 완료는 아직이다.**

| 작업 | 현재 상태 |
| --- | --- |
| 연구 질문 | 기존3개 보존, 제조 조건 비교 질문 추가·검토 완료 |
| 외부 근거 | Atlas QA1건 → 근거 묶음1개·주장3개 연결 |
| 근거 종합 | 4항목 등록, 세 역할×세 회차 검토 후 제한적 진행 |
| 비교 가설 | 의미 있는 차이·실용적으로 작은 차이의2개 초안 등록, 별도 세 역할×세 회차 검토 후 제한적 진행 |
| 원관측 연결 보완 | 독립 지적3개를 한 후속 작업으로 묶음. 미해결로 보존 |
| D1·D2 설계 | 사출 속도 설정 두 수준과 전도도 측정·비교 구조 검토 완료; 실제 수치 미정 |
| D3 파일 전달 | CSV v2·검증기, 55개 검사 및 독립 코드 재검토 통과 |
| 최종 검토·실험 준비·M2 인계 | 남은 쟁점25개를 최종 검토 초안에 연결. 준비7개 묶음은 미확인. 인계 미완료 |

[읽기 쉬운 초안과 검토 결과](atlas-review/synthesis-hypotheses.md), [연구 UI](http://127.0.0.1:8768/)를 확인한다. UI의 근거 종합 또는 가설 → 에이전트 대화에서 실제 발언을 볼 수 있다.

6단계 마무리 때18개 발언을 추가해 누적144개다. 기존26개 쟁점은 그대로이며 선택적 보완 지적3개를 추가했다. 원래22개는 미해결이고 이전 선정 지적4개는 해결 상태를 유지한다. 기존 질문·외부 답변·근거 묶음·승인·인계 기록은 바꾸지 않았다.

두 가설은 차이의 크기를 판정하는 틀이다. 문헌으로부터 특정 제조 두 조건의 변화 방향을 예측했거나 배향 기전을 판별한 것이 아니다. 작은 차이도 개별 작용의 부재를 뜻하지 않으며, 넓은 구간은 판별 불충분으로 남긴다.

현재 [진행표·D2 대화](experiment-design/README.md)와 [실제 착수까지 남은 준비](experiment-design/start-readiness.md)를 기준으로 이어간다. 다음은 실제 장비·재료·수치·반복·운영 정보 확정, 최종 쟁점 판단과 실제 준비 증거 확보다. 가상 설계·CSV 검사를 다시 시작하지 않는다.

착수 준비 초안과 미확인 이유를 정식 기록에 연결하는 B5a를 구현했다. 실제 검토·검증20건의 작업 원장을 복구했고, 기존 되돌림 한도3회 대비 기록7회의 정책 조건을 남겼다. 이후 B5b에서 항목별 증거 검증과 외부 인계·수신 기능을 구현하고 UI에 반영했다. 실제 준비 항목7개는 여전히 미확인이며, 준비 초안 등록이 완료 조건을 열지는 않는다. [사용 기준](../guides/m1-preparation-handoff.md).

검색·선정의 이전 질문 참조는 과거 버전으로 보존한다. Pilot이 자체 수집·추출을 완료했다고 처리하지 않았으며, 이번 종합·가설은 명시적인 Atlas 외부 근거 경로를 사용한다. 실제 실험·모델 학습·장비 제어·CSV 자동 수신은 수행하지 않았다.

## 완료 표시 정정

종합 노드의 실제 검토가 ready이고 외부 근거·사용 판단이 연결됐음을 서버에서 다시 확인했다. 이전 `stage6_complete: false`는 선택적 보완과 후속 M1 준비를 이 단계의 미완료 사유로 함께 취급한 보고 오류여서 정정했다. 연구 원기록·에이전트 발언·쟁점 상태·승인·인계는 바꾸지 않았다. 현재 사례 범위의 완료이며 기존 세 연구 질문에 필요한 모든 근거가 충족됐다는 뜻은 아니다.
