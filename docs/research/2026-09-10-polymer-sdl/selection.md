# 초기 문헌 선정안

이 5편 선정안은 첫 시험 기록이다. 사용자의 요청으로 더 넓은 독립 탐색을
[재시작](restart.md)했으므로, 이 목록을 최종 선정안으로 승인 요청하지 않는다.

2026-09-10. 초기 후보 5편을 DOI·저자 저장소로 표적 조회했다. 전체 문헌 검색이나
신규성 검증은 아니다. 관련 근거와 제약을 함께 남기기 위해 5편 모두 포함한다.
자료 포함은 데이터 사용 가능 판정이나 대표 소재 확정과 다르다.

| 자료 | 포함 목적 | 실제 확인 범위와 남은 일 |
| --- | --- | --- |
| P01 전기전도도·평가 누출 | 평가 방법을 반박·검증할 근거, 데이터 감사 우선 후보 | 초록과 공식 Figshare 파일 메타데이터 확인. XLSX 내용, 실험군·측정 조건·반복 정보는 미검사 |
| P04 입자 복합소재 열전도도 모델 | 체적분율·입자 크기·계면 열저항의 경쟁 설명 | 출판사 본문 일부 확인. 보충 데이터 단위·문헌 그룹과 계면 열저항이 실측인지 목표값 적합인지 확인 필요 |

조정자의 제안은 **전기전도도 자료부터 내용 감사를 시작하고, 열전도도 사례를
병행 비교하는 것**이다. 첫 후보는 파일 위치와 사용권을 확인했고 평가 누출을
직접 다루므로 평가 구조를 먼저 점검하기 좋다. 보고된 예측 성능으로 순위를
매기지 않았다. 특정 수지·필러를 지금 확정할 근거는 아직 부족하다.

## 다음 단계의 산출물

선정 검토 결과: 세 역할 모두 `ready_with_limits`. 검색 3개·선정 2개의 선택적
쟁점이 추가되어 총 14개가 열린 상태다. 선정의 2개는 독립 검토자가 제기한
동일한 분류 문제로 원본 제출을 보존했다. P01은 무작위 분할 평가의 타당성에
대한 제약 근거이며 **제안 에이전트 효과의 직접 반증은 미확인**이다. 이 문서의
설명이 native Issue의 검증·해결 기록을 대신하지는 않는다.

범위·질문·검색·선정의 실제 제출 36건을 호스트 응답과 대조했다. 현 상태의
유일한 진행 조건은 `corpus_approval_required`이며 승인 전이다.

1. 승인된 자료의 접근 범위·사용권·파일 해시·표/그림 위치를 연결한다.
2. 조성·공정·측정·논문/배치 그룹·반복·결측·단위를 비교한다.
3. 예측 평가용 자료와 기전 판별용 직접 관측을 구분한다.
4. 대표 소재·주 물성·일반화 범위를 제안하고 경쟁 가설과 반증 조건을 정리한다.

기존 미해결 쟁점은 열린 상태로 보존한다. 원자료가 부족하면 추가 검색으로
돌아가며, 자료가 없다는 사실을 에이전트 합의로 대체하지 않는다. 모델 학습과
실험은 아직 수행하지 않았다. 실제 선정 검토 상태는 UI 및 `screen-status.json`을
기준으로 한다. 사용자의 실제 문헌 선정 결정 전에는 corpus 승인 기록을 만들지 않는다.
