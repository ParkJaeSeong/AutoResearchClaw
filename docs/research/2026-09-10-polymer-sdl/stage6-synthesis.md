# 6단계: 근거 종합과 자료 사용 판단

현재 PC/CNT 자료와 보존된 3역할 최종 의견을 묶은 **조정자 종합 초안**이다. 5단계는 사용자의 지시에 따라 현재 자료 기준으로 이번 회차를 마감한다. 모든 문헌을 읽었다거나 미해결 조건이 사라졌다는 의미는 아니다.

이번에는 새 검색과 같은 원문의 재검토를 반복하지 않고, 기존 판단을 사용 용도와 다음 질문으로 연결했다. 새 에이전트 합의로 표시하지 않는다.

## 주장별 사용 범위

| 항목 | 지금 사용할 수 있는 범위 | 보류할 해석·작업 |
| --- | --- | --- |
| C01 · 같은 CNT 함량에서 제조·형상 조합 비교 | 조건을 맞춘 비교표 작성, 설명할 차이와 경쟁 가설 찾기 | 공정 하나의 인과 효과, 독립 반복 25회에 근거한 유의성 주장 |
| C02 · 최종 두께와 시편 치수 | 치수 출처의 불확실성을 표시하고 두께를 맞추는 대조 조건 설계 | 1.2 mm로 전도도 재계산, 1 mm로 자동 교정, 인장 구간 길이를 전극 간 거리로 사용 |
| C03 · 측정 온도와 장비·방법 | 실측·미상·가공 입력을 구별하는 조건표와 일관된 측정 절차 설계 | 현재 25행으로 온도·장비·측정법 각각의 효과 추정 |
| C04 · 전도도 단위와 CNT 함량 | 원문 단위를 명시한 사례별 정리와 같은 함량의 잠정 비교 | 여러 문헌의 절대 전도도 통합, 검증되지 않은 체적분율 환산 |
| C05 · CNT 함량과 PC 원료 구성 | CNT 증가와 PC 구성 변화의 설명을 구별할 대조 설계 | 함량 추세를 CNT 증가만의 효과로 단정 |
| C06 · 137행의 문헌 간 통합 비교 | 문헌별 조건·자료 의존성·누락 정보를 정리하고 평가 대상 후보 선정 | 전체 PC/CNT에 대한 일반화, 동일 ID의 임의 평균·삭제, expt를 독립 배치로 취급 |

## 가설 단계로 넘길 질문

근거가 보여 주는 것은 조건별 차이와 해석의 제약이다. 아래 설명들은 함께 성립할 수 있으며, 서로 배타적인 정답 후보로 강제하지 않는다.

| 설명 후보 | 구별하기 위해 필요한 관측·대조 | 현재 근거의 한계 |
| --- | --- | --- |
| 제조 과정에서 나노튜브 구조·배향이 달라짐 | 동일 형상·두께·측정 방향에서 제조 조건을 바꾸고 구조 관측과 전도도를 연결 | 현재 자료로 배향만의 인과 효과를 확정하지 않음 |
| 측정 방향·접촉 조건이 차이에 관여함 | 같은 시편에서 전극·방향을 계획적으로 비교하고 반복성 기록 | 측정 정보 부족은 측정 조건이 원인이라는 증거가 아님 |
| 함량 변화와 PC 원료 구성 변화가 함께 작용함 | PC 공급원을 고정한 함량 변화와 PC 혼합비 대조를 분리 | 같은 함량의 제조 조합 차이를 이 설명 하나로 해결하지 않음 |

이 질문들은 H2의 가설 판별 사례 후보를 만드는 준비다. 가설 검증형 에이전트가 다른 실험 선택법보다 낫다는 증거는 아직 없다. H1의 예측 평가와 H3의 실행 전 검사 평가도 별도의 대조 설계가 필요하다.

## 추가 확인을 다시 시작할 조건

- **C01 · 같은 CNT 함량에서 제조·형상 조합 비교:** 정량 차이 또는 비율을 확정할 때만 해당 그림 점의 판독 오차를 확인한다.
- **C02 · 최종 두께와 시편 치수:** 기존 치수를 수치 보정이나 정량 설명변수로 사용하려 할 때 실측·최종 치수 기록을 요청한다.
- **C03 · 측정 온도와 장비·방법:** 기존 기록을 측정 조건 비교에 투입할 때 해당 열의 생성 규칙과 측정 기록을 요청한다.
- **C04 · 전도도 단위와 CNT 함량:** 문헌 간 수치 통합 전에 해당 단위 정의·밀도·환산식을 확인한다.
- **C05 · CNT 함량과 PC 원료 구성:** 함량 효과를 CNT의 단독 효과로 해석하려 할 때 PC 등급·분자량·혼합비 근거를 요청한다.
- **C06 · 137행의 문헌 간 통합 비교:** 평가 데이터 분할을 확정하기 전에 사용할 문헌의 측정 사건과 데이터 재사용 관계를 확인한다.

알 수 없는 수치를 임의 보정하지 않는다. 필요한 기록을 얻을 수 없으면 해당 수치의 사용을 보류하고, 이미 확인한 범위에서 가설·대조 설계를 계속한다. 미해결 문제는 기존 쟁점에 연결하며 이번에 새 쟁점을 중복 등록하거나 기존 22개를 해결 처리하지 않았다.

## 근거와 실제 기록 연결

- [기존 원문 검토와 질문·답변](source-analysis.md): 3역할·9개 발언·9개 질문에 대한 응답.
- [이번 종합의 구조화 자료](stage6-synthesis.json): 여섯 판단 각각의 원문 인용·줄 번호·출처 버전과 이전 최종 발언 연결.
- 해소·승인·단계 완료를 새로 기록하지 않았다. 기존 시스템의 `synthesize`는 선정안·수집·추출의 등록과 검토를 요구하므로, 이번 종합 초안과 정식 노드 완료는 구분한다.
- 다음 작업: 세 설명 후보의 서로 다른 예측과 반증 조건을 작성해 교차 검토한다. 정식 등록에는 기존 수집·추출 기록과 이번 입력 묶음을 연결하는 작업도 남아 있다.
