# 4–5. 이전 자료·수신·수행·근거 구체화

[공통 해석 규칙](README.md)을 적용한다. 아래 필드는 논리적 기록 요구이며 기존 API에 없는 필드를 바로 전송하지 않는다.

## 4. 이전 자료 전달

조정자는 다음 순서로 입력 묶음을 구성한다.

1. 목적·단계 질문·이번 결정 기준.
2. 현재 유효한 판단과 그 근거, 사용자 피드백.
3. 필수 읽기 목록: 판단을 좌우하는 원형/발췌와 가장 강한 반론.
4. 참고 목록: 필요할 때 접근할 고정 버전 자료.
5. 열린 문제·실패·재개 지점과 직전 묶음 이후 변경 사항.
6. 독립 검토일 경우 동료 미공개 의견이 없는지 확인.

| 입력 목록 필드 | 요구 |
| --- | --- |
| 자료 참조·버전 | 필수. 갱신되는 URL만 쓰지 않고 확인한 시점/버전 연결 |
| 종류·원천 | 원문/검색/Atlas 해석/실험/계산/이전 결정 구분 |
| 필요한 이유 | 어느 질문·주장에 쓰는지 |
| 위치·확인 범위 | 페이지·표·행·본문 구간 또는 해당 없음 이유 |
| 원형·해시 | 확보한 파일은 해시와 접근 참조. 미확보는 해시 생성 금지 |
| 실제·합성·가상 | 실험·계산 자료의 성격 표시 |
| 필수/참고·생략 | 역할에 필요한 자료만, 생략 이유 포함 |
| 한계·반대 근거 | 전달 요약에서 삭제하지 않음 |

요약은 원형의 대체 증거가 아니다. 서로 다른 검토자는 같은 기준 입력과 공개 규칙을 받는다. 역할별 추가 자료가 있으면 차이를 목록에 명시하고, 결론을 바꿀 새 근거는 다음 공통 입력 버전에 편입한다.

### 수신 확인 결과

수행자는 `이해한 목적 / 맡은 질문 / 확인한 입력 / 부분 확인 / 접근 불가 / 수행 가능 범위 / 필요한 보완`을 반환한다. 단순히 “확인 완료”라고만 쓰지 않는다.

- 필수 방법 페이지를 못 읽음: 방법 타당성 판단 보류, 서지 정리 등 독립 작업은 가능.
- 선택적 참고 자료 접근 불가: 누락 영향이 없으면 이유를 남기고 수행.
- 목적 버전 충돌: 조정자가 현재 지시를 확인하기 전 의존 판단 보류.
- 이미 끝난 요청: 결과 버전을 검증하고 재사용. 응답 유실이면 기존 요청 상태부터 조회.

## 5. 수집·분석 실행 기록

| 작업 | 최소 기록 | 결과 해석 |
| --- | --- | --- |
| 검색 | 질문·검색식·도구/사이트·시각·조건·실제 후보·실패 | 검색은 발견 경로. 검색 순위가 근거 품질은 아님 |
| 서지/확보 | 제목·저자·연도·식별자·URL·버전·확보 상태·원형 참조 | 미확인 서지를 만들지 않음. 파일이 있다고 읽은 것은 아님 |
| Atlas 분석 | 목적·고정 자료·분석 질문·요청/결과 참조·미응답 항목 | Atlas 해석과 원문 관측 구분 |
| 데이터 분석 | 입력/코드/설정·변환·단위·산식·결과·오류 | 숫자는 실제 계산 증거와 연결. 실행하지 않은 계산은 계획 |
| 실험 자료 검토 | 시료·방법·조건·측정·반복·원자료·실패 | 실제 관측과 예측·합성 구분 |

수집 기준은 질문 관련성 → 내용/버전 확인 → 방법과 비교 가능성 → 현재 용도 적합성 순으로 적용한다. 획일적인 출처 점수 대신 기준별 이유를 기록한다. 이전 버전·중복 후보는 보존하며 관계를 표시한다.

### 주장–근거 카드

```text
주장 ID/버전:
주장 문장과 대상 질문:
유형: 관측 / 문헌 보고 / 계산 / 외부 해석 / 본인 추론 / 가정 / 제안
핵심 여부와 영향받는 결정:
근거별 참조·버전·위치·확인 범위:
지지 / 반박 / 불충분 관계와 이유:
조건·단위·기간·대상:
동일 원천·재인용 관계:
적용 가능한 용도 / 금지할 확장:
검토자·검토 결과 참조:
미확인 사항·재검토 조건:
```

### 작성 예 — 설명용 가정

```text
주장: 두 문헌의 전도도 수치를 직접 비교할 수 있다.
유형: 제안한 비교의 타당성 판단. 핵심: 공정 효과 판단에 영향.
입력: 자료 A와 B의 식별자·방법 위치는 실제 수행 시 연결해야 함.
현재 근거: 전극 배치·측정 방향의 일치가 미확인.
판정: 직접 수치 비교는 보류. 서지와 보고된 조건 정리는 가능.
다음 작업: Atlas에 두 방법 구간 대조 의뢰. 근거가 없으면 비교 범위를 제한.
```

이 예시는 수치나 논문 결과를 주장하지 않는다. 실제 결과에는 A/B 같은 임시 참조 대신 확인한 자료를 연결해야 한다.

### 목적별 분석 결과 요구

- M1-1: 이론·관측·경쟁 설명·변수·교란·검증 가능성. 통계 판정 규칙을 물리적 가설로 바꾸지 않는다.
- M1-2: 정의·비교 조건·평가 기준·사실·권고·대표성. 기간과 분모가 다르면 비교 불가를 허용한다.
- M1-3: 사실·가정·대안·산정식·자원·위험·민감도. 기술 가능성과 실제 수요를 분리한다.
