# 1–3. 목적·단계·페르소나 구체화

[공통 해석 규칙](README.md)을 적용한다.

## 1. 목적 카드

조정자는 요청 원문을 보존하고 아래 항목을 작성한다.

| 필드 | 배정 전 요구 | 적절한 값의 예 |
| --- | --- | --- |
| 의사결정 질문 | 필수. 결과를 받아 무엇을 결정하는가 | “보유 수동 장비에서 자동화할 작업의 우선순위를 정한다” |
| 주 경로·세부 유형 | 필수. 선정 이유 포함 | M1-2, 기술 도입 평가 |
| 결과물·독자 | 필수. 분량/양식은 나중에 확정 가능 | 실험실 책임자용 도입 검토 보고서 |
| 대상·비교·기간·지역 | 결정에 필요한 부분은 필수 | 보유 장비 대상, 기준일 명시, 해외 사례는 국내 적용 조건 별도 |
| 성공 조건 | 필수. 문서 분량 대신 판단 가능성 | 비교 가능한 기준과 조건별 우선순위가 설명됨 |
| 제외 범위 | 필수 | 실제 구매·장비 제어는 이번 작업에 포함하지 않음 |
| 현재/목표 상태 | 필수. 모르면 미확인 | 현재 수동 운영 / 목표 자동화 후보 선정 |
| 제약·권한 | 필수. 미확인 비용은 지출 권한 없음 | 공개자료 조사, 현장 정보 미확인, 구매 불허 |
| 목적 변경 조건 | 필수 | 연구 질문·장비 대상·성공 기준 변경은 사용자 의도 재확인 |

“복합재를 연구한다”처럼 결정 대상이 없는 요청은 질문 후보를 제시하고 좁힌다. 핵심 목적이 불명확하면 그 선택에 의존하는 실행은 보류한다. 일반 현황 조사처럼 독립적인 탐색은 임시 범위를 표시해 진행할 수 있다.

출력은 목적 카드 버전과 열린 확인 사항이다. 사용자가 말하지 않은 기한·예산·장비를 사실로 채우지 않는다. 목적 변경 시 변경 전후·이유·원래 지시·영향 결과를 연결한다.

## 2. 마일스톤·단계의 목적

마일스톤 카드는 목적, 필수 결과, 수신자, 완료 조건, 적용하지 않는 항목을 가진다. M1-1/2/3은 M1 아래 목적 경로이며 실제 수행 단계·회차와 분리한다.

| 경로 | M1이 끝날 때 답할 질문 | 주 인계 |
| --- | --- | --- |
| M1-1 연구 설계 | 경쟁 설명을 무엇으로 구분하며 실제 검증에 필요한 조건은 준비됐는가 | M2 실행 명세. 문헌 연구는 별도 작성 준비 판단 |
| M1-2 조사·평가 | 어떤 기준과 근거로 무엇을 결론·권고할 수 있는가 | M4 보고서 구성·주장·근거 |
| M1-3 계획 수립 | 어떤 안을 왜 추진하고 무엇을 검증하며 언제 수정·중단할 것인가 | M4 계획서·가정·검증 계획 |

단계 카드의 필수 항목은 `목적 / 입력 / 답할 질문 / 수행 / 출력 / 종료 / 복귀 / 책임`이다.

| 공통 작업 | 목적과 최소 출력 | 종료와 복귀 |
| --- | --- | --- |
| 질문 정리 | 질문·범위·판단 기준 확정 | 핵심 의도 일치 시 종료. 목적이 달라지면 재정의 |
| 자료 수집 | 필요한 증거의 후보·원형·공백 확보 | 필수 질문의 분석 대상을 확보하거나 미확보 처리 결정. 새 공백이 판단을 바꾸면 재검색 |
| 내용 분석 | 조건·관측·출처 위치·한계 정리 | 요청 항목별 답/미확인/불가 구분. 원형/버전 오류면 자료 확인으로 복귀 |
| 전문가 토론 | 해석과 반론 검토 | 주요 차이의 이유·영향·처리 정리. 새 증거 필요면 분석/수집으로 복귀 |
| 방향·계획 정리 | 경로별 판단과 실행/작성 계획 | 필수 산출물 충족, 의존하는 미확인 처리. 핵심 전제 붕괴 시 질문 재검토 |
| 인계 준비 | 수신자가 수행할 수 있는 의뢰 작성 | 수신 요건 확인. 보완 요청은 영향 단계에만 반환 |

이는 반드시 한 번씩 순차 통과할 고정 엔진이 아니다. 이미 있는 자료·검토는 입력 버전과 목적이 맞으면 재사용하고 근거를 남긴다.

## 3. 페르소나 배정표

| 역할 | 맡길 질문·방법 | 필요한 입력 | 요구 출력·금지 |
| --- | --- | --- | --- |
| 분야 전문가 | 이론이 성립하는 조건과 경쟁 설명은 무엇인가 | 직접 관련 문헌·조건별 관측·반례 | 설명별 근거·적용 범위. 전문성만으로 사실 확정 금지 |
| 방법·평가 검토자 | 비교·검증이 주장을 구분하는가 | 측정/선정/분할/평가 방법과 원데이터 구조 | 편향·교란·반증·불확실성. 상관을 인과로 바꾸지 않음 |
| 실행 검토자 | 실제 조건에서 이 계획을 수행할 수 있는가 | 장비·환경·자원·권한·실패 처리 | 실행 전제·확인 항목. 미확인 장비/권한 가정 금지 |
| 조사·비교 전문가 | 정의·기간·대상의 차이가 비교를 깨는가 | 비교 기준·통계 정의·출처·기준일 | 비교표·비교 불가·조건부 권고. 무근거 순위 금지 |
| 수요·활용 전문가 | 누구의 어떤 문제와 선택에 도움이 되는가 | 고객/수혜자 관측·과업 요구·대안 | 수요 근거·채택 조건. 홍보 문구를 수요 입증으로 쓰지 않음 |
| 자원·계획 검토자 | 비용·일정·의존성과 실패 조건이 맞는가 | 산정 근거·역량·가용 자원·추진안 | 대안·민감도·중단 조건. 가정을 확정 실적으로 쓰지 않음 |
| 조정자 | 원래 목적에 답하며 다음 행동을 정할 수 있는가 | 위 결과·이견·권한·현재 상태 | 결정·인계·보류 범위. 합의로 과학적 사실 생성 금지 |

경로별 기본 배정:
- M1-1: 분야 + 방법 검토. 실행 계획 채택 시 실행 검토 추가.
- M1-2: 분야/조사 담당 + 비교 방법 검토. 도입 권고에는 활용 관점 추가.
- M1-3: 분야/계획 담당 + 수요/자원/위험 중 핵심 가정에 맞는 반대 관점. 공고형 연구 제안에는 시장 매출 대신 공고·연구 목표 적합성 적용.

기본 배정은 책임 커버리지이며 모든 역할을 매회 별도 호출하라는 뜻은 아니다. 중요 결과 작성자와 그 독립 검토자는 구분한다. 필요한 전문성이 없으면 보완 요청을 반환한다. 역할 카드에는 판단을 바꿀 증거와 담당하지 않을 판단을 반드시 쓴다.

### 채운 역할 카드 예 — 검토 방식 예시, 실제 연구 판정 아님

```text
역할: 복합재 측정·비교 방법 검토자 v0.1
목적: 공정 차이와 측정 조건 차이를 혼동하지 않게 한다.
질문: 전극 배치·측정 방향·두께가 다른 자료를 직접 비교할 수 있는가?
방법: 측정량 정의·형상·단위·접촉 영향·조건 차이를 대조한다.
입력: 고정된 문헌 버전, 관련 방법/표/그림 위치, 실제 확인 범위.
변경 조건: 동일 조건 비교 또는 차이를 보정할 검증 근거가 추가되면 재평가한다.
출력: 허용 비교, 금지 비교, 추가 확인, 설계에 넘길 측정 요구.
경계: 이 검토만으로 소재의 인과 메커니즘이나 실험 준비 완료를 확정하지 않는다.
```
