# 이전 자료 보관함

- [2026-09-19 프로젝트 정리](legacy/2026-09-19-project-cleanup/README.md): 과거 단계 문서 4개·실험 스크립트 7개 아카이브, 캐시 삭제, 현행 개발 진입점 정리.

현재 연구 가이드와 원본·이전 구현 자료를 구분하기 위한 보관 폴더다. 파일은 삭제하지 않고 이동했다.

- `upstream/`: 원본 AutoResearchClaw에서 이어진 소개 문서, 번역, 통합 안내, 논문 예시, 이미지와 홍보 웹페이지. 일부 파일에는 이전 포크 수정이 포함될 수 있어 원본의 무수정 복제본으로 간주하지 않는다.
- `legacy/`: 이전 구현의 프런트엔드와 운영·개발 문서. 원본과 포크의 기여가 혼합돼 출처를 단정하지 않는다.

여기의 에이전트 지침·자동 실행 설명은 현행 운영 지침이 아니다. 현재 기준은 [연구 운영 가이드](../docs/research/guides/README.md)에서 확인한다.

기존 자료 내부의 이미지와 링크는 이동 위치에 맞춰 수정했다. Python 런타임과 그 설정·프롬프트는 현재 CLI와 테스트의 의존성이 있어 이동하지 않았다. 루트 LICENSE와 저작자 표시는 유지한다.

이동 경로와 삭제한 캐시는 [정리 기록](../docs/project-organization.json)에 남겼다.

- [2026-09-13 설계 정리](legacy/2026-09-13-design-reset/README.md): 이전 고정 단계 설계·계획 22개와 철회한 Zotero 제안 1개. 현행 연구 운영·연동 계약과 분리했다.
