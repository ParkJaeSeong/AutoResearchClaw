# 이전 단계 설계·계획 보관

2026-09-13 새 자율 연구 구조 논의에 따라 이전 고정 단계 설계·계획 22개와 철회한 Zotero 수집 제안 1개를 옮겼다. 구현 당시의 근거와 이력은 유지하되 현행 작업 지시와 분리한다. 원본 프로젝트 문서라고 단정하지 않는다.

현재 기준은 [Pilot 설계 검토본](../../../docs/superpowers/specs/2026-09-13-pilot-autonomous-research-design.md)을 참고한다.

파일 이동·내용 해시·참조 변경 목록은 [manifest.json](manifest.json)에 있다. 이동 후 링크와 아카이브 안내만 수정했다. 코드·실행 상태·연구 원문·현재 Atlas 계약·공통 UI 디자인 기준은 이동하지 않았다. 기존 기록 내부의 과거 경로 문자열은 역사적 기록으로 유지한다.

스킬 정리에서 이전 `skills/researchclaw/SKILL.md` 원문도 `skills/researchclaw/SKILL.md`에 보관했다. 그 원문의 상대 참조는 당시 스킬 배치 기준이다. 실제 이전 엔진 재개에 필요한 참조는 현재 패키지의 `skills/researchclaw/references/legacy-workflow.md`와 기존 참고 파일에서 제공한다. 이 추가 스킬 사본은 앞서 이동한 문서 23개와 별도다.
