# 2026-09-19 프로젝트 정리

현행 Pilot 개발 진입점과 과거 실험 도구를 분리했다. 이동 목록·원형 SHA-256·삭제한 캐시의 수와 용량은 [manifest.json](manifest.json)에 기록했다.

## 아카이브한 자료

- `docs/`: 23단계 개요, 9월 8일 개발 현황, stage13 경로 수정·시간 연장 설명 4개.
- `run_hep_pipeline.sh`: HEP 전용 원본 파이프라인 실행 예제.
- `scripts/`: MetaClaw 시작, 홍보 그림, Beast Mode·CodeAgent 실험 스크립트 6개.

스크립트는 역사 자료로 원형 보존했다. 원래 루트 기준 경로를 포함하므로 이 위치에서 바로 실행하는 도구가 아니다. 재사용 시 코드·설정·경로를 검토해야 한다. 현행 CLI·테스트·스킬의 외부 호출 참조가 없는 것을 확인한 뒤 이동했다.

## 삭제한 자료

소스·테스트 폴더의 Python bytecode와 루트 pytest/ruff 캐시만 삭제했다. Git 추적 파일이 없는 것을 확인했다. 이후 실행·검사에서 캐시는 다시 생성될 수 있다.

## 보존한 자료

연구 원형·에이전트 발언·프로젝트 저장소·외부 연결 파일·검증 증거·가상환경은 보존했다. 연구 catalog와 프로젝트 HEAD의 해시를 정리 전후 대조했다. 큰 과거 연구 저장소는 경로와 참조가 연결돼 있어 이동하지 않았다.

이전 M1 UI·원본 sentinel·검토 실행기는 아직 코드 또는 테스트가 참조하므로 유지했다. 실행기 통합이나 전체 M1 자동 실행을 완료한 정리가 아니다.

- 프로젝트 관리·현행 연구 CLI·이전 M1 CLI 관련 기존 테스트 15개 통과.

- 일반 검색에서 archive/workspaces/output/.superpowers가 제외되는 것을 확인했다.

전체 M1 자동 실행·모델 설정 연결·연구 재개는 이번 정리에 포함하지 않았다.
