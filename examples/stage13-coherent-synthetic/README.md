# 정합성이 맞는 합성 입력 샘플

이 폴더는 새 사용자 테스트를 위한 **원천 자료 묶음**이다. 12단계 완료 상태를
조작한 프로젝트가 아니며, 기존 사용자 테스트와 승인·증거를 수정하지 않는다.
`tests/codex_native/helpers.py`의 범용 fixture는 구조·무결성 테스트용이다.
서로 다른 연구 주제와 고정 결과를 조합하므로 사용자 대상 과학적 판단의
정합성 샘플로 사용하지 않는다.

## 주제와 계산

주제는 합성 배터리 수명 예측표의 지표·분할 검증이다. 입력은 14개 가상 셀,
7개 가상 그룹이며 train 6/3, validation 2/1, calibration 2/1, test 4/2
(셀/그룹)로 나뉜다. 각 그룹과 셀은 한 분할에만 속한다.
지표는 test 네 행의 `mean(abs(target_cycles - prediction_cycles))`이며,
이름 `mae_cycles`, 단위 `cycles`, 기대값은 **0.5**이다.
분할 수와 오차는 CSV에서 계산하며 결과에 상수로 넣지 않는다.

저장소 루트에서 독립적인 자료 확인만 하려면:

```sh
python3 examples/stage13-coherent-synthetic/baseline.py examples/stage13-coherent-synthetic/input.csv
```

표준 라이브러리만 사용한다. 파일을 수정하거나 네트워크에 접속하지 않는다.
출력은 `evidence_eligible=false`인 산술 확인 결과이며, ResearchClaw의 실행
결과 등록 형식이 아니다. 이 명령을 13단계에서 반환된 실행 argv 대신 쓰지 않는다.

## 새 연구 프로젝트에서 사용

새 프로젝트를 만들 때 `scenario.json`과 이 CSV를 입력으로 제시하고,
목표·가설·설계·패키지의 지표와 분할을 위 정의에 맞춰 작성한다. 기존
완료 fixture의 제목·결과·해시만 바꾸거나 승인 기록을 복제하지 않는다.
실제 단계별 검증과 필요한 사용자 승인을 거쳐 12단계 결과를 등록한 뒤
13단계 독립 검토를 시작한다. 이 묶음만으로 13단계가 준비되는 것은 아니다.

에이전트들은 개선할 근거가 없다면 baseline 유지 또는 판단 유보를 선택할 수
있다. 후보 1개·본 실행 1회는 상한이지 반드시 채워야 하는 목표가 아니다.
예측값은 학습된 모델의 출력이 아니라 고정된 합성 값이다. test의 정답을
복사하거나 입력을 바꿔 얻은 낮은 오차는 유효한 개선이 아니다. 모든 수치는
워크플로 검증용이며 실제 배터리 성능이나 연구 증거를 뜻하지 않는다.
